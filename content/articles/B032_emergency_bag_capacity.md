# 防災リュックは何L必要？中身・重さから容量を決める考え方

防災リュックを選ぶとき、「20L・30L・40Lのどれがよいか」と容量から考えたくなります。しかし、公的な防災資料は非常持ち出し品をリュック等に入れて準備することを案内している一方、**家庭向けに一律の正解容量を示しているわけではありません。**

この記事では、持ち出す中身 → 自分が運べる重さ → 家族での分担 → バッグへの詰め方 → 最後に容量、の順で考えます。

## 結論：L数より「中身 → 重さ → 容量」の順で決める

防災リュックは次の順で選びます。

1. 避難時に本当に持ち出す物を決める
2. 自宅備蓄と分ける
3. 家族で分担できる物を決める
4. 実際の荷物を一度集める
5. 背負って移動できる重さか確認する
6. その荷物が収まり、取り出しやすい容量・形状を選ぶ

**大きいリュックを先に買い、空いている分まで荷物を足す**のは逆の考え方です。

## 1. まず「自宅に置く物」を外す

内閣府は、食料・飲料水は最低3日分、できれば1週間分を備える一方、急いで避難する場合に「すぐ必要になるもの」「ないと困るもの」を非常持ち出し品としてリュック等へ入れておく考え方を示しています。

つまり、1週間分の水や食料を全部リュックへ入れる必要はありません。

| 自宅備蓄 | 持ち出し品 |
|---|---|
| 数日〜1週間の水・食料 | 避難直後に必要な飲料・食品 |
| まとまった携帯トイレ | 移動中・避難先用の少量 |
| 大容量の生活用品 | 最低限の衛生用品 |
| 予備の電源・電池 | 移動中・避難先で使う充電手段 |

具体的な中身を先に決めたい場合は、[防災リュックの中身は何を入れる？](article_b002.html)で用途ごとに確認できます。

## 2. 「誰が、どこまで運ぶか」で持てる量が変わる

同じ30Lのバッグでも、徒歩で長く移動する人と、近くの避難場所まで移動する人では負担が違います。

容量を考える前に、

- 本人の体力・年齢
- 避難先までの距離
- 階段や坂の有無
- 乳幼児や要介護者を支援する必要があるか
- 両手を空けておく必要があるか

を確認します。

子どもや高齢者へ一律の荷物量を割り当てません。乳幼児がいる家庭ではおむつ・ミルク等でかさが増え、高齢者や持病のある人では薬・補助具が優先されます。**「○人なら○L」という人数だけの基準では決めにくい**理由です。

## 3. 家族分を1個の大型バッグへ集中させなくてもよい

「2人用だから大きなリュック1個」と考える必要はありません。

家族で避難する場合は、飲料水、食品、ライト、モバイルバッテリー、衛生用品などの共用品を分担できます。

一方、

- 常用薬
- 眼鏡・補聴器
- 乳幼児用品
- 本人に必要な医療・衛生用品

など、**特定の人に代替がきかない物は、その人と一緒に動くバッグへ入れる**方が、家族が別々になった場合にも確認しやすくなります。

共用品を1人へ集中させず、誰か1人が持てなくなっても最低限が残るよう分ける方法もあります。

## 4. 20L・30L・40Lという数字だけでは決まらない

同じ「30L」と表示されたリュックでも、形、開口部、ポケット、背面構造などが異なるため、同じ荷物が同じように入るとは限りません。

| 確認項目 | なぜ見るか |
|---|---|
| 開口部 | 必要品を取り出しやすいか |
| 本体重量 | 中身を入れた総重量へ影響する |
| 肩紐・背面 | 体格に合わせて背負えるか |
| ポケット | 移動中に使う物を分けられるか |
| 防水・撥水 | 雨天時の保護方法を考えられるか |
| 形状 | 重い物を背中側へ寄せやすいか |

L数は候補を絞るための情報として使い、**最終判断は実際の中身を入れた状態**で行います。

## 5. 大きすぎるバッグは「空き容量を埋める」問題がある

容量に余裕があると、「これも入れておこう」と荷物が増えやすくなります。

防災リュックでは、空間を埋めることより、

- 背負って立てる
- 数分歩ける
- 階段を使える
- 両手を使える
- 必要な物をすぐ取り出せる

ことを優先します。

バッグが大きくても、中身を必要最小限にできていれば問題ありません。逆に、小さなバッグへ必要品を無理に詰め込んで使いにくくするのも避けます。

## 6. 入りきらないときは、必要品を削る前に役割を分ける

必要な薬や衛生用品を、バッグへ合わせるためだけに削るのは避けます。

入りきらないときは、次の順で確認します。

1. 自宅備蓄まで入れていないか
2. 同じ用途の物が重複していないか
3. 家族で分担できないか
4. 車載備蓄など別の保管場所へ分けられないか
5. それでも必要品が入らないなら、より大きいバッグを検討する

**容量を増やす前に、中身の役割を整理する**ことがポイントです。

## 7. バッグの中は「すぐ使う物」と「避難先で使う物」を分ける

容量が足りていても、必要な物が底に埋まっていると移動中には使いにくくなります。

### 取り出しやすい位置へ置く物

- ライト
- スマートフォン
- 常用薬
- 家族の連絡先
- 身分証の控えなど、到着前後に確認する物

### 奥でもよい物

- 着替え
- 予備品
- 避難先に着いてから使う衛生用品など

また、水など重い物を片側へ寄せると背負いにくくなります。バッグの中で重さが偏らないようにし、**容量・重量・取り出しやすさを同時に確認**します。

## 8. 実際に詰めて「避難テスト」をする

消防庁は、非常持ち出し品を持ち出しやすい場所に置き、背負える袋などに入れて両手を使えるようにする考え方を案内しています。

購入後は棚に置いて終わりにせず、

1. 全部入れた状態で背負う
2. 家の中を歩く
3. 階段を使う
4. 玄関まで持って行く
5. ライトや薬など、すぐ使う物を取り出す
6. 肩の痛み、重心の偏り、通路での動きにくさを確認する

ところまで試します。

重すぎる場合は、容量を変える前に**中身を減らす・家族で分担する・配置を変える**ことを検討します。

## 容量選びチェックリスト

- [ ] 自宅備蓄と持ち出し品を分けた
- [ ] 必要品を先に並べた
- [ ] 家族固有の薬・衛生用品を確認した
- [ ] 誰がどこまで運ぶかを考えた
- [ ] 家族で共用品を分担した
- [ ] 実際の荷物をバッグに入れた
- [ ] 背負って数分歩いた
- [ ] 階段や玄関までの動線を確認した
- [ ] すぐ使う物を取り出せる
- [ ] 大きさに合わせて不要品を追加していない

## 商品を探す段階で見る表示

| 表示 | 一緒に確認したいこと |
|---|---|
| 容量（L） | 実寸、形状、開口部 |
| 本体重量 | 中身を入れた総重量 |
| ポケット | 必要品の取り出しやすさ |
| 肩紐 | 調整範囲・体格への適合 |
| 防水・撥水表記 | 製品が示す条件・カバーの有無 |

特定の容量を「この人数なら必ず十分」とは決めず、**持ち出す中身と本人の体格・避難条件に合わせて確認**します。

## まとめ：容量は最後に決める

防災リュックのL数は、最初に決める答えではありません。

先に自宅備蓄を外し、必要な持ち出し品を並べ、家族で分担し、実際に背負って歩きます。そのうえで、**必要品が無理なく入り、重すぎず、取り出しやすいバッグ**を選ぶのが実用的です。
