# 停電したら冷蔵庫の食品はいつまで？冷蔵・冷凍食品の判断と停電対策

停電すると「冷蔵庫は何時間もつ？」「肉や牛乳は食べられる？」「冷凍食品は再冷凍できる？」と判断に迷います。

農林水産省は2026年9月8日の案内で、**扉を開けない場合に低温を保持できる時間の目安を、冷蔵庫で約4時間、冷凍庫で約1〜2日間**としています。ただし、これは安全を保証する時間ではなく、気温や庫内の食品量などで変わる目安です。

そのため、**全国の家庭に共通する「○時間までなら必ず安全」という一本の線では判断できません。** 時間の目安に加えて、食品の種類、庫内温度、解凍状態、扉の開閉、商品表示を合わせて確認します。

この記事では、停電直後の行動 → 時間の目安 → 食品の判断 → 冷凍品の扱い → 長引く場合の対応 → 復電後の電気安全、の順で整理します。

## 結論：冷蔵約4時間・冷凍約1〜2日は「目安」。まず扉を開けない

優先順位は次のとおりです。

1. 冷蔵庫・冷凍庫の扉を必要以上に開けない
2. 停電情報と復旧見込みを確認する
3. **冷蔵約4時間、冷凍約1〜2日**を「扉を開けない場合の低温保持の目安」として把握する
4. 肉・魚・惣菜・乳製品・作り置き等、温度管理が重要な食品を優先して確認する
5. 時間だけでなく、庫内温度・室温・解凍状態・食品表示を合わせて判断する
6. 温度管理が失われた、または状態が分からない食品は無理に食べない
7. 完全に解凍した冷凍食品は、再冷凍を避ける
8. 冷蔵庫やコンセントに浸水・焦げ臭さ・損傷がある場合は、食品より電気安全を優先する

## 1. 停電直後は、まず扉を閉めたままにする

農林水産省と厚生労働省は、停電時に冷蔵庫・冷凍庫の**扉の開閉をできるだけ控える**よう案内しています。

停電直後に「何が入っているか」を何度も確認すると、そのたびに冷気が逃げます。農林水産省が示す冷蔵約4時間・冷凍約1〜2日という目安も、**扉を開けないことが前提**です。

最初は、

- 扉を閉めたままにする
- 停電情報で復旧見込みを確認する
- 常温で食べられる備蓄があれば、先にそちらを使う
- 保冷剤やクーラーボックスへ移す場合も、移す物を決めてから短時間で作業する

という順で考えます。

**食品を全部取り出して並べてから考える**のは避けます。

## 2. 「何時間もつ？」には公的な目安がある。ただし安全保証ではない

農林水産省が2026年9月8日に公表した案内では、停電中に扉を開けない場合、低温を保持できる時間について次の目安を示しています。

| 区分 | 低温を保持できる時間の目安 | 注意点 |
|---|---:|---|
| 冷蔵庫 | 約4時間 | 気温、庫内の食品量、機種、扉開閉等で変わる |
| 冷凍庫 | 約1〜2日間 | 同上。食品が完全に解凍した場合は再冷凍を避ける |

この数字は、**「4時間以内なら肉も牛乳も必ず安全」「冷凍庫なら2日まで何でも食べられる」という意味ではありません。**

同じ停電時間でも、

- 停電前に十分冷えていたか
- 冷蔵庫・冷凍庫の断熱性能
- 食品がどの程度入っているか
- 室温が高いか低いか
- 扉を何回開けたか
- 冷蔵室か冷凍室か
- 食品ごとの保存条件

で状態は変わります。

したがって当サイトでは、農林水産省の時間を**判断開始の目安**として使い、その後に食品の種類・保存温度・解凍状態・商品表示を確認します。

平常時から機種の温度表示や取扱説明書を確認し、必要に応じて**庫内温度を把握できる方法**を用意しておくと、停電後の推測を減らせます。

## 3. 温度管理が重要な食品から確認する

特に慎重に扱うのは、冷蔵・冷凍による温度管理が前提の食品です。

| 食品の例 | 判断で重視すること |
|---|---|
| 生肉・魚介類 | 温度管理、汁漏れ、他食品への汚染 |
| 牛乳・乳製品 | 要冷蔵表示と温度管理 |
| 卵を使った料理 | 調理後の保存状態 |
| 作り置き・残り物 | 停電前後の保存状態 |
| 要冷蔵の惣菜 | 商品表示と庫内状態 |
| 冷凍食品 | 解凍の進み方、温度管理 |

農林水産省は、**肉・魚・惣菜など傷みやすい食品は、冷蔵庫の低温保持の目安時間を超えた場合は廃棄する**よう案内しています。また、要冷蔵・要冷凍食品で適正な保存温度を保てなかった場合も、食べずに処分するよう案内しています。

一方で、家庭の停電状況は一律ではないため、「停電から何時間」という数字だけで全食品を同じように扱わず、商品表示や実際の保存状態も確認します。

**温度管理が失われた可能性があり、安全性を確認できない場合は、もったいなくても無理に食べない**判断が必要です。

## 4. におい・見た目・味見だけで安全確認しない

傷んだ食品は変色や異臭が出ることがありますが、見た目やにおいに変化がないことは安全の保証になりません。

「少し食べてみて大丈夫なら使う」という確認方法も避けます。

食品の安全は、**停電時間だけでなく、どの温度でどの程度管理されていたか**を重視します。

## 5. 冷凍食品は、完全に解凍したら再冷凍を避ける

停電後もしばらく凍った状態を保つ食品がありますが、場所や食品の大きさによって解凍の進み方は異なります。

復旧後は、

- 十分凍った状態が残っているか
- 表面や全体が柔らかくなっていないか
- 肉汁等が漏れていないか
- 他の食品へ付着していないか
- 温度管理がどの程度失われたか

を確認します。

農林水産省は、**完全に溶けた冷凍食品を再び凍らせることは避ける**よう案内しています。

「再冷凍すれば安全に戻る」とは考えず、完全に解凍した食品や、適正な保存温度を保てなかった食品は無理に使いません。まだ凍結状態が残っている場合も、商品表示や保存状態を確認します。

## 6. 真夏など停電が長引くときは条件を厳しく見る

室温が高いほど、庫内温度も上がりやすくなります。

農林水産省の冷蔵約4時間・冷凍約1〜2日という数字も、**気温や庫内の食品量などで変わる目安**です。真夏だから同じ時間だけ安全に保てるとは考えません。

真夏に復旧が長引きそうな場合でも、生肉・魚・乳製品・作り置き等を**「悪くなる前に全部食べ切ろう」と急いで消費する**のではなく、安全性を確認できないものは無理に使いません。

保冷剤やクーラーボックスを使う場合も、何を移すか先に決め、扉を開ける時間を短くします。

停電対策全体は[停電に備えて準備しておきたいもの](article_b004.html)、非常食を使って冷蔵庫を開ける回数を減らす備えは[非常食は何日分必要？](article_b026.html)で確認できます。

## 7. 計画停電・台風前なら、冷蔵庫へ依存しない食事も準備する

停電の可能性が事前に分かっている場合は、

- 保冷剤を凍らせる
- 冷蔵庫内を整理し、必要な物を短時間で取り出せるようにする
- 常温で食べられる食品を別に用意する
- スマートフォン等を充電する
- ポータブル電源を使う場合は冷蔵庫の定格・起動電力・メーカー注意事項を確認する

といった準備ができます。

**「冷蔵庫を何時間守れるか」だけでなく、冷蔵庫を開けなくても数食を確保できるか**まで考えると選択肢が増えます。

電源の選び方は[ポータブル電源は防災に必要？](article_b028.html)で整理しています。

## 8. ドライアイス・保冷剤は「入れれば安全」ではない

保冷剤やクーラーボックスは温度上昇を遅らせる助けになりますが、食品の安全を無条件に保証するものではありません。

ドライアイスを使う場合は、製品・販売元の取扱注意に従い、**密閉空間での二酸化炭素濃度上昇や素手での接触**にも注意します。冷蔵庫へ入れる方法を独自に推奨せず、機器メーカーの取扱説明書も確認します。

## 9. 浸水・断水が同時に起きたら、食品より人と電気の安全を先にする

大雨や洪水では、停電と断水・浸水が同時に起きる場合があります。

食品を守るために危険な場所へ戻らず、冷蔵庫・コンセントが浸水した場合は、**通電確認より建物と電気設備の安全確認を優先**します。

冷蔵庫やコンセントに、

- 浸水
- 焦げ臭さ
- 火花・異音
- 電源コードの損傷

がある場合は、何度も通電を試さず、メーカーや電気の専門家へ相談します。

## 10. 復電後は「食品」と「冷蔵庫本体」を分けて確認する

地域の停電が復旧しても、冷蔵庫が正常に冷えるとは限りません。

食品は保存状態を確認し、冷蔵庫本体は、

- 電源が入るか
- 異音・異臭がないか
- 冷却が再開しているか
- 浸水や損傷がないか

を確認します。

異常がある場合は、食品を守るために通電を繰り返すのではなく、専門家へ確認します。

## 停電前後の食品チェック

- [ ] 停電中は冷蔵庫・冷凍庫を必要以上に開けない
- [ ] 復旧見込みを確認した
- [ ] 冷蔵約4時間・冷凍約1〜2日は安全保証ではなく目安だと理解した
- [ ] 要冷蔵・要冷凍食品を優先して状態確認する
- [ ] 時間だけで安全判定しない
- [ ] 完全に解凍した冷凍食品を再冷凍しない
- [ ] におい・見た目・味見だけで安全と決めない
- [ ] 温度管理が不明で不安な食品は無理に食べない
- [ ] 肉汁等の漏れによる交差汚染を確認する
- [ ] 常温で食べられる備蓄も用意している
- [ ] 浸水・焦げ臭さ・異音がある冷蔵庫へ再通電しない

## まとめ：公的な時間目安を使いながら、食品の状態も確認する

停電時の低温保持について、農林水産省は**扉を開けない場合、冷蔵庫で約4時間、冷凍庫で約1〜2日間**という目安を示しています。

ただし、これは一律の安全保証ではありません。まず扉を閉め、復旧見込みを確認し、**時間の目安 → 温度管理が重要な食品 → 解凍状態 → 保存条件 → 冷蔵庫本体の安全**の順で見ます。状態が分からず不安な食品は無理に食べないことも、災害時の安全対策です。
