# 台風の風災は火災保険でどう扱われる？

台風で屋根や外壁、窓などが壊れた場合、火災保険の**風災補償の対象になる契約があります**。ただし、「台風の日に壊れた」ことだけでは判断できません。強風による突発的な損傷なのか、洪水による浸水なのか、以前からの経年劣化なのかで確認する補償が変わります。

この記事では、**風災と水災の違い → 契約で見る項目 → 損害原因 → 被害後の行動 → 修理契約**の順で整理します。

## 結論：「台風」という災害名ではなく、損害原因と契約を確認する

確認するのは次の4点です。

1. **風災補償が付いているか**
2. **壊れた物が建物・家財のどちらの保険対象か**
3. **強風・飛来物等と損害の因果関係があるか**
4. **免責・支払条件・保険金額等がどうなっているか**

被害後は、**安全 → 記録 → 契約確認 → 保険会社・代理店へ連絡 → 修理**の順で進めます。高所へ上がって写真を撮ったり、保険金が出る前提で修理契約を急いだりしません。

## 1. 台風でも「風災」と「水災」を分ける

同じ台風でも、損害の原因によって確認する補償が変わります。

| 被害の例 | 最初に確認する補償 | ポイント |
|---|---|---|
| 強風で屋根材が飛んだ | 風災 | 風による突発的損害か確認する |
| 飛来物で窓が破損 | 風災 | 何が当たり、どこが壊れたか整理する |
| 河川氾濫で床上浸水 | 水災 | 風災ではなく水災の契約を見る |
| 高潮で浸水 | 水災 | 沿岸部の浸水原因を確認する |
| 屋根破損後に雨が室内へ侵入 | 風による破損との因果関係 | 雨漏りだけを見て判断しない |

火災保険の水災は[火災保険の水災補償とは？](article_b013.html)で詳しく整理しています。

## 2. 保険証券では「風災・対象・免責・連絡先」を見る

台風前に契約を確認するなら、商品名だけではなく次を見ます。

| 確認項目 | 何を見るか |
|---|---|
| 風災補償 | 風災・雹災・雪災等の補償が付いているか |
| 保険対象 | 建物、家財、両方のどれか |
| 免責・自己負担 | 損害時の自己負担が設定されているか |
| 保険金額・支払条件 | 金額・限度・条件がどうなっているか |
| 事故受付先 | 保険会社・代理店へどう連絡するか |

紙の証券がすぐ見つからない場合に備え、Webサービスやアプリ等で契約を確認できるか、保険会社名・代理店連絡先を家族が分かるかも確認します。

## 3. 「台風の日に雨漏りした」だけでは風災と決めない

長年の劣化で屋根や外壁に傷みがあり、台風時に雨漏りが分かった場合などは、損害原因の確認が必要です。火災保険は一般に、通常の経年劣化や自然消耗を修繕する制度ではありません。

一方、強風で屋根材が損傷し、その開口部から雨が入った等、風による破損との因果関係を確認するケースもあります。

**自分で「台風だから対象」「古い家だから対象外」と決めず**、発生状況、写真、修理業者の確認内容等を契約先へ伝えます。

## 4. 建物本体だけでなく、家財・付属設備の契約範囲も確認する

窓が割れて雨が入り家具・家電が壊れた場合など、家財損害がある時は**家財を保険対象としているか**確認します。建物契約だけでは家財が同じように補償されるとは限りません。

また、カーポート、門、塀、物置、アンテナ、太陽光設備等が「建物」に含まれるかは契約によって異なります。

| 壊れたもの | 確認すること |
|---|---|
| 屋根・外壁・窓 | 建物の風災補償 |
| 家具・家電 | 家財契約の有無と原因 |
| カーポート・物置等 | 契約上、建物等に含まれるか |
| 賃貸住宅の建物部分 | 所有者・管理会社側の手続きとの分担 |

**自宅敷地内にある物がすべて同じ契約で補償されるとは決めつけない**ことが重要です。

## 5. 平常時の維持管理と、突発的な風災を分けて考える

雨どいの外れ、屋根材の浮き、アンテナの緩み等が以前から分かっている場合は、台風シーズン前に修繕を検討します。

保険を「古くなった部分を台風後に直す仕組み」と考えるのではなく、**平常時の点検・修繕と、突発的な損害への保険を別に持つ**と整理しやすくなります。

## 6. 被害後は「安全→記録→契約確認→連絡→修理」の順で進める

### 1. 安全：屋根や高所へ上がらない

台風通過直後でも強風が残る場合があります。屋根・高所へ自分で上がって撮影せず、地上から安全に確認できる範囲にします。

瓦、外壁材、枝、看板等が落下する可能性もあるため、建物周囲へ近づく場合も頭上を確認します。

### 2. 記録：全景と損傷部を組み合わせる

安全に撮影できる場合は次を残します。

- 建物全景
- 屋根・外壁等の損傷が分かる遠景
- 地上へ落ちた部材
- 室内への雨水侵入状況
- 家財損害がある場合は部屋全体
- 被害に気付いた日時

高所の詳細写真が必要な場合は、自分で上がらず、修理業者等が安全に確認した資料を使えるか保険会社へ相談します。

### 3. 契約確認：風災・対象・免責を見る

事故受付前後に証券を確認し、分からない点は自己解釈せず保険会社・代理店へ尋ねます。

### 4. 連絡：保険会社・代理店へ事故状況を伝える

飛来物の発生元が分からない場合や、自宅の物が近隣へ飛散した場合など、第三者との関係があるケースもあります。自宅の風災補償と賠償責任は別問題になる可能性があるため、事実を伝えて確認します。

### 5. 修理：保険金が出る前提で契約しない

自然災害後には「保険金を使えば無料で修理できる」等の勧誘トラブルが注意喚起されています。修理業者の見積額と保険会社の認定額が同じになるとは限りません。

**損害確認・契約先の案内を踏まえた後に、修理内容と費用を検討**します。

## 7. 応急処置が必要でも、自分で危険な高所作業をしない

屋根の破損等で雨が入り続ける場合、応急処置が必要になることがあります。ただし、ブルーシートを掛けるため自分で屋根へ上がる等の危険な作業は避けます。

専門業者へ依頼した場合は、作業内容、写真、領収書等を残し、費用の扱いを契約先へ確認します。

## 8. 小さな被害でも「後で分かる損傷」に備えて記録する

雨どいの一部破損や外壁の小さな損傷でも、後から雨漏り等が判明する場合があります。安全な範囲で写真と気付いた日時を残します。

一方、請求期限を気にして危険な現場確認や高額契約を急ぐ必要はありません。**安全確保 → 事故連絡 → 必要資料の確認 → 修理**の順を崩さないことが重要です。

## 台風シーズン前の確認

1. 風災補償があるか
2. 建物・家財のどちらを契約しているか
3. 水災補償も必要な地域か
4. 免責・自己負担がいくらか
5. 保険会社・代理店の連絡先が分かるか
6. 以前から分かっている住宅の傷みを放置していないか

## まとめ

台風の風災を確認する時は、**「台風だったから火災保険」ではなく、何が原因で、何が壊れ、どの契約があるか**を順に見ます。

被害後は、屋根等へ上がらず安全を確保し、記録、契約確認、保険会社への連絡を行ってから修理を検討します。保険手続きと住宅の安全確保を混同しないことが重要です。
