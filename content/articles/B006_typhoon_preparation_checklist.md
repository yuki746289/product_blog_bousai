# 台風が来る前に何をする？家庭の事前チェック

台風対策で重要なのは、**風や雨が強くなる前に、外で行う作業と避難準備を終えること**です。台風は進路や接近時刻の予報を確認できるため、地震などと比べて事前に準備できる時間があります。その時間を「直前の買い物」に使うのではなく、危険になる前に必要な作業を終えるために使います。

この記事では、**①地域の危険を確認する → ②準備期限を決める → ③屋外・窓を片付ける → ④停電・断水へ備える → ⑤車と避難を決める → ⑥接近中は外へ出ない**の順で整理します。

## 結論：台風対策は「接近前・風雨が強まる前・接近中」の3段階で考える

| 時期 | 主に行うこと | この段階の目的 |
|---|---|---|
| 進路が気になり始めた段階 | ハザードマップ、避難先、家族予定、備蓄を確認 | 自宅で何が危険になるかを知る |
| 風雨が強まる前 | 屋外片付け、窓・雨戸、充電、車の移動判断 | 外へ出る必要がある作業を終える |
| 接近中 | 外へ出ず、最新情報を確認し安全確保 | 新しい作業を増やさず身を守る |

この3段階のうち、最も重要なのは**「外でしかできない作業を、いつまでに終えるか」**を前もって決めることです。

## 1. まず台風の進路ではなく「自分の地域で何が危険か」を確認する

台風の中心位置や進路予報だけでは、家庭の行動は決められません。同じ台風でも、山間部では土砂災害、河川沿いでは氾濫、沿岸部では高潮、都市部では内水氾濫など、注意する災害が異なります。

| 確認する情報 | 何を見るか |
|---|---|
| 気象庁の台風情報 | 進路、接近時期、勢力等 |
| 暴風・大雨・高潮等の警報・注意報 | 自分の地域で高まっている危険 |
| キキクル | 土砂・浸水等の危険度分布 |
| 自治体の避難情報 | 高齢者等避難・避難指示等の地域情報 |
| 河川・道路情報 | 氾濫・通行止め・冠水等 |
| ハザードマップ | 自宅・避難先・経路が何の災害に弱いか |

2026年5月29日から防災気象情報の体系が見直されているため、SNSの古い画像や過去の記事ではなく、**現在の気象庁・自治体情報を優先**します。

沿岸部では、潮位上昇より先に暴風で移動できなくなる場合があります。高潮の避難タイミングは[高潮はいつ避難する？](article_b043.html)で整理しています。

## 2. 家の外は「飛ぶ物」と「水の通り道」を先に片付ける

外で行う作業は、風雨が強くなってから始めないことが前提です。

### 飛ばされやすい物

| 例 | すること | 理由 |
|---|---|---|
| 植木鉢・ベランダの小物 | 屋内へ移す、安定した場所へ置く | 強風で飛散・転倒するのを防ぐ |
| 物干し竿・ハンガー | 外して屋内へ入れる | 長い物・軽い物が飛来物になるのを防ぐ |
| 清掃用品・軽い収納ボックス | 屋内へ移す | 普段は動かない物でも強風で移動するため |
| 自転車 | 倒れにくい場所へ移動・固定を検討 | 転倒・移動して周囲をふさぐのを防ぐ |

### 水の通り道

| 確認場所 | 何を見るか |
|---|---|
| 側溝 | 落ち葉・ごみ等が排水を妨げていないか |
| 排水口 | 詰まりや物の置き方で水をせき止めていないか |
| ベランダ排水 | 泥・落ち葉等がたまっていないか |
| 雨どい周辺 | 地上から安全に確認できる範囲で異常がないか |

屋根や高所へ上がって確認する作業を台風前の標準行動にはしません。**安全にできる範囲を早めに終え、風雨が強まったら中止**します。

## 3. 窓・雨戸は「割れない保証」ではなく被害を減らす準備として考える

窓や雨戸は閉め、鍵がかかるか確認します。雨戸やシャッターがある住宅では、正常に動くかを平常時から確認しておきます。

| 窓まわりで行うこと | 目的 |
|---|---|
| カーテン・ブラインドを閉める | 万一破損した時の室内への飛散を抑える補助にする |
| 割れ物・倒れやすい家具を窓から離す | 窓破損時の二次被害を減らす |
| 窓際で寝ない | 飛来物・ガラス破損から距離を取る |
| 雨戸・シャッターを確認する | 使える設備を接近前に確実に閉める |

テープ等を貼れば窓が割れなくなると断定できるものではありません。窓ガラス・雨戸・養生テープ・飛散防止の違いは[台風の窓ガラス対策](article_b046.html)で詳しく整理しています。

## 4. 停電への備えは「照明・情報・連絡・充電」に分ける

台風前の停電対策は、品名ではなく役割で確認すると不足が分かりやすくなります。

| 役割 | 備えるものの例 | なぜ必要か |
|---|---|---|
| 照明 | 懐中電灯、ヘッドライト、予備電池 | 停電直後の移動・作業を安全にする |
| 情報 | 携帯ラジオ、スマートフォン | 台風・停電・避難情報を確認する |
| 連絡 | スマートフォン、家族の連絡先メモ | 家族が別々の場所にいる場合に備える |
| 充電 | モバイルバッテリー、必要なケーブル | 情報・連絡手段を使い続ける |

スマートフォンやモバイルバッテリーは、**停電してからではなく接近前に充電**します。ろうそく等の裸火を停電時の基本照明にはせず、電池式・充電式照明を基本に考えます。

詳しい停電対策は[停電に備えて準備しておきたいもの](article_b004.html)、商品例は[ライト・ラジオ](/goods/light-information.html)と[モバイルバッテリー・電源](/goods/power-charging.html)で確認できます。

## 5. 断水・物流停止も想定し、生活用品を前倒しで確認する

台風で自宅が直接被災しなくても、停電、断水、店舗の休業、交通の乱れ等が起こる可能性があります。

| 確認するもの | 主な役割 | 関連情報 |
|---|---|---|
| 飲料水 | 断水・物流停止時の水分確保 | [商品例](/goods/water-food.html) |
| すぐ食べられる食品 | 調理・買い物が難しい時の食事 | [商品例](/goods/water-food.html) |
| 携帯トイレ | 断水・排水制限時の排泄 | [使い方](article_b003.html) / [商品例](/goods/toilet-hygiene.html) |
| 衛生用品 | 水が使いにくい時の衛生維持 | [商品例](/goods/toilet-hygiene.html) |
| 常用薬 | 治療の継続 | 本人の必要量・保管条件を個別に確認する |
| 乳幼児・高齢者等の個別用品 | 一般備蓄で代替しにくい物を補う | 家族条件に合わせる |

接近直前に買い物へ集中すると、混雑や品切れの中で外出することになります。普段から一定量を備蓄し、**台風のたびにゼロから買い集めない**ようにします。

## 6. 車は「移動させるか」より先に駐車場所のリスクを知る

大雨が予想される場合は、地下・半地下駐車場、河川沿い、周囲より低い土地などの浸水リスクを確認します。

安全な場所へ車を移動させる場合も、風雨が強くなってから取りに行くのではなく、**安全に移動できる段階で判断**します。避難開始が遅れた後に「車だけ移動する」ことを優先せず、冠水した道路やアンダーパスには進入しません。

## 7. 避難先・経路・家族の動きを「全員がそろう前提」にしない

台風が近づく前に、次を決めます。

| 決めること | 理由 |
|---|---|
| 避難先 | どこへ移動するかで迷わないため |
| 避難経路 | 川・海・低い道路等を避けるため |
| 家族の連絡方法 | 別々の場所で被災する前提を持つため |
| 高齢者・乳幼児・持病のある人等の支援 | 移動に時間がかかる人を早く動かすため |
| ペットの避難 | 同行避難等の地域ルールと必要品を確認するため |
| 家族が外出中の場合の行動 | 危険な帰宅を避けるため |

**「全員が家にそろってから避難する」ことを避難開始の条件にしない**ようにします。勤務先や学校が安全なら、その場で待機する方が安全な場合もあります。子どもの学校・施設の引き渡しルールや、自宅以外の集合候補も確認します。

## 8. 接近前は家事・生活面も前倒しする

外作業だけでなく、風雨が強まった後に外出する理由を減らします。

| 前倒しすること | 目的 |
|---|---|
| 必要な薬を手元にそろえる | 接近中に受け取りへ出ないため |
| スマートフォン等を充電する | 停電前に情報・連絡手段を確保するため |
| 水・食品・携帯トイレを使いやすい場所へまとめる | 停電・断水時に探さないため |
| 洗濯物・ベランダ用品を屋内へ入れる | 飛散物を減らすため |
| ライトの場所を家族で共有する | 停電直後に探さないため |
| 防災バッグを持ち出しやすい場所へ置く | 避難開始を遅らせないため |

夜間に危険が高まる予報なら、日没前を一つの区切りとして、屋外作業や避難経路の確認を終えるよう前倒しします。

## 9. 接近中は「新しい作業を始めない」

接近中は準備の時間ではなく、安全確保の時間です。

| 避けたい行動 | 理由 |
|---|---|
| 川・海・用水路を見に行く | 増水・高潮・高波等に近づくため |
| 屋根・雨どいを見に外へ出る | 強風・転倒・落下の危険があるため |
| 強風の中で植木鉢等を片付ける | 飛来物や転倒の危険が高まるため |
| 冠水した道路へ進入する | 水深・路面・流れが分からないため |
| 地下・低い場所へ車を取りに行く | 浸水箇所へ自ら入ることになるため |
| 停電してからライト・電池を探す | 暗所で移動・作業する危険が増えるため |

**接近前は準備、接近中は安全確保**と役割を分けます。

## まとめ

台風対策は、**接近してから行う作業をできるだけ減らすこと**が重要です。

まず地域で何が危険かを確認し、外作業・窓・停電・断水・車・避難を安全に動けるうちに終えます。夜間接近ならさらに前倒しし、接近中は新しい準備を始めず、最新の公的情報を確認しながら安全確保を優先してください。
