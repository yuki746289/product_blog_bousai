# 大雨・水害にどう備える？まず知っておきたい基本

大雨・水害への備えは、雨が強くなってから始めるのではありません。平常時にまず**自宅では何の水害が起こり得るか**を調べ、その結果から**どこへ避難するか、何の情報を見るか、家の内外で何を準備するか**を決めておくことが基本です。

同じ「大雨」でも、河川の氾濫、内水氾濫、土砂災害、高潮では危険になる場所も避難方法も違います。この記事では、**①自宅のリスク → ②水害の種類 → ③見る情報 → ④避難方法・経路 → ⑤家の外と中の準備 → ⑥家族条件 → ⑦避ける行動**の順で整理します。

## 結論：水害対策は「自宅の危険を知る→情報を決める→安全なうちに動く」

最初に押さえたいのは次の3点です。

1. **自宅と生活圏の水害リスクを調べる** — 洪水だけでなく内水・土砂・高潮も確認する
2. **何の情報を見て避難を判断するか決める** — 気象庁・自治体・河川情報等を組み合わせる
3. **安全に移動できるうちに行動する** — 雨・風が強くなってから屋外作業や避難準備を始めない

この3点を決めた後で、避難経路、家の外の片付け、停電・断水への備蓄、家族ごとの支援を具体化します。

## 1. まず「自宅が何に弱いか」を確認する

最初に確認したいのは、単に「川が近いか」ではありません。ハザードマップで、自宅・勤務先・学校・普段使う道路について次を確認します。

| 確認すること | 何が分かるか |
|---|---|
| 洪水浸水想定区域に入っているか | 河川氾濫による浸水の想定 |
| 想定浸水深 | 自宅や避難経路でどの程度の浸水が想定されるか |
| 内水氾濫のリスク | 排水能力を超えた雨で市街地等が浸水する可能性 |
| 土砂災害警戒区域等 | 崖崩れ・土石流等を優先して確認すべき場所 |
| 高潮の想定 | 沿岸部・河口等で海面上昇による浸水が想定されるか |
| 地下・半地下、アンダーパス、用水路、崖等 | 避難経路で水や土砂が集まりやすい場所 |

国土地理院・国土交通省のハザードマップポータルで広域的に確認したうえで、**最終的には市区町村が公表する最新のハザードマップも確認**します。

ハザードマップに色が付いていない場所でも「絶対に安全」という意味ではありません。想定条件を超える雨や、地図で表現しきれない局地的な浸水が起きる可能性もあるため、地形や過去の浸水履歴も参考にします。

## 2. 「水害」は洪水だけではない

ハザードマップを見る時は、「水害」という一語でまとめず、何の災害なのかを分けます。大雨では複数の災害が同時に起こることもあります。

| リスク | 主な特徴 | 特に確認したい場所 |
|---|---|---|
| 河川の氾濫 | 越水・破堤等で広い範囲が浸水 | 河川周辺、低地 |
| 内水氾濫・浸水害 | 排水能力を超えて道路や住宅地に水がたまる | 市街地、低い道路、地下空間 |
| 土砂災害 | 雨が地中にたまり崖崩れ等の危険が高まる | 崖、急傾斜地、渓流付近 |
| 高潮 | 台風等で海面が上昇し沿岸部が浸水 | 海岸、河口、低地 |

**「川から離れているから大丈夫」とは限りません。** 都市部では側溝や下水の排水が追いつかず、短時間で道路が冠水することがあります。

## 3. 次に「何の情報を見るか」を決める

自宅で注意する災害が分かったら、危険が高まった時に見る情報を決めます。

2026年5月29日から、河川氾濫、大雨、土砂災害、高潮等の防災気象情報は、警戒レベルとの対応がより分かりやすい体系になりました。古い記事や保存画像だけに頼らず、気象庁・自治体の現行情報を確認します。

自治体から**警戒レベル3 高齢者等避難**や**警戒レベル4 避難指示**が発令された場合は、その情報に従って行動します。また、避難情報がまだ出ていなくても、レベル3・4相当の防災気象情報が発表された場合は、キキクルや河川水位情報等を確認して自ら避難を判断することが求められています。

| 情報 | 何を見るか |
|---|---|
| 気象庁の警報・キキクル | 大雨・土砂・浸水等の危険度 |
| 自治体の避難情報 | 高齢者等避難・避難指示等、自分の地域の行動情報 |
| 河川水位・洪水予報 | 対象河川の水位や氾濫の危険度 |
| 道路情報 | 通行止め、冠水等で避難経路が使えるか |
| ハザードマップ | 現在地・避難先・経路にどんな危険があるか |

キキクルでは、自宅だけでなく**これから通る避難経路の危険度**も見ると判断しやすくなります。洪水キキクル・指定河川洪水予報を使った避難判断は、[洪水キキクル・河川氾濫はいつ避難する？](article_b042.html)で詳しく整理しています。

スマートフォンの通知だけに依存せず、停電や通信障害も考えてラジオ等の予備手段も用意しておくと、情報経路を一つにしない備えになります。

## 4. 情報を見たら「どこへ、どう避難するか」を判断する

避難は「必ず学校へ行くこと」ではありません。災害から生命・身体を守るために、現在地の危険を避ける行動です。

気象庁は内閣府のガイドラインに沿って、主に次の考え方を示しています。

| 避難方法 | どんな行動か | 注意点 |
|---|---|---|
| 立退き避難 | 指定緊急避難場所、安全な親族・知人宅等へ移動する | 移動中の経路が安全なうちに行う |
| 屋内安全確保 | 条件を満たす場合、自宅や頑丈な建物の上階等で安全を確保する | 想定浸水深・建物構造・土砂災害リスク等を事前確認する |
| 緊急安全確保 | すでに移動が危険な場合、その時点で少しでも安全な場所へ移る | 本来はこの段階になる前に避難判断する |

重要なのは、**その災害と現在地に対して安全な場所を平常時に考えておくこと**です。

## 5. 避難経路は「普段の最短ルート」ではなく危険箇所で選ぶ

避難場所が安全でも、そこまでの経路に危険があれば移動できません。

| 避けたい場所の例 | なぜ危険か |
|---|---|
| 川沿い・用水路沿い | 増水や流れが近く、夜間・冠水時に境界が見えにくい |
| 崖の近く | 大雨で土砂災害の危険が高まる場合がある |
| 冠水しやすい道路 | 水深や路面状況が分かりにくくなる |
| アンダーパス・地下道 | 周囲より低く、水が集まりやすい |
| 増水時に渡れなくなる橋 | 河川状況によって経路が遮断される可能性がある |

昼間は見える側溝や段差も、夜間や冠水時には見えなくなります。**昼と夜の両方を想定して経路を確認**し、可能なら第2候補も決めます。

## 6. 家の外の準備は雨・風が強くなる前に終える

家の外で行う作業は、危険が高まってから始めないことが重要です。

| 平常時・早い段階で行うこと | 目的 |
|---|---|
| 側溝・排水口を掃除する | 排水を妨げるごみ等を減らす |
| 飛ばされそうな物を固定・屋内へ移す | 強風による飛散を防ぐ |
| 窓・雨戸を確認する | 破損や飛来物への備えを確認する |
| 車・自転車の置き場所を確認する | 低い場所・浸水しやすい場所に置いたままにしない |

雨が激しくなってから側溝を掃除したり、屋根や雨どいを見に行ったりするのは危険です。**外作業を中止する段階を遅らせない**ことを優先します。

## 7. 家の中では「停電・断水・トイレ停止」まで一緒に備える

大雨では直接浸水しなくても、停電や断水、物流の遅れが起こることがあります。自宅備蓄と避難時の持ち出し品を分け、役割ごとに確認します。

| 備えるもの | 主な役割 | 詳細 |
|---|---|---|
| 飲料水・食品 | 断水・物流停止時の生活維持 | [商品例](/goods/water-food.html) |
| 携帯トイレ | 断水・排水制限時の排泄 | [使い方・必要数](article_b003.html) / [商品例](/goods/toilet-hygiene.html) |
| 懐中電灯・ヘッドライト | 停電時の安全な移動 | [商品例](/goods/light-information.html) |
| ラジオ・予備電池 | スマホ以外の情報取得 | [商品例](/goods/light-information.html) |
| モバイルバッテリー | スマートフォン等の充電 | [商品例](/goods/power-charging.html) |
| 常用薬・お薬手帳等 | 治療継続・医療情報の確認 | 本人に必要な量・保管方法を個別確認する |
| 防災リュック | 避難時の持ち出し | [中身と重さの考え方](article_b002.html) |

**重い自宅備蓄を全部持ち出そうとしない**よう、あらかじめ役割を分けます。

## 8. 家族によって「避難開始の余裕」が違う

高齢者、乳幼児、障害のある人、持病のある人、ペットがいる家庭などでは、準備や移動に時間がかかる場合があります。

| 先に決めること | 理由 |
|---|---|
| 誰が誰を支援するか | 避難開始時に役割で迷わないため |
| 薬や補助用品を誰が持つか | 本人に代替しにくい物を忘れないため |
| 車を使わない場合の移動方法 | 道路冠水・渋滞等で車を使えない場合に備えるため |
| 家族が別々の場所にいる場合の連絡方法 | 一度自宅へ戻る危険な行動を避けるため |

避難は、危険が迫ってから全員同じタイミングで始める必要はありません。**移動や準備に時間がかかる人ほど、より早い段階から準備・避難を始める**ことを考えます。

## 9. 家族が外出中なら「一度自宅へ戻る」を固定ルールにしない

大雨は、家族全員が自宅にいる時に起きるとは限りません。勤務先、学校、買い物先などで危険度が上がった場合に、「必ず自宅へ戻る」と決めていると、かえって危険な道路や河川を横切ることがあります。

平常時に次を決めます。

| 確認すること | 目的 |
|---|---|
| 外出先が安全ならその場で待機できるか | 危険な帰宅移動を避けるため |
| 帰宅経路に川・アンダーパス・土砂リスクがないか | 普段のルートが使えない場合を想定するため |
| 家族が別々に避難した場合の連絡方法 | 互いを探しに戻る行動を減らすため |
| 電話がつながらない場合の代替手段 | 通信混雑に備えるため |
| 自宅以外の集合候補 | 自宅周辺が危険な場合に備えるため |

重要なのは「全員が一度自宅へ集合すること」ではなく、**それぞれが現在地で安全を確保し、無理な移動をしないこと**です。

## 10. 大雨時に避けたい行動

最後に、これまでの流れを逆にしてしまう行動を確認します。

| 避けたい行動 | 理由 |
|---|---|
| 冠水した道路へ徒歩・車で安易に進入する | 路面の陥没・側溝・水流等が見えなくなるため |
| 川や用水路、海を見に行く | 増水・高潮等の危険に近づくため |
| 雨や風が強くなってから屋外作業を始める | 作業中に危険が急上昇するため |
| 地下・半地下等にとどまる | 水が集まりやすく、避難が難しくなる場合があるため |
| 避難情報が出るまで何もしない | 移動に時間がかかる家庭では行動開始が遅れるため |
| 「前回大丈夫だったから今回も大丈夫」と判断する | 雨量・経路・河川状況等が毎回異なるため |

## 大雨・水害対策で個人ができることは？

個人で今日からできる対策は、まず次の5つです。雨が強くなってから新しく始めるのではなく、平常時か予報の早い段階で確認します。

1. 自宅のハザードマップを開き、注意する水害を1つ以上確認する
2. その災害に対応する避難先を最低1つ決める
3. 避難経路に川・低い道路・崖等の危険箇所がないか確認する
4. 防災リュックと自宅備蓄を分け、足りない物を確認する
5. 気象庁・自治体の情報を受け取れる状態にする

## まとめ

大雨・水害対策は、**自宅のリスクを知る → 見る情報を決める → 避難先と経路を決める → 家の内外を準備する → 家族条件を上乗せする**という順で考えると整理しやすくなります。

水害は洪水だけではなく、内水氾濫、土砂災害、高潮等もあります。平常時に自宅と避難経路を確認し、雨が強まった時には**安全に移動できるうちに行動する**ことを基本にしてください。
