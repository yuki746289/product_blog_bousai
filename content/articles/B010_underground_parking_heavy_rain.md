# 地下駐車場・低い場所に車を置いている場合の大雨対策

地下・半地下駐車場や周囲より低い駐車場所では、道路が冠水してから車を移動しようとすると危険です。重要なのは、**車を守ることより先に「移動するならいつまでに終えるか」「いつから取りに戻らないか」を決めておくこと**です。

この記事では、**駐車場所のリスク確認 → 管理側のルール → 移動先と期限 → 中止条件 → 移動できなかった場合 → 浸水後の対応**の順で整理します。

## 結論：車を移す判断には「締切」を作る

大雨前は、次の4点を平常時から決めます。

1. **駐車場所と出入口の浸水リスク**
2. **安全な代替駐車場所**
3. **移動を終えるタイミング**
4. **道路冠水・避難情報等が出たら車を取りに戻らない中止条件**

「車が心配だから最後に見に行く」ではなく、**安全な時間を過ぎたら車両保全を諦め、人の安全へ切り替える**ことを家庭のルールにします。

## 1. 最初に「駐車場所」と「出入口」を見る

地下駐車場は車室が低いだけでなく、出入口のスロープが水の流入口になる場合があります。周辺道路が先に冠水すると、車室がまだ浸水していなくても外へ出られなくなる可能性があります。

| 確認すること | 何を見るか |
|---|---|
| 洪水・内水・高潮のハザード | 駐車場周辺にどんな浸水リスクがあるか |
| 出入口の高さ | 周囲の道路より低く、水が集まりやすくないか |
| 過去の浸水履歴 | 同じ施設・周辺道路で浸水したことがないか |
| 止水板・防水扉等 | 設備の有無と、誰が操作するか |
| 機械式駐車場 | 停電・浸水時に装置がどうなるか |

ハザードマップに色が付いていないことだけで安全と判断せず、施設内の排水能力や過去の浸水、管理側の対策も確認します。

## 2. 月極・商業施設・マンションで「誰に確認するか」が違う

駐車場の管理主体によって、大雨時の案内や設備操作の担当が違います。

| 駐車場所 | 主な確認先 | 平常時に聞くこと |
|---|---|---|
| 月極駐車場 | 管理会社・所有者 | 大雨時の連絡、車両移動の案内があるか |
| 商業施設 | 施設管理者 | 営業時間外・閉鎖時の対応、退避案内 |
| マンション | 管理会社・管理組合 | 地下設備・止水設備・機械式駐車場の運用 |
| 自宅地下・半地下 | 建築・設備の管理先 | 止水設備、排水設備、改修の相談先 |

止水板や土のうを共用部へ個人判断で設置せず、**管理規約・施設の運用に従う**ことを基本にします。

## 3. 車を移すなら「どこへ・いつまでに・どの道で」を決める

移動先が決まっていないと、雨の中で安全な駐車場所を探し回ることになります。平常時に候補を1〜2か所決め、営業時間や利用条件も確認します。

| 決める項目 | 確認内容 |
|---|---|
| 移動先 | 高台・浸水リスクの低い駐車場等 |
| 移動期限 | 雨風が強くなる前、安全に走れる時間帯まで |
| ルート | 河川沿い、アンダーパス、低地を避ける |
| 中止条件 | 冠水、強風、避難情報、夜間の視界不良等 |

## 4. 「車を移すための外出」で避難を遅らせない

大雨時は、家族の避難や住宅の安全確保が車両保全より優先です。

次のような状況になったら、予定していた車移動を中止します。

- 道路冠水が始まった
- 自治体から避難情報が出た
- 強風や大雨で運転が危険になった
- 地下・半地下へ水が流入している
- 施設から退避・立入制限の案内が出た
- 夜間で道路状況を確認しにくい

**車だけを救うために地下・低地へ戻らない**ことを最優先にします。

## 5. 止水板・土のうは「車を取りに行ける時間を保証する設備」ではない

止水板や土のう等は、浅い浸水の初期段階で被害を減らす補助になる場合がありますが、深い浸水や強い流れを止められる保証はありません。

管理施設では、誰が、どの情報をきっかけに、どの出入口へ設置するかを事前に決めます。利用者は「止水板があるからまだ取りに行ける」と判断せず、管理者の案内と道路状況を優先します。

## 6. 機械式駐車場は非常操作を自己判断しない

機械式駐車場は停電・浸水で装置が停止する可能性があります。大雨予報が出てから初めて操作方法を調べるのではなく、管理会社やメーカーの非常時運用を平常時に確認します。

非常操作を一般利用者が行ってよいとは限りません。**連絡先と退避方法を知っておくこと**を利用者側の準備にします。

## 7. 移動できなかったら「雨が弱まった＝戻ってよい」と考えない

車を残した場合、雨が弱くなっただけで地下へ戻りません。施設管理者が立入を制限している、排水設備が停止している、停電で照明がないなど、車両以外の危険もあります。

安全確認後に立ち入れるようになったら、車両の状態を自分で試すより、**周辺状況を記録し、管理者・保険会社・ロードサービス・販売店等へ連絡**します。

## 8. 浸水した車は始動せず、EV・PHEV・HVも自己点検しない

一度浸水した車は、外見上問題がなくても電装部や機械部分に水が残っている可能性があります。**「動くかだけ確認する」目的で始動しません。**

EV・PHEV・HVは高電圧系統を持つため、バッテリーや配線を自分で触らず、販売店・整備事業者等へ相談します。

車両が水没した場合の脱出・水没後対応は[車が冠水・水没しそうなとき](article_b008.html)で確認できます。

## 9. 被害後の記録・保険確認は安全確保後に行う

安全に立ち入れるようになった後、次を記録すると後の説明をしやすくなります。

| 記録すること | 目的 |
|---|---|
| 車両の位置 | どこで被害を受けたか整理する |
| 浸水痕・周囲の水位跡 | 浸水状況を説明する |
| 車内外の損傷 | 修理・保険確認に使う |
| 管理施設の案内 | 立入制限や退避指示等の経緯を残す |
| レッカー・移動先 | 被害後の車両所在を追えるようにする |

台風・洪水・高潮による水没は車両保険で補償対象となる契約がありますが、契約条件は異なります。[水没した車は車両保険の対象？](article_b011.html)で確認してください。

## 10. 車内の重要品は平常時から減らしておく

車検証類、仕事道具、電子機器等を長期間車内に置いていると、車を動かせなかった場合に同時に被害を受けます。

大雨が強まってから荷物を取りに戻るのではなく、**重要書類や高価な電子機器を常時車内へ置かない**など、車両移動以外で減らせる被害を先に減らします。

## 大雨予報が出た日のチェック

1. ハザードマップ・施設案内で駐車場の浸水リスクを確認する
2. 代替駐車場所とルートを確認する
3. 移動するなら風雨が強くなる前に終える
4. 冠水・避難情報等が出たら車移動を中止する
5. 移動できなかった場合は、管理側の安全確認まで戻らない

## まとめ：車を救う判断には「終わり」を決める

地下・低地の車対策で重要なのは、**いつ移すかと同じくらい、いつから移さないかを決めること**です。

安全な段階なら車を移動できますが、道路や地下空間の危険が高まった後は、人の避難を優先します。移動できなかった場合も、雨が弱まっただけで戻らず、施設の安全確認後に専門家へ連絡してください。
