# 断水時の携帯トイレ｜使い方・処分・衛生と必要数の考え方

断水や大きな地震の後は、便器そのものが無事でも、水や排水設備の状態によって水洗トイレを流せないことがあります。そこで家庭で備えておきたいのが、**便器に袋を取り付けて排泄物を凝固・吸収し、袋ごと処理する「携帯トイレ」**です。

初めて備える場合は、「何回分買うか」だけ先に考えると、実際の使い方や使用後の袋の置き場所で困ります。この記事では、**携帯トイレとは何か → 使い方 → 必要数 → 衛生 → 一時保管・処分 → 保管と見直し**の順で説明します。

## 結論：携帯トイレは「使える・衛生を保てる・処分まで考える」で備える

備える時は、次の5点を一つのセットとして確認します。

1. **自宅の便器で使うタイプか、便座ごと必要か**を確認する
2. 家族全員が**袋のセットから密閉まで一度試す**
3. **人数×1日の回数×想定日数**で必要数を概算する
4. 手指衛生・防臭・夜間照明など**周辺用品も一緒に用意する**
5. 使用後の袋を**どこに置き、自治体のルールでどう出すか**を確認する

内閣府の防災広報では、成人の平均排泄回数を1日5回として、1週間なら**1人35回分**を備蓄目安として紹介しています。ただし、35回分を買うだけでは実用的な備えにはなりません。

## 1. まず「携帯トイレ」と「簡易トイレ」の違いを知る

名前が似ていますが、家庭で使う時の形が違います。最初にここを理解すると、商品を選ぶ時に「袋だけでよいのか、便座も必要なのか」を判断しやすくなります。

| 種類 | どんなものか | 向いている場面 |
|---|---|---|
| **携帯トイレ** | 既存の洋式便器などに便袋を取り付け、凝固剤・吸水材等で排泄物を処理するタイプ | 自宅の便器や座れる設備が使える場合 |
| **簡易トイレ** | 箱・便座などを組み立て、そこへ便袋等をセットして使うタイプ | 既存便器を使えない、便座そのものが必要な場合 |

つまり、**便器が使える家庭なら携帯トイレの便袋タイプが中心、便座が使えない状況まで想定するなら簡易便座も検討**します。商品名だけで選ばず、自宅でどの形で使うのかを先に決めます。

→ [携帯トイレ・衛生用品の商品例を確認する](/goods/toilet-hygiene.html)

## 2. 水が出ても、すぐ水洗トイレを流してよいとは限らない

携帯トイレを使う場面は「断水した時」だけではありません。地震や水害では、下水管や宅内配管の損傷、集合住宅の排水制限などで水洗トイレを流せない場合があります。

> **流してよいか分からないとき**
>
> 水が出るからといって自己判断で流さず、管理会社・自治体・上下水道事業者などの案内を確認します。排水先が壊れている場合、逆流や漏水につながるおそれがあります。

特に集合住宅では、自分の便器が無事でも共用配管側に問題があることがあります。**「便器が壊れていない＝通常どおり流せる」とは考えない**ことが重要です。

## 3. 携帯トイレの基本的な使い方は4段階

製品によって袋の枚数や凝固剤を入れる順序が違うため、最終的には製品説明に従います。そのうえで、家庭で事前に確認する流れは次の4段階です。

| 手順 | すること | 事前に確認する点 |
|---|---|---|
| 1. 袋をセット | 便器や簡易便座へ便袋を取り付ける | 袋の大きさ、便座への固定方法 |
| 2. 排泄・凝固 | 製品指定の方法で使用し、凝固剤・吸水材を使う | 凝固剤を入れる順序、1回分の量 |
| 3. 袋を密閉 | 使用済み便袋の口を指定方法で閉じる | 臭い・液漏れを抑えられる閉じ方 |
| 4. 一時保管 | 回収まで決めた場所へ置く | 高温・雨水・子ども・ペット・臭気への対策 |

災害が起きてから初めて説明書を読むと、暗所や混乱の中で「袋が便器に合わない」「凝固剤の順序が分からない」となりやすくなります。**平常時に家族で1回試す**と、必要な周辺用品まで分かります。

## 4. 必要数は「人数×1日の回数×想定日数」で考える

使い方が分かったら、次に数量を計算します。内閣府の防災広報では、成人の平均排泄回数を1日5回として、**1人35回分/週**を備蓄目安として紹介しています。政府広報では5〜6回×人数×7日分という整理もあります。

| 人数 | 3日分（5回/日） | 7日分（5回/日） |
| --- | ---: | ---: |
| 1人 | 15回 | 35回 |
| 2人 | 30回 | 70回 |
| 4人 | 60回 | 140回 |

計算式は次のとおりです。

**必要回数の概算 = 家族人数 × 1日あたりの回数 × 想定日数**

この数字は「これだけあれば必ず足りる」という保証ではありません。体調、在宅時間、子ども・高齢者の状況、避難先のトイレ状況で必要数は変わります。また、袋を破いた、セットに失敗した等も考えられるため、保管場所に余裕があれば予備も検討します。

## 5. 大便・凝固剤・臭いは「製品仕様」と「密閉」を分けて確認する

### 大便に使えるかは製品ごとに確認する

携帯トイレには複数の方式があります。**尿だけを想定した製品か、大便を含む排泄に使えるか**は、パッケージやメーカー説明で確認します。

家族で備える場合は、袋の大きさ、便器への固定方法、凝固剤を入れる順序まで一度試しておくと、実際に使った後で「袋が小さい」「処理方法が分からない」となるのを避けやすくなります。

### 凝固剤が固まらない時は、追加投入より説明書を先に見る

経済産業省の2026年の調査では、市販の携帯・簡易トイレで、凝固剤の量、吸水量、凝固までの時間、消臭性能、保存期間などの表示・仕様にばらつきがあることが示されています。そのため、**「何分で必ず固まる」「1袋で必ず何mL固まる」と一律には言えません。**

固まりにくい場合は、自己判断で別製品の凝固剤を混ぜる前に、次を確認します。

| 確認すること | 理由 |
|---|---|
| 凝固剤を入れる順序 | 製品によって使用手順が違うため |
| 指定された1回分の量 | 少なすぎる・使い方が違う可能性を確認するため |
| 袋・凝固剤の保管状態 | 湿気・高温等で劣化していないか見るため |
| 製品の対象用途 | 想定外の使い方になっていないか確認するため |

製品説明に追加投入の指示がある場合は、その方法に従います。

### 臭い対策は「固める」だけで終わらない

凝固剤に消臭・抗菌機能をうたう製品はありますが、仕様は製品ごとに異なります。**凝固したから臭いが完全になくなるとは考えず、使用後の袋を確実に閉じ、必要に応じて防臭・密閉用の袋を組み合わせる**方が現実的です。

## 6. 衛生用品は「携帯トイレと一緒に使う物」として備える

携帯トイレだけを箱で置いても、手が洗えない、夜に見えない、使用済み袋を二重にできない、といった問題が残ります。

| 一緒に備えるもの | 何に使うか |
|---|---|
| トイレットペーパー | 排泄後の清拭 |
| ウェットティッシュ・体拭き | 断水時の手・体の清拭 |
| 手指消毒用品 | 手洗いが難しい時の手指衛生 |
| 使い捨て手袋 | 使用後の袋等を扱う時の衛生補助 |
| 防臭・密閉用の袋 | 使用済み便袋の臭気・液漏れ対策 |
| 夜間用ライト | 停電時に袋のセットや処理を行うため |
| 生理用品・使用済み用品用の袋等 | 生理時の衛生と廃棄物管理 |

政府広報オンラインでは、女性向けの災害用品として生理用品、清浄綿、携帯トイレ、携帯用ビデなどを挙げています。必要な物は人によって異なるため、本人が普段使っている物を基準にします。

トイレを我慢するために水分摂取を減らすのは避けます。災害時のトイレ問題は衛生だけでなく、脱水や体調悪化にもつながるため、**使える状態を維持すること自体が生活継続の備え**です。

→ [携帯トイレ・衛生用品の商品例を見る](/goods/toilet-hygiene.html)

## 7. 使用後の袋は「自治体のルール確認」と「一時保管場所」をセットで決める

使用後の処理方法やごみ区分は自治体によって異なります。平常時に自治体の災害ごみ・し尿処理の案内を確認し、収集が再開するまで一時保管できる場所を考えます。

| 一時保管場所で確認すること | 理由 |
|---|---|
| 直射日光・高温を避けられるか | 臭気や袋の劣化を抑えるため |
| 生活空間と距離を取れるか | 衛生・臭気の影響を減らすため |
| 雨水が入らないか | 袋や周辺を汚染しないため |
| 子ども・ペット・動物が触れないか | 袋の破損や接触を防ぐため |
| 追加の密閉袋を使えるか | 臭気・液漏れ対策を補うため |

ベランダ等に置けば必ず良いという意味ではありません。集合住宅では管理規約や共用部のルールも確認します。

## 8. 保管時は「残数・期限・袋の状態」を確認する

携帯トイレは非常時まで置きっぱなしにするのではなく、製品表示に従って保存します。経済産業省の調査では、製品保証期間や保存期間（使用期限）を仕様に含める調達例がある一方、表示内容には差があります。

家庭では、**箱に記載された保存条件・使用期限・保証期間を優先**し、凝固剤だけでなく袋や個包装の劣化も確認します。

見直しを忘れないよう、年1回などの点検をスマートフォンのカレンダーへ登録する、防災用品を入れ替える日を決める、引っ越しや家族構成の変化時に数量を再計算するなど、具体的なきっかけを設定します。

一か所に全量を置くより、トイレ近くと防災備蓄場所などに分けると、家具転倒等で一方へ近づけない場合にも対応しやすくなります。

## 9. 在宅用と持ち出し用を分ける

自宅が安全で在宅避難をする場合、トイレは毎日使うため、まとまった数量が必要になります。一方、避難所へ移動する場合でも、到着直後に十分な仮設トイレが使えるとは限りません。

そのため、**自宅には家族分のまとまった備蓄、防災リュックには避難途中・到着直後に使う少量**という分け方が現実的です。すべてを避難バッグに詰め込むと重くなり、移動しにくくなります。

家族に介助が必要な人がいる場合は、便座の高さ、立ち座りのしやすさ、夜間照明、手すり、プライバシー確保も一緒に確認します。単に「何回分あるか」だけではなく、**その人が実際に使えるか**まで確認します。

## 今日やるなら、この3つ

1. **使う形を決める** — 自宅便器に便袋を取り付ける携帯トイレでよいか、簡易便座も必要か確認する。
2. **数量を計算する** — 家族人数×5回×7日を一つの目安として概算し、現在の残数と比べる。
3. **使用後を決める** — 一時保管場所と自治体の処分案内を確認する。

そのうえで、購入・追加が必要なら[携帯トイレ・衛生用品の商品紹介](/goods/toilet-hygiene.html)で、回数・袋・凝固剤・周辺用品を比較します。

## まとめ

携帯トイレは「何回分買えばよいか」だけで考えると不十分です。

まず**携帯トイレと簡易トイレの違いを知る → 実際の使い方を試す → 必要数を計算する → 衛生用品をそろえる → 使用後の一時保管と処分を決める**、という順で備えます。

数量の計算は入口です。**使える・衛生を保てる・捨てられる**ところまで決めて、初めて実用的なトイレ備蓄になります。
