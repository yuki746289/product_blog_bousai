# 地震保険は保険会社で違う？補償・保険料が同じ点と火災保険側で違う点

結論は明確です。**法定の地震保険そのものは、同じ条件なら保険会社による補償内容・保険料の会社差は基本的にありません。** 比較するのは、セットする火災保険と周辺サービスです。

## 結論：地震保険本体をランキングするより、火災保険を同条件で比較する

地震保険は「地震保険に関する法律」に基づき、政府と損害保険会社が共同で運営する制度です。日本損害保険協会は、建物所在地・構造などの条件が同じなら、**どの保険会社で加入しても地震保険の補償内容と保険料に違いはない**と案内しています。一部、払込方法によって保険料が異なる場合があります。

したがって「A社の地震保険は補償が厚い」「B社なら地震保険だけ安い」という比較は制度の理解として適切ではありません。当サイトでは**地震保険会社ランキングではなく**、地震保険の共通部分と、セットする火災保険で比較すべき部分を分けます。**地震保険の会社ランキングは作らず**、契約全体の条件をそろえて確認します。

地震保険の基本制度は[地震保険の基本｜火災保険との違いを整理](article_b017.html)で確認できます。

## 地震保険で共通する部分：原因・対象・保険金額・損害区分

主な共通ルールは次のとおりです。

| 項目 | 共通する基本ルール |
|---|---|
| 対象原因 | 地震・噴火・これらによる津波 |
| 主な損害 | 火災、損壊、埋没、流失 |
| 保険対象 | 居住用建物、生活用家財 |
| 契約方法 | 火災保険にセットして契約 |
| 地震保険金額 | 火災保険金額の**30〜50％**の範囲 |
| 契約限度額 | 建物**5,000万円**、家財**1,000万円** |
| 損害区分 | **全損・大半損・小半損・一部損** |
| 基本支払割合 | 100％・60％・30％・5％ |

これは「どの会社でも契約額が必ず同じ」という意味ではありません。契約者が30％を選ぶか50％を選ぶか、割引条件が該当するか等で実際の契約額・保険料は変わります。**会社を比較するときは地震保険金額、割引、保険期間、払込方法をそろえる**必要があります。

また、地震保険は損害区分に応じて保険金を支払う制度で、通常の修理費をそのまま全額実費で支払う保険ではありません。「一部損が出やすい会社」を自由に商品設計する仕組みでもなく、制度上の損害認定基準は共通です。

## 保険会社で違うのは、主にセットする火災保険側

地震保険は単独契約できず、火災保険にセットします。その火災保険は各社の商品なので、契約全体では違いが生まれます。

比較対象になるのは、たとえば次の項目です。

- 水災・風災・破損汚損など火災保険の補償範囲
- 自己負担額や特約の構成
- 建物・家財の評価・契約設計
- Web、電話、代理店など申込・相談方法
- 事故連絡や契約管理の方法
- 火災保険全体の保険料と払込方法

つまり「地震保険は同じだから会社はどこでも完全に同じ」でもありません。**地震保険本体は共通でも、セットする火災保険まで含めた契約全体には会社差があります。**

火災保険を比較するときは[火災保険10社を比較｜水災・風災・補償の選び方・申込方法](article_b051.html)を参照してください。

## 「地震火災費用」は法定の地震保険とは別に確認する

火災保険には、商品によって「地震火災費用保険金」「地震火災費用特約」などが含まれる場合があります。名称に地震と入っていても、**法定の地震保険そのものではありません。**

地震火災費用は、地震等を原因とする火災について一定条件を満たした場合に定額・一定割合を支払うなど、商品ごとに条件があります。火災以外の損壊・埋没・流失まで地震保険と同じ範囲で補償するとは限らず、限度額や対象条件も確認が必要です。

したがって、**「地震火災費用が付いているから地震保険は不要」とは置き換えません。** 火災保険の特約と法定地震保険を別々に読みます。

## 「同じ条件」にそろえない見積りは比較にならない

地震保険の見積りが会社ごとに違って見える場合、まず条件差を確認します。

1. 火災保険金額が同じか
2. 地震保険金額を30〜50％のどこに設定したか
3. 建物構造・所在地が同じか
4. 耐震等級などの割引条件が同じか
5. 保険期間と**払込方法**が同じか
6. 火災保険側の補償・特約が同じか

これらが違えば「地震保険が安い会社」なのか、「前提条件が違う契約」なのかを区別できません。比較表を作るときは、地震保険部分と火災保険部分の金額も分けて確認します。

## 加入先を選ぶ実務ポイント：相談しやすさと契約全体の確認しやすさ

制度が共通でも、Web中心、コールセンター中心、代理店型など手続き方法は異なります。ここは事故対応の優劣を根拠なく順位付けするのではなく、**自分が契約内容を確認・変更しやすいか**という実務面で見ます。

地震後は広域災害となり、契約内容・連絡先をすぐ確認できることが重要です。保険証券や契約者ページへのアクセス方法、代理店・保険会社の連絡先を平時に家族と共有しておきます。

なお、現在の火災保険に地震保険を付けていない場合、保険期間の途中から地震保険を追加できる場合があります。一方、「火災保険はA社のまま、地震保険だけB社から独立商品として選ぶ」という一般の商品比較とは違います。変更時は現在の契約先へ確認します。

## 地震保険を付けるかどうかは「会社選び」と分けて考える

地震保険は被災物件を完全復旧するための実費保険ではなく、被災後の生活安定に寄与することを目的とする制度です。必要性を検討するときは会社名より、住宅ローン・貯蓄・家族構成・地域の地震リスク・被災後に必要な当面資金を考えます。

火災保険・地震保険・自動車保険を含め、災害時の保険を全体で整理する場合は[災害と保険の全体像](article_b019.html)を確認してください。

## 比較するときのチェック表

| 確認項目 | 会社差の考え方 |
|---|---|
| 地震保険の対象災害 | 基本的に共通 |
| 地震保険の損害区分 | 共通 |
| 地震保険金額30〜50％ | 共通ルール |
| 建物5,000万円・家財1,000万円の限度 | 共通ルール |
| 同条件での基本的な地震保険料 | 原則共通 |
| 払込方法 | 条件により差が出る場合あり |
| 火災保険の補償・特約 | 商品ごとに異なる |
| 地震火災費用 | 火災保険側の商品条件を確認 |
| 申込・相談方法 | 会社・商品で異なる |

## まとめ

地震保険は、同じ条件なら保険会社を変えて補償を厚くしたり、基本保険料だけを安くしたりする商品ではありません。まず法定地震保険の共通部分を理解し、そのうえで**火災保険側の補償、地震火災費用等の周辺特約、手続き方法、契約全体の保険料**を比較します。

「地震保険のおすすめ会社」を探すより、同じ条件で火災保険全体を比較し、自分に必要な補償を確認する方が実務的です。
