# 地震保険は保険会社で違う？補償・保険料が同じ点と火災保険側で違う点

「地震保険はどの会社がいいのか」「保険会社を変えれば安くなるのか」と迷うことがあります。

結論からいうと、**地震保険そのものは、所在地・建物構造などの条件が同じなら、保険会社によって補償内容や保険料が変わる商品ではありません**。

一方で、地震保険をセットする**火災保険の商品内容、申込・相談方法、地震火災費用などの周辺補償**は会社・商品によって異なります。

この記事では、「同じ部分」と「違う部分」を分けて整理します。

## 結論：地震保険そのものより、セットする火災保険を比較する

地震保険は「地震保険に関する法律」に基づき、政府と損害保険会社が共同で運営する公共性の高い保険です。

日本損害保険協会は、建物の所在地や構造などの条件が同じであれば、**どの保険会社で加入しても補償内容や支払う保険料に違いはない**と案内しています。

したがって、

- A社の地震保険は補償が手厚い
- B社なら同じ条件でも地震保険料が安い
- 地震保険だけ最安会社へ乗り換える

という比較は、基本的には地震保険の商品選びとしては適切ではありません。

比較するなら、**地震保険のセット元となる火災保険全体**を見ます。

## 保険会社が違っても同じ主な項目

| 項目 | 地震保険の共通ルール |
|---|---|
| 対象となる原因 | 地震・噴火・これらによる津波 |
| 主な損害 | 火災、損壊、埋没、流失 |
| 保険の対象 | 居住用建物、生活用家財 |
| 契約方法 | 火災保険にセットして契約 |
| 保険金額 | 火災保険金額の30〜50％ |
| 限度額 | 建物5,000万円、家財1,000万円 |
| 損害区分 | 全損・大半損・小半損・一部損 |
| 支払割合の基本 | 100％・60％・30％・5％ |
| 保険料の主な決まり方 | 所在地、建物構造、割引条件等 |

地震保険の基本制度については、[地震保険の基本｜火災保険との違いを整理](article_b017.html)で詳しく説明しています。

## 地震保険料は会社が自由に決めているわけではない

火災保険は商品ごとに補償範囲や保険料が異なりますが、地震保険は同じ性格ではありません。

地震保険料は、主に**建物の所在地（都道府県）と建物構造**によって異なり、免震建築物割引、耐震等級割引、耐震診断割引、建築年割引などの制度があります。

そのため、同じ建物・同じ地震保険金額・同じ割引条件なのに、「会社を変えれば地震保険だけ大幅に安くなる」という考え方では比較しません。

なお、日本損害保険協会は、**一部、保険料の払込方法によって保険料が異なる場合がある**と案内しています。実際の見積りでは払込条件もそろえて確認します。

## 損害区分の基準も会社独自ではない

地震保険では、修理費をそのまま実額払いするのではなく、損害の程度を区分して保険金を支払います。

現行制度では、

- 全損：地震保険金額の100％
- 大半損：60％
- 小半損：30％
- 一部損：5％

という区分があります。実際の支払額には時価等の上限があります。

この損害区分の仕組みも、各社が独自に「A社は一部損を出しやすい」と自由設計しているものではありません。

事故時は契約先が損害確認を行いますが、**制度上の損害認定基準と支払割合は共通**です。

## では、保険会社を選ぶ意味はどこにある？

地震保険自体が同じでも、契約全体では違いがあります。

主に見るのは次の4点です。

1. セットする火災保険の補償内容
2. 地震火災費用など火災保険側の補償
3. Web・電話・代理店などの契約・相談方法
4. 払込方法や契約管理のしやすさ

## 違い1：セットする火災保険の内容

地震保険は単独では契約できず、火災保険にセットします。

この**火災保険は各社の商品**なので、

- 水災を付けるか外すか
- 風災の自己負担額
- 破損・汚損を補償するか
- 建物・家財の補償設計
- Web完結型か代理店型か

などに違いがあります。

つまり、地震保険部分が同じでも、**火災保険＋地震保険という契約全体では会社ごとに違いが生じます**。

火災保険会社を比較する場合は、[火災保険10社を比較｜水災・風災・補償の選び方・申込方法](article_b051.html)を参照してください。

## 違い2：「地震火災費用」と地震保険は別もの

火災保険の商品によっては、「地震火災費用保険金」「地震火災費用特約」などが用意されている場合があります。

名称に「地震」と入っていますが、**これは法定の地震保険そのものではありません**。

日本損害保険協会は、通常の火災保険では地震等による火災損害を補償しない一方、一定条件を満たす地震火災について、費用保険金を支払う仕組みがあると説明しています。

たとえば、地震等を原因とする火災で建物が一定以上焼損した場合などに、火災保険金額の一定割合を支払うタイプがあります。

ただし、

- 火災以外の地震損害まで広く補償するものではない
- 支払条件や限度額は商品・特約を確認する必要がある
- 地震保険の代替として同じものではない

という点に注意します。

**「地震火災費用があるから地震保険はいらない」と単純には置き換えられません**。

## 違い3：申込・相談・事故連絡の窓口

地震保険の制度が共通でも、契約先の火災保険によって手続き方法は異なります。

たとえば、

- Web中心で申し込む
- コールセンターへ相談する
- 代理店と補償を決める
- 事故連絡をWebで受け付ける
- 代理店経由で事故連絡する

などの違いがあります。

ここは「どの会社が事故対応1位か」という話ではなく、**自分が契約内容を確認しやすい窓口か**という実務面で比較します。

## 違い4：払込方法や火災保険全体の保険料

地震保険そのものの基本料率が会社競争で変わるわけではありませんが、契約全体の支払額を見ると、セットする火災保険の保険料が違います。

また、損害保険協会の案内では、地震保険についても払込方法によって保険料が異なる場合があるとされています。

そのため見積り比較では、

- 火災保険の補償条件
- 地震保険金額
- 地震保険の割引
- 保険期間
- 払込方法

をそろえます。

## 「地震保険おすすめ10社」を作りにくい理由

地震保険について10社を1位から10位まで並べても、制度上共通の部分が大きいため、読者にとって有益なランキングにはなりにくいです。

特に、

- 補償内容
- 保険金額の設定範囲
- 損害区分
- 基本的な保険料の仕組み

を会社独自の強みとして順位付けすると、制度を誤解させる可能性があります。

そのため当サイトでは、**地震保険会社ランキングではなく、火災保険全体の比較と、地震保険で共通する制度の確認を分けます**。

## 地震保険だけ別の会社に加入できる？

地震保険は単独契約ではなく、火災保険にセットする制度です。

現在契約している火災保険に地震保険が付いていない場合は、保険期間の途中から地震保険を追加できる場合があります。

「火災保険はA社のまま、地震保険だけB社の商品を別契約で選ぶ」という一般の独立商品比較とは違うと考えます。

契約変更や乗り換えを検討するときは、現在の火災保険の満期・解約条件も含めて契約先へ確認します。

## 同じ条件なら、どこで加入しても地震保険金額は同じ？

地震保険金額は、火災保険金額の30〜50％の範囲で契約者が設定します。

そのため、同じ建物でも、A社で30％、B社で50％というように**契約者が設定する金額が違えば契約金額は変わります**。

これは「会社の商品差」ではなく、設定した地震保険金額の違いです。

会社比較をするときは、地震保険金額の割合もそろえます。

## 比較するときのチェック表

| 確認項目 | 会社差か |
|---|---|
| 地震保険の対象災害 | 基本的に共通 |
| 地震保険の損害区分 | 共通 |
| 地震保険金額30〜50％ | 共通ルール |
| 建物5,000万円・家財1,000万円の限度 | 共通ルール |
| 同条件での基本的な地震保険料 | 会社差ではない |
| 火災保険の水災・風災・破損補償 | 会社・商品で異なる |
| 地震火災費用等の周辺補償 | 商品・特約を確認 |
| Web・代理店などの手続方法 | 会社・商品で異なる |
| 払込方法 | 契約条件を確認 |

## どの会社で加入するか迷ったときの順番

1. まず地震保険を付けるか、建物・家財のどちらに付けるかを考える
2. 地震保険金額を30〜50％の範囲で検討する
3. 耐震等の割引が使えるか確認する
4. セットする火災保険の補償条件を決める
5. 同じ条件で複数の火災保険を比較する
6. 地震火災費用等の周辺補償を地震保険と混同せず確認する
7. 手続方法・相談窓口も含めて契約先を選ぶ

地震保険そのものをランキングするより、この順番の方が契約全体の違いを把握しやすくなります。

## まとめ

**地震保険は、同じ所在地・建物構造・保険金額・割引条件等なら、保険会社によって補償内容や基本的な保険料が変わる商品ではありません。**

一方、セットする火災保険の補償、地震火災費用等の周辺補償、申込・相談方法、払込条件などには違いがあります。

そのため「地震保険のおすすめ会社」を探すより、まず地震保険の共通制度を理解し、そのうえで**火災保険全体を同条件で比較する**のが実務的です。
