# 自宅が浸水した後、片付ける前に記録したいもの

浸水後は早く片付けたくなりますが、保険・修理・自治体への説明などで、**被害前の状態を後から再現できない**ことがあります。

ただし、記録のために危険な建物へ戻る必要はありません。この記事では、**安全確認 → 全景 → 浸水高さ → 個別損害 → メモ・時系列 → 片付け前後 → 連絡・書類保存**の順で整理します。

## 結論：安全が確認できたら「全体→高さ→個別→書類」の順で残す

記録は次の順にすると、後で位置関係を説明しやすくなります。

1. 建物外観・部屋全体
2. 浸水高さが分かる壁・柱等
3. 床・壁・建具などの損傷
4. 家財全体と個別の損害
5. 家電等の型番・銘板
6. 日時・場所・対応内容のメモ
7. 片付け・修理前後の写真
8. 見積書・領収書・受付番号等

感電、ガス、倒壊、汚水等の危険がある場合は、**撮影より安全確認を先にします。**

## 1. 撮影のため危険な建物へ入らない

水が残っている、焦げ臭い、配線が露出している、建物が傾いている、ガス臭がする等の異常があれば、専門機関等の安全確認を優先します。

**スマートフォンで撮影できることと、立ち入って安全であることは別です。**

特に水と電気が関わる場所では、写真を撮るために濡れた家電を動かしたり、通電したりしません。

## 2. 最初は接写ではなく、建物・部屋全体を撮る

損保協会は、被害を受けた建物や家財の全体写真と、浸水高さ・損傷箇所が確認できる写真を案内しています。

まず、

- 建物外観
- 各部屋の入口から見た全体
- 家財が置かれていた状態
- 床・壁・建具の被害範囲

を残します。

いきなり壊れた家電だけを拡大して撮ると、**どの部屋のどの場所にあった物か**が分かりにくくなります。

## 3. 同じ場所を「遠景・中景・近景」で撮る

損傷部は、可能なら3段階で残します。

| 撮り方 | 何が分かるか |
|---|---|
| 遠景 | 建物・部屋のどこに被害があるか |
| 中景 | 周辺との位置関係 |
| 近景 | ひび、破損、汚れ、浸水痕等の詳細 |

例えば壁の浸水線なら、部屋全体 → 壁一面 → 浸水線の近接、という順です。

安全上無理な角度へ移動したり、高所へ上がったりして撮影する必要はありません。

### 動画は補助として使う

水が流れる様子、雨漏り、設備の異音などは動画で伝わりやすい場合があります。ただし、全景・浸水高さ・損傷部は**静止画でも残す**と一覧しやすくなります。

## 4. 浸水高さは清掃で消える前に残す

壁、柱、家具等に浸水線が残っている場合は、清掃前に記録します。

- 浸水線の位置
- 床からの高さが分かる物差し等との比較
- 部屋全体との位置関係

を残すと、後で被害状況を説明しやすくなります。

ただし、測定のために危険な場所へ長くとどまりません。

## 5. 家財は「全体→品物→型番」の順で残す

浸水した家具・家電を処分すると、商品名・型番・購入時期等を後から確認しにくくなります。

記録は、

1. 部屋全体
2. 家財が置かれていた位置
3. 個々の家財全体
4. 損傷部
5. 型番・銘板

の順にすると追いやすくなります。

濡れた電気製品を型番確認のため動かしたり、電源を入れたりしません。安全な位置から確認できる場合だけ行います。

### 被害品一覧は部屋ごとに作る

一度に家全体を書き出すより、リビング・台所・寝室など部屋ごとに整理します。

| 記録項目 | 例 |
|---|---|
| 写真番号 | L-03 |
| 品名 | 冷蔵庫 |
| メーカー・型番 | 分かる範囲 |
| 購入時期 | 2024年頃 |
| 損傷 | 下部まで浸水、通電せず |
| 対応 | 業者確認待ち |

完璧な台帳より、**処分前に最低限追跡できる記録を残す**ことを優先します。

## 6. 写真だけでなく「日時・場所・判断」を短くメモする

写真だけでは、いつ確認したか、なぜ片付けたかを後から思い出しにくくなります。

| 記録 | 例 |
|---|---|
| 日時 | 9月1日 10時ごろ |
| 場所 | 1階リビング南側 |
| 状況 | 床上まで浸水、泥流入 |
| 家財 | 冷蔵庫・テレビ・ソファ浸水 |
| 判断 | 感電リスクを考え通電せず退避 |
| 作業 | 衛生上、当日中に一部家財を屋外搬出 |

特に、**被害 → 安全上の判断 → 実施した作業**の順を一言残すと、後から時系列を説明しやすくなります。

## 7. 安全・衛生上必要なら、保険会社の到着を待たず片付ける場合がある

損保協会は、防犯・安全上の問題等から片付けや修理が必要な場合は進めてもよいと案内し、その際に可能な範囲で損傷箇所を撮影するよう案内しています。

「保険会社が来るまで何も動かしてはいけない」と考え、汚水や危険物を放置する必要はありません。

可能なら、

- 片付け前
- 搬出・処分する物
- 片付け後

を同じ方向から撮影します。

壁の浸水線など、清掃すると消える情報は先に残します。

## 8. 修理・処分・連絡の記録も同じ時系列へ追加する

被害写真だけで終わらず、その後のやり取りも一つの記録にまとめます。

- 保険会社・代理店への連絡日時
- 事故受付番号
- 管理会社・大家への連絡
- 修理業者の担当者
- 見積書
- 作業前後の写真
- 交換部品・修理箇所
- 廃棄・応急修理・宿泊等の領収書
- 次に必要な行動

誰に何を伝えたか分からなくなるのを防ぐため、**受付日時・担当者・番号・次の予定**を一つのメモへまとめます。

「保険金を使えば無料で修理できる」等の勧誘トラブルもあるため、修理契約を急がず、保険会社・代理店へ確認します。

## 9. 罹災証明と保険請求は別の手続き

自治体の罹災証明は、公的支援等で使う制度です。損害保険の請求とは別に考えます。

日本損害保険協会は2026年8月31日更新の大雨災害案内で、**損害保険の保険金等の請求では地方自治体の罹災証明書の提出は原則不要**と案内しています。

ただし、個別契約で必要な資料は契約先へ確認します。自治体手続きと保険手続きを分けて管理すると混乱を減らせます。

## 10. 濡れた書類も、読める情報は写真に残す

保険証券、保証書、領収書、契約書等が濡れていても、読める情報があれば記録します。

再発行できる書類もあるため、原本を救うため危険な場所へ戻ったり、無理な乾燥作業を優先したりしません。

## 11. データは完璧に整理するより、まず失わない

災害直後にファイル名を一枚ずつ整える必要はありません。

まず、

- 外観
- 1階
- 2階
- 家財
- 修理

など大まかなフォルダへ分け、撮影日時・場所のメモを残します。

クラウド同期が使える場合はバックアップになりますが、個人情報を含む被害写真を公開SNSへ上げることは避けます。スマートフォン故障・紛失も考え、家族へ共有できる記録も用意します。

## まとめ：写真は「証拠を集める」より、後から状況を再現できるように残す

浸水後の記録は、細かい損傷を大量に接写することが目的ではありません。

**安全確認 → 全体 → 高さ → 個別 → 型番 → 時系列 → 片付け前後 → 連絡書類**の順に残すと、保険・修理・自治体手続き・家族間の説明へ使いやすくなります。

安全・衛生上片付けが必要なら、記録できる範囲で残したうえで進めます。撮影のために危険な建物へ戻らないことが最優先です。
