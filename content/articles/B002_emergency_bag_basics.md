# 防災リュックの中身は何を入れる？最低限の持ち出し品と重さ・置き場所

防災リュックを準備しようとすると、「何を入れればよいか」「全部入れると重すぎないか」で迷います。避難時に持ち出すバッグは、自宅で数日過ごすための備蓄とは役割が違うため、**必要品を全部詰め込むのではなく、避難途中から避難直後に使う物を優先**します。

内閣府は、急いで自宅から避難する場合に備え、**「すぐに必要になるもの」「ないと困るもの」**を非常持ち出し品として事前にリュック等へ入れておくことを案内しています。消防庁も、最小限の非常持ち出し品を普段から用意し、すぐ取り出せる場所に置くことを勧めています。

この記事では、まず自宅備蓄と持ち出し品を分け、その後に**何を入れるか → なぜ必要か → 重さをどう減らすか → どこに置くか → どう見直すか**の順で整理します。

## 結論：防災リュックは「持って避難できる最小限」を優先する

防災リュックは、次の順で作ると整理しやすくなります。

1. 自宅備蓄と持ち出し品を分ける
2. 避難直後に必要なものから入れる
3. 自分・家族に代わりがきかないものを優先する
4. 実際に背負い、重すぎる物を減らす
5. すぐ持ち出せる場所に置く
6. 期限だけでなく生活の変化でも見直す

基準は「防災用品かどうか」ではなく、**そのバッグを持って避難する場面で本当に使うか**です。

## 1. まず自宅備蓄と防災リュックを分ける

自宅で数日生活するための備蓄と、避難時に持ち出すものでは目的が違います。

| 分類 | 主な目的 | 例 |
|---|---|---|
| 自宅備蓄 | 在宅避難やライフライン停止に備える | 水、食料、携帯トイレ、生活用品など |
| 防災リュック | 避難途中〜避難直後に必要なものを持つ | 飲料水、すぐ食べられる食品、ライト、常用薬、衛生用品など |
| 日常携行 | 外出中の災害に備える | モバイルバッテリー、ライト、連絡先、身分証明等 |

例えば、1週間分の水や食品をすべてリュックに入れるのではなく、自宅備蓄へ置き、持ち出し用には避難直後に必要な量を入れます。内閣府の家庭向け案内でも、備蓄と持ち出し品は別に説明されています。

## 2. 防災リュックに入れるものを5つの用途に分ける

「品名だけのチェックリスト」では、なぜ必要なのか分からず、重くなった時に何を減らすか判断できません。ここでは**用途と必要理由**をセットで見ます。

### A. 水分・食料

| 備品 | 何に使う | なぜ入れるか・注意点 |
|---|---|---|
| 飲料水 | 避難途中・到着直後の水分補給 | 自宅備蓄の全量ではなく、持てる範囲の初動分にする |
| すぐ食べられる非常食・栄養補助食品 | 調理できない時の食事 | 火や湯を使わず食べられる物を優先すると使いやすい |
| 食べ慣れた小型食品 | 空腹対策、子ども等の食事 | 普段食べ慣れた物なら非常時にも受け入れやすい |

→ [水・非常食の選び方と商品紹介](/goods/water-food.html)

### B. 明かり・情報・連絡

| 備品 | 何に使う | なぜ入れるか・注意点 |
|---|---|---|
| 懐中電灯 | 暗い場所や足元を照らす | 夜間・停電時の移動で転倒物を確認するため |
| ヘッドライト | 両手を使う移動・作業 | バッグを持つ、手すりを使う等の場面で両手を空けやすい |
| 携帯ラジオ | 災害情報の取得 | スマートフォンの通信・電池が使いにくい時の別経路になる |
| 予備電池 | ライト・ラジオの継続使用 | 機器と電池規格が合うことを事前に確認する |
| スマートフォン | 連絡、自治体情報、地図等の確認 | 重要だが、通信障害・充電切れを前提に代替も用意する |
| モバイルバッテリー・ケーブル | スマートフォン等の充電 | ケーブルの端子が手持ち機器と合うか確認する |
| 家族の連絡先を書いたメモ | 電話番号・集合ルールの確認 | スマートフォンが使えない時にも確認できる |

→ [防災用ライト・ラジオの商品紹介](/goods/light-information.html)  
→ [モバイルバッテリー・電源の商品紹介](/goods/power-charging.html)

### C. 衛生・生活用品

| 備品 | 何に使う | なぜ入れるか・注意点 |
|---|---|---|
| マスク | ほこり・飛沫対策等 | 避難環境や災害種別に応じて使う |
| ウェットティッシュ・体拭き | 手や体を拭く | 断水時に水を使わず衛生を保ちやすい |
| タオル・ティッシュ | 清拭、汗・水分の処理 | 汎用性が高いが、量を入れすぎない |
| 携帯トイレ | トイレが使えない時の排泄 | 避難途中・到着直後分を持ち、自宅分は別備蓄にする |
| 生理用品 | 生理時の衛生維持 | 本人が普段使う物を基準にする |
| 最低限の下着・衣類 | 汚れ・濡れへの対応 | 季節と避難環境に合わせ、かさばりすぎない量にする |
| 雨具 | 雨天時の移動・体温低下対策 | 傘だけで両手がふさがらないよう、着用型も検討する |

→ [携帯トイレ・衛生用品の商品紹介](/goods/toilet-hygiene.html)

### D. 健康・応急用品

| 備品 | 何に使う | なぜ入れるか・注意点 |
|---|---|---|
| 日常的に必要な薬 | 持病等の治療継続 | 本人に代替がききにくい。必要量・保管は医師・薬剤師等へ確認する |
| お薬手帳・薬の情報 | 診療・調剤時の情報共有 | 薬名・用法・用量を確認できるようにする |
| 救急用品 | 軽微なけがの初期対応 | 家庭で扱える範囲の用品を入れる |
| 眼鏡・補聴器・予備電池等 | 視覚・聴覚等の補助 | 移動や情報取得に直結し、代替しにくい |

政府広報オンラインでは、災害時に**常用薬や病気の情報を正確に伝えるため、お薬手帳やマイナ保険証等を活用する考え方**が案内されています。スマートフォンだけに情報を保存している場合は、充電切れや通信障害も考え、薬の名前・用法・用量、かかりつけ医等を紙でも確認できるようにする方法があります。

### E. 身元確認・お金

| 備品 | 何に使う | なぜ入れるか・注意点 |
|---|---|---|
| 身分証明書等 | 本人確認や各種手続き | 原本・コピー等の扱いは紛失・盗難リスクも考えて決める |
| 現金 | キャッシュレス決済が使えない時の支払い | 必要以上の高額を持ち歩くこととは別に考える |
| 必要な連絡先 | 家族・勤務先・医療機関等への連絡 | スマートフォン以外でも確認できる形を検討する |
| 保険・口座等の必要情報 | 被災後の確認・手続き | 情報の持ち歩き方は個人情報保護とのバランスを取る |

## 3. 「人によって必要なものが違う」を最優先にする

消防庁は、非常持ち出し品は**人によって異なる**と案内しています。一般的なリストを埋めた後ではなく、**「これがないと本人が困る物」**は早い段階で追加します。

| 家庭・本人の条件 | 追加で確認したいもの | 関連情報 |
|---|---|---|
| 乳幼児がいる | ミルク、哺乳瓶、紙おむつ等 | [赤ちゃんの防災備蓄](article_b034.html) |
| 高齢者・介助が必要 | 普段使う補助用品、薬等 | [高齢者の防災](article_b035.html) |
| 持病がある | 常用薬、薬の情報 | 医師・薬剤師等にも確認する |
| 眼鏡・補聴器等が必要 | 代替しにくい用品、予備電池 | 本人が普段使う物を優先する |
| ペットがいる | ペット用の避難用品 | [ペットの防災](article_b033.html) |

## 4. 避難所へ行く場合は「代替しにくい物」を追加確認する

「避難所には物資があるはず」と考えて、個人用品をすべて置いていくのは避けます。避難所の備蓄内容、開設直後の供給状況、本人に必要な物は地域や状況で異なるためです。

| 優先して確認 | 理由 |
|---|---|
| 常用薬・お薬手帳・薬の情報 | 本人に代替がききにくく、診療・調剤時の情報になる |
| 眼鏡・補聴器・予備電池 | 避難生活中の移動・情報取得に関わる |
| マスク・ティッシュ・ウェットティッシュ・生理用品 | 個人差が大きい衛生用品を補う |
| スマートフォン・充電ケーブル・モバイルバッテリー | 連絡・自治体情報の確認に使う |
| 最低限の着替え・防寒具や雨具 | 季節・天候に応じて体温管理に使う |
| 身分証明・連絡先 | 手続きや家族との連絡に使う |
| 乳幼児・介護・ペット用品 | 一般的な備蓄だけでは代替しにくい |

ただし、**持ち物を全部そろえるために避難を遅らせない**ことが前提です。すでに危険が迫っている場合は、荷造りを続けるより安全確保を優先します。

## 5. 重さは数字だけでなく、実際に背負って決める

持ち出し品は、実際に持って歩けなければ意味がありません。

政府広報オンラインでは、非常持ち出し袋の量の想定として、**成年男性約15kg、成年女性約10kg、子ども・高齢者約6kg**という目安を紹介しています。ただし、これは個人の体力、年齢、健康状態、移動距離、階段の有無などで大きく変わり、**「この重さまでなら安全」という上限ではありません。**

実際には、次のようにバッグを背負って確認します。

| 試すこと | 確認する理由 |
|---|---|
| 数分歩く | 重さで歩行が崩れないか見る |
| 階段を上り下りする | 自宅・避難経路で持てるか見る |
| 両手を使えるか確認する | 手すり・ドア・子どもの補助等に対応できるか見る |
| 家族で荷物を分ける | 1人へ重量が集中していないか見る |

容量から見直したい場合は、[防災リュックは何L必要？](article_b032.html)で中身・重さから決める手順を整理しています。

> **Q&A:** [防災バッグは何kgまでなら大丈夫ですか？](qa.html#qa-bag-weight)

### 重すぎたら「避難中に使うか」で減らす

1. **自宅で使う物は自宅備蓄へ戻す** — 数日分の水・食品、かさばる生活用品などを分ける。
2. **同じ役割の物が重複していないか確認する** — ライト、充電手段、衛生用品等を必要以上に重ねない。
3. **家族で分散できる物は分ける** — 全員分を1人のバッグへ集中させない。
4. **代替しにくい物は最後まで残す** — 常用薬、眼鏡、補聴器、乳幼児用品等を先に削らない。
5. **もう一度背負って歩く** — 減らした後も実際の移動を確認する。

## 6. バッグは「両手が使えて、自分が持てるもの」を選ぶ

内閣府や消防庁では、非常持ち出し品をリュック等へ入れて準備する例が示されています。リュック型なら**両手を使いやすい**ため、移動時の自由度を確保しやすくなります。

| 確認点 | 理由 |
|---|---|
| 自分の体格に合う | 肩・背中への負担を減らしやすい |
| 肩紐を調整できる | 荷物を背中側へ安定させやすい |
| 開閉しやすい | 必要品をすぐ取り出しやすい |
| 雨対策ができる | 中身の濡れを減らすため |
| 中身を分類しやすい | 暗所・混乱時でも探しやすくするため |

**高価な「防災専用バッグ」でなければならないわけではありません。** 普段使っていないリュックを活用する方法もあります。

[20L・30Lなど、防災リュックの容量をどう決めるか](article_b032.html)で容量の考え方を詳しく整理しています。

## 7. 置き場所は「すぐ持ち出せるか」で決める

消防庁は、非常持ち出し品を**目につきやすく、すぐ取り出せる場所**へ置くことを案内しています。政府広報オンラインでは、玄関の近く、寝室、車の中、物置などへ配置する考え方も紹介しています。

| 置き場所を決める時 | 理由 |
|---|---|
| 玄関から持ち出せるか | 避難開始時に探し回らないため |
| 夜間でも手に取れるか | 停電・暗闇でも使えるようにするため |
| 出口をふさがないか | 転倒物等で避難を妨げないため |
| 家族が場所を知っているか | 誰が在宅していても持ち出せるようにするため |

玄関が使えない場合や2階からの避難等も考え、住宅によっては寝室・玄関付近などへ分散する方法もあります。

## 8. 見直しは「日付」だけでなく生活の変化をきっかけにする

一度作って終わりではありません。期限切れだけでなく、生活条件が変わると必要品も変わります。

| 期限・状態の確認 | 暮らしの変化で確認 |
|---|---|
| 食品・飲料の期限 | 子どもの成長・サイズ変更 |
| 電池・モバイルバッテリーの状態 | 季節の変化 |
| 薬や衛生用品 | 住所・連絡先の変更 |
| バッグ・雨具等の劣化 | 家族構成・持病・介護状況の変化 |

「半年に1回覚えて確認する」だけにせず、**スマートフォンのカレンダーへ繰り返し予定を入れる、防災の日や季節の衣替えに合わせる、引っ越し・進学・薬変更時に見直す**など、忘れにくいきっかけを決めます。

## 最初に作るなら、この簡易チェックから

最初は次の表を使い、1つずつ「なぜ入れるか」を確認しながら入れます。

| 最初に確認するもの | 目的 |
|---|---|
| 飲料水 | 避難途中・到着直後の水分補給 |
| すぐ食べられる食品 | 調理できない時の食事 |
| ライト | 暗所の移動・作業 |
| 予備電源 | スマートフォン等の充電 |
| 携帯ラジオ等 | スマートフォン以外の情報取得 |
| タオル・マスク・衛生用品 | 断水・避難環境での衛生維持 |
| 携帯トイレ | トイレが使えない場合への備え |
| 常用薬・医療情報 | 治療継続・診療時の情報共有 |
| 家族の連絡先 | 通信障害時にも確認できるようにする |
| 身分証明・現金等 | 手続き・支払いに備える |

入れ終わったら実際に背負い、**重すぎるものは自宅備蓄へ戻す**という順で調整します。

## 防災セットを購入する場合も「不足と不要」を確認する

市販の防災セットは、最初の準備を簡単にできる利点があります。一方で、セット内容がそのまま自分の家庭に合うとは限りません。

| 確認すること | 理由 |
|---|---|
| 家族構成に合っているか | 乳幼児・高齢者・持病等で必要品が変わる |
| 薬・衛生用品が足りるか | 個人差が大きく、セットでは代替しにくい |
| ライトや電源の仕様が合うか | 電池・端子・使用時間等が家庭ごとに違う |
| 自分で持てる重さか | セットでも持てなければ避難に使いにくい |
| 不要な物が多くないか | 重量を増やすだけの物を減らすため |

用途別の商品例を確認したい場合は、[水・非常食](/goods/water-food.html)、[トイレ・衛生](/goods/toilet-hygiene.html)、[ライト・情報](/goods/light-information.html)、[電源・充電](/goods/power-charging.html)から、自分に不足している分だけ比較します。

> **Q&A:** [防災用品は最初に一式セットを買った方がいいですか？](qa.html#qa-buy-all)

## まとめ

防災リュックは、できるだけ多くの物を詰め込むためのバッグではありません。

**避難途中〜避難直後に使うもの、本人に代替がきかないものを先に入れ、実際に背負って重さを調整する。** これが基本です。自宅備蓄とは分け、置き場所と見直しのきっかけまで決めると、実際に使える防災リュックになります。
