# 地震に備えて最初に確認したいこと

地震は台風のように「明日来るから片付ける」という準備ができません。そのため、最初にやるべきことは防災用品を増やすことではなく、**突然揺れても、その場でけがをしにくい室内環境を作ること**です。

この記事では、初めて地震対策をする家庭向けに、**①寝室・出口の安全 → ②揺れている間の行動 → ③揺れた後の確認順 → ④停電・断水への備え → ⑤火災・避難 → ⑥家族連絡**の順で整理します。家具転倒、帰宅困難、在宅避難、津波など、詳しいテーマは必要な箇所から個別記事へ進める構成にします。

## 結論：最初は「揺れた瞬間にけがをしない家」を作る

地震対策は次の順で確認すると、優先順位が分かりやすくなります。

1. **寝る場所と出口の安全を確認する** — 家具・落下物でけがをしない、逃げ道を失わないため
2. **揺れている間の基本行動を家族で共有する** — 火元へ走るより、まず身の安全を確保するため
3. **揺れが収まった後の確認順を決める** — けが、火気・電気、出口、情報、避難を落ち着いて確認するため
4. **停電・断水・トイレ停止へ備える** — 自宅が安全でも生活インフラが止まる場合に備えるため
5. **避難先と家族連絡を決める** — 家族が別々の場所にいる前提で行動するため

家具固定や備蓄の量を増やす前に、まずこの5点を家庭の中で確認します。

## 1. 寝室・子ども部屋・出口から家具を見直す

消防庁は、家具が倒れて就寝位置を直撃したり、出入口を塞いだりしないよう、配置を工夫することを示しています。最初に見る場所は、家全体ではなく**寝る場所と避難動線**です。

| 確認する場所 | 何を見るか | なぜ先に見るか |
|---|---|---|
| ベッド・布団の周囲 | 背の高い家具が寝ている位置へ倒れないか | 就寝中はすぐ移動できないため |
| 寝室・子ども部屋の出入口 | 家具が倒れるとドアを塞がないか | 揺れ後の避難経路を残すため |
| 棚・収納の上 | 重い物・割れ物を高所に置いていないか | 落下物によるけがを減らすため |
| テレビ・電子レンジ等 | 移動・落下しないか | 重い家電の転倒・落下を減らすため |
| 玄関までの通路 | 倒れる家具・荷物で通路が塞がれないか | 外へ移動する経路を残すため |

固定器具は壁の構造に合う方法を選びます。壁ならどこにでも固定できるわけではないため、賃貸等では管理者への確認も必要です。

具体的な家具配置・固定方法は[地震の家具転倒対策](article_b023.html)で詳しく整理しています。

### 家の中の「身を守りやすい場所」も共有する

地震時に毎回同じ場所へ移動できるとは限りませんが、家具や窓から離れやすい場所、丈夫な机の位置などを家族で確認しておくと、揺れ始めた時の迷いを減らせます。

子どもにも「玄関へ走る」と一つの行動だけを覚えさせるのではなく、**その場で頭を守り、倒れる物・落ちる物から離れる**という原則を共有します。

## 2. 揺れている間は「火より先に自分の安全」

気象庁は、緊急地震速報を見聞きした場合や揺れを感じた場合、周囲の状況に応じて**あわてず、まず身の安全を確保する**ことを基本としています。

無理に火元へ駆け寄るより、頭を守り、倒れる家具・落下物・ガラス等から身を守ります。揺れている最中に外へ飛び出すことも、外壁・瓦・看板・ガラス等の落下物に近づく可能性があります。

> **海岸付近では津波を別に考える**
>
> 強い揺れや長くゆっくりした揺れを感じた地域では、津波警報を待たず高い場所へ避難する必要がある場合があります。本記事は家庭内の一般的な地震対策を扱います。津波の避難開始、徒歩と車、避難先は[津波からどう避難する？](article_b041.html)で確認してください。

## 3. 揺れが収まった後は「けが→火気・電気→出口→情報→避難」の順で確認する

揺れが止まった直後は、家の中にも外にも危険が残ります。「地震が来たら必ずすぐ外へ出る」と固定するのではなく、周囲を確認しながら行動します。

| 順番 | 確認すること | 理由 |
|---|---|---|
| 1. けが・周囲 | 自分と家族の負傷、落下物、割れたガラス | まず動ける状態かを確認するため |
| 2. 火気・電気 | 火元、焦げ臭さ、破損した家電・配線 | 火災・感電等の二次被害を避けるため |
| 3. 出口 | 靴を履き、玄関や避難経路を確認 | ガラス等から足を守り、移動経路を確保するため |
| 4. 情報 | 気象庁・自治体等の地震・津波・避難情報 | 現在地の危険を確認するため |
| 5. 避難 | 建物、火災、津波等の状況で必要性を判断 | 「地震だから外へ」ではなく危険から離れるため |

揺れた直後の行動だけを詳しく確認したい場合は、[地震が起きたらまず何をする？](article_b057.html)へ進めます。

## 4. 自宅が安全でも、停電・断水・トイレ停止へ備える

大きな地震では電気・ガス・水道・通信・物流が止まる可能性があります。自宅が倒壊していなくても、生活を続けるための備えが必要です。

| 生活機能 | 備えの例 | 何のためか |
|---|---|---|
| 水 | 飲料水 | 断水・物流停止時の飲用 |
| 食事 | 常温食品等 | 調理・買い物が難しい場合の食事 |
| トイレ | 携帯トイレ、衛生用品 | 断水・排水制限時の排泄 |
| 明かり | 懐中電灯、ランタン、予備電池 | 停電時の安全な移動・生活 |
| 情報・連絡 | スマートフォン、ラジオ、充電手段、家族ルール | 災害情報・安否確認 |
| 個別用品 | 常用薬、眼鏡、介護用品等 | 本人に代替しにくい物を確保するため |

具体的な備蓄品は[水・非常食](/goods/water-food.html)、[携帯トイレ・衛生用品](/goods/toilet-hygiene.html)、[ライト・ラジオ](/goods/light-information.html)、[モバイルバッテリー・電源](/goods/power-charging.html)で確認できます。

地震後の停電・断水をまとめて確認する場合は[地震後の停電・断水にどう備える？](article_b024.html)へ進めます。

## 5. 電気火災は「感震ブレーカーを付ければ終わり」ではない

内閣府は、地震時の電気火災対策として感震ブレーカーの設置を促しています。ただし、感震ブレーカーだけで地震火災が完全に防げるわけではありません。

確認したいのは、**設備の適合、停電時の照明、復電前の家電・配線の状態**です。焦げた臭い、浸水、破損等がある場合は通電を続けず、専門家や電力会社等へ確認します。

種類ごとの違い、夜間照明・医療機器・復電時の注意は[感震ブレーカーとは？](article_b040.html)で詳しく整理しています。

## 6. 避難するか自宅に残るかは「建物と周囲の安全」で判断する

地震では、火災、建物倒壊、津波等、避難する理由が複数あります。指定緊急避難場所・指定避難所の違いを自治体資料で確認し、昼夜それぞれの経路も見ます。

自宅が安全でライフライン対策ができる場合、在宅避難が適するケースもあります。一方、**備蓄があるから危険な建物に残る**という判断は避けます。

家具を固定していても、建物自体に大きな損傷が生じれば安全な在宅生活はできません。築年数、耐震診断・耐震改修の履歴等に不安がある場合は、自治体の耐震診断・改修支援制度や専門家への相談を確認します。

自宅に残るか避難所へ行くかの判断は[地震後、自宅に残る？避難所へ行く？](article_b039.html)で整理しています。

## 7. 家族が別々の場所にいる前提で連絡方法を決める

地震は通勤・通学・買い物中にも起こります。都市部では多数の人が一斉に帰宅すると混乱するため、「むやみに移動を開始しない」という考え方が示されています。

| 家族で決めること | 理由 |
|---|---|
| 電話がつながらない場合の連絡手段 | 通信混雑に備えるため |
| 災害用伝言サービス等を使うか | 電話以外の安否確認手段を持つため |
| 自宅以外の集合候補 | 自宅周辺が危険な場合に備えるため |
| 学校・施設の引き渡しルール | 子どもを迎えに行く条件を事前確認するため |
| 帰宅経路が危険な場合の行動 | 無理な帰宅を避けるため |

**「必ず自宅へ戻る」ことを最優先にせず、各自が安全を確保したうえで安否確認する**ことを共通ルールにします。

具体的な帰宅困難時の考え方は[大地震で電車が止まったら帰宅する？](article_b038.html)、家族ルールは[家族の連絡・集合ルール](article_b030.html)で確認できます。

## 8. 地震後は余震と情報の信頼性にも注意する

大きな揺れの後は、倒れかけた家具、割れたガラス、落下しそうな物がある場所へ不用意に入らず、靴・手袋を使い、退避経路を残しながら片付けます。**「もう大きな揺れは来ない」と決めつけない**ことが重要です。

また、具体的な日時を指定した地震予知等、科学的根拠のない情報に振り回されず、気象庁・自治体等の情報を優先します。SNSを安否確認等に使う場合も、**公的な危険情報と個人投稿を同じ重みで扱わない**ようにします。

## 最初の30分でできる地震対策

今日すぐ始めるなら、家全体を一度に変える必要はありません。

1. 寝室の背の高い家具が、寝る位置へ倒れないか確認する
2. 玄関までの通路を塞ぐ家具がないか確認する
3. 枕元に靴とライトを置く
4. 水・食品・携帯トイレの残量を確認する
5. 家族の連絡方法と避難先を共有する

この5つが終わったら、家具固定、備蓄量、感震ブレーカー、建物耐震性等を個別記事で深めます。

## まとめ

地震対策で最初に確認したいのは、**揺れた瞬間にけがをしにくい室内環境**です。その次に、揺れ後の確認順、停電・断水、火災、避難、家族連絡を整えます。

防災用品を増やすことだけを先にせず、**寝室と出口を見る → 家族で揺れ中・揺れ後の行動を共有する → 生活インフラと避難を備える**という順で進めると、地震対策全体をつなげて考えられます。
