# 防災は何から始める？家庭で最初に確認したい基本項目

防災を始めようと思っても、「非常食を買う」「防災バッグを用意する」「家具を固定する」など、やることが多くて迷いやすいものです。

最初から全部そろえる必要はありません。まずは、自宅や生活圏で起こり得る災害を知り、避難先と連絡方法を確認し、そのうえで備蓄や持ち出し品を整えると、必要なものを判断しやすくなります。

この記事では、防災を始める順番を6段階に分けて整理します。

## 結論：最初は「買う」より「確認する」

最初の防災は、次の順番で進めると整理しやすくなります。

1. 自宅や生活圏の災害リスクを確認する
2. 避難先と避難経路を確認する
3. 家族の連絡方法・集合方法を決める
4. 水・食料・トイレなどの備蓄を確認する
5. 非常持ち出し品を分けて準備する
6. 家具や住宅内の危険を減らす

内閣府の令和8年版防災白書でも、食料・飲料水の備蓄、非常持ち出し品、ハザードマップ、避難場所・避難経路の確認が事前の備えとして示されています。

## 1. 自宅や生活圏の災害リスクを確認する

防災用品を選ぶ前に、まず「自分の場所では何が起こり得るのか」を確認します。ただ災害名を一覧で見るだけでは、自分に関係するものを選びにくいため、**まず身の回りの地形や場所を手掛かりに、優先して見る災害を絞ります。**

| 自宅・生活圏の特徴 | まず確認したい災害 |
| --- | --- |
| 川の近く、低地、周囲より低い道路、地下・半地下がある | 洪水・内水氾濫 |
| 海岸、湾岸、河口に近い | 高潮・津波 |
| 崖、急な斜面、谷筋、山際に近い | 土砂災害 |
| 火山の周辺や降灰が想定される地域 | 噴火・降灰 |
| どの地域でも | 地震。地域によって津波・液状化等も追加確認 |

これは「川から離れているから洪水はない」といった自己判断をするための表ではありません。**何のハザードマップを先に開くかを決める入口**です。同じ市内でも想定は変わるため、最後は自宅・勤務先・学校などの住所ごとに公式地図で確認します。

洪水の避難判断は[洪水キキクル・河川氾濫はいつ避難する？](article_b042.html)、土砂災害は[土砂キキクルと避難判断の見方](article_b036.html)、高潮は[高潮はいつ避難する？](article_b043.html)、津波は[津波からどう避難する？](article_b041.html)で具体的に確認できます。

### ハザードマップは、まずこの順番で開く

初めて見る場合は、国土交通省・国土地理院の**ハザードマップポータルサイト**を入口にすると探しやすくなります。

1. ハザードマップポータルサイトを開く。
2. 「重ねるハザードマップ」の**住所から探す**に自宅住所を入力する。
3. 洪水、土砂災害、高潮、津波など必要な災害種別を切り替え、自宅周辺にどのような表示があるかを見る。
4. 次に「わがまちハザードマップ」から都道府県・市区町村を選び、自治体が公開する最新のハザードマップも確認する。

「重ねるハザードマップ」は全国のリスクを同じ地図上で見比べる入口、「わがまちハザードマップ」は市区町村が作成した地図を探す入口です。地図に色が付いていたら、色だけを見て終わらず、凡例で**想定浸水深、土砂災害の区域、高潮・津波の想定**など、その色が何を意味するかまで読みます。

地震については、自治体が地震ハザードマップ、揺れやすさ、液状化等を別に公開している場合があります。ハザードマップポータルで確認できない項目は、市区町村の防災ページも確認します。

## 2. 避難先と避難経路を確認する

災害リスクを確認したら、次は「どこへ、どう移動するか」です。ここで**近所の小学校や公民館を知っているだけでは、避難先を確認したことにはなりません。**

内閣府は、命を守るため緊急に逃げる場所を「指定緊急避難場所」、危険がなくなるまで一定期間滞在する施設を「指定避難所」と区別しています。指定緊急避難場所は洪水、土砂災害、地震、津波など**災害種別ごとに指定**されるため、「学校だから洪水でも津波でも行けばよい」とは限りません。

避難先を知らない場合は、次の順で1か所目を探します。

1. 自治体のハザードマップまたは避難場所一覧を開く。
2. 自宅で優先確認した災害に対応する**指定緊急避難場所**を探す。
3. 自宅からそこまでの経路に、川沿い、地下道、低い道路、崖沿いなど、その災害で危険になりやすい場所がないか確認する。
4. 第1候補が使えない場合に備え、別方向の第2候補も確認する。
5. 家族が学校・勤務先にいる場合は、無理に自宅へ集合せず、それぞれの施設の災害時ルールも確認する。

地図で候補を見つけたら、平常時に一度歩いてみると、階段、暗い道、狭い歩道、ベビーカーや車いすで通りにくい場所など、地図だけでは分からない点を確認できます。

家族が別々の場所にいる場合の決め方は[家族で決めておきたい災害時の連絡・集合ルール](article_b030.html)で詳しく整理しています。

具体的な避難行動は災害の種類やその時の状況で変わります。発災時は、この記事ではなく、気象庁・自治体などの最新の公的情報を優先してください。

## 3. 家族の連絡方法と集合方法を決める

災害は家族全員が自宅にいる時に起こるとは限りません。

内閣府は、平常時から家族・親族で安否確認方法や集合場所を確認しておくことを案内しています。

最低限、次の項目を決めておくと整理しやすくなります。

- 連絡が取れない場合の集合候補
- 自宅へ戻れない場合の行動
- 子どもの学校・家族の勤務先との連絡方法
- 遠方の親族など、家族共通の連絡先
- 災害用伝言サービスを使うか

スマートフォンだけを前提にせず、「連絡が取れなかったらどうするか」まで決めておくことが重要です。具体的な決め方は[家族の連絡・集合ルール](article_b030.html)へ進めます。

## 4. 水・食料・トイレなどを備蓄する

避難先と連絡方法を確認したら、次に自宅で生活を続けるための備蓄を見直します。

令和8年版防災白書では、食料・飲料水は最低3日分、できれば1週間分を備えることが望ましいとされています。

内閣府の家庭向けチェックページでは、飲料水の目安として「1人1日3リットル」が示されています。また、普段使う食品を多めに買い、使った分を買い足すローリングストックも紹介されています。

備蓄では食料だけでなく、ライフラインが止まった時に困るものも考えます。

- 飲料水
- 食料
- 携帯トイレ・簡易トイレ
- トイレットペーパー
- カセットコンロ等の調理手段
- 懐中電灯などの照明
- 充電・情報収集手段
- 衛生用品
- 日常的に必要な医薬品等

必要量は家族構成や生活条件で変わります。具体的な備蓄品を比較したい場合は、必要な項目ごとに商品記事を確認できます。

- [水・非常食の選び方と商品紹介](/goods/water-food.html)
- [携帯トイレ・衛生用品の商品紹介](/goods/toilet-hygiene.html)
- [停電用ライト・ラジオの商品紹介](/goods/light-information.html)
- [モバイルバッテリー・電源の商品紹介](/goods/power-charging.html)

## 5. 自宅備蓄と非常持ち出し品を分ける

「防災用品」を全部ひとつのバッグへ入れる必要はありません。

自宅で数日生活するための備蓄と、急いで避難する時に持ち出すものでは役割が異なります。

| 分類 | 主な目的 | 考え方 |
|---|---|---|
| 自宅備蓄 | ライフライン停止時などに自宅で生活する | 水・食料・トイレ・生活用品などを中心にする |
| 非常持ち出し品 | 避難時に必要なものを持って移動する | 「すぐ必要」「ないと困る」ものを優先し、重くしすぎない |
| 日常携帯 | 外出中に被災した時の初動に使う | 無理なく普段から持てる範囲にする |

乳幼児がいる家庭、介助が必要な人がいる家庭、ペットがいる家庭などでは、一般的なリストだけでは不足します。家族にとって「代わりがきかないもの」から確認することが重要です。

## 6. 家の中で危険な場所を減らす

備蓄と並行して、災害時にけがをしにくい環境も作ります。

令和8年版防災白書では、家具・家電の固定や配置の見直しによって安全な空間を作ることが重要とされています。

例えば次のような点から確認できます。

- 寝ている場所の近くに倒れそうな家具がないか
- 出入口を家具がふさぐ配置になっていないか
- 高い場所に重い物を置いていないか
- 家具・家電の固定が必要ではないか
- 懐中電灯などを夜間でも手に取れる場所に置いているか

家具対策は[地震の家具転倒対策｜まず優先したい場所](article_b023.html)で具体的に確認できます。

## 今日15分で始めるなら、この5つ

「自治体のハザードマップを開く」と言われても、初めてではそこで止まりやすいため、**今日は検索から結果を1つメモするところまで**を目標にします。

1. 「ハザードマップポータルサイト」を開き、「重ねるハザードマップ」の住所欄へ自宅住所を入力する。
2. 洪水・土砂災害・高潮・津波のうち、自宅周辺で表示されるリスクを1つ確認し、災害名と表示内容をメモする。
3. 「わがまちハザードマップ」または自治体の地図で、その災害に対応する避難場所を1つ確認する。
4. 家族へ「連絡できない場合に自宅へ戻るか、今いる安全な場所に留まるか」を一度話す。
5. 自宅の水・食料・携帯トイレを見て、足りない物を1つだけメモする。

ここまで終われば、「何を買えばいいか」ではなく、**自分の家では何が起こり得て、どこへ逃げ、何が不足しているか**が見え始めます。残りは一度に終わらせず、個別記事を使って順番に整えます。

## 家庭によって優先順位は変わる

一般的な防災リストは出発点にはなりますが、全家庭に同じ準備が当てはまるわけではありません。

特に次の条件がある場合は、必要な備えを追加で考えます。

- [乳幼児がいる家庭の防災備蓄](article_b034.html)
- [高齢者・要介護者がいる家庭の防災](article_b035.html)
- 継続して必要な薬・医療機器がある
- [ペットがいる家庭の防災](article_b033.html)
- 車で移動することが多い
- [マンションの高層階に住んでいる](article_b022.html)
- 浸水や土砂災害のリスクがある地域に住んでいる

## 最初の1週間は「確認→試す→足す」で進める

防災は、チェックリストを一度埋めて終わりではありません。例えば最初の日にハザードマップと避難先を確認し、次の買い物で不足している水・食品・携帯トイレを補い、週末に実際の避難経路や防災リュックの重さを確かめる、という進め方にすると続けやすくなります。

地図上では歩けそうな道でも、夜間は暗い、階段が多い、ベビーカーや介助では通りにくい、といった問題に気づくことがあります。そこで見つかった不足を次の準備へ反映すると、家庭ごとの防災になります。

見直しを忘れないため、スマホのカレンダーに**年1回の防災確認**を繰り返し登録する方法もあります。加えて、引っ越し、進学、転職、家族構成の変化があった時は、予定日を待たずに避難先・連絡先を見直します。

## まとめ

防災を始める時に、最初から大量の防災グッズを買う必要はありません。

まず、災害リスク、避難先・避難経路、家族の連絡方法、備蓄、非常持ち出し品、自宅内の安全の順で確認すると、必要な備えが見えやすくなります。

特にハザードマップは、**住所を入力して災害種別を確認するところまで**、避難先は**その災害に対応する場所か確認するところまで**を一つの作業と考えると、単なる「確認しましょう」で終わりません。
