# 防災は何から始める？家庭で最初に確認したい基本項目

防災を始めようと思っても、「非常食を買う」「防災バッグを用意する」「家具を固定する」など、やることが多く、何から始めればよいか分かりにくいものです。

**最初にやることは、防災用品を買いそろえることではありません。** まず自宅や生活圏で起こり得る災害を確認し、その災害からどこへ避難するか、家族とどう連絡するかを決めます。その後で、水・食料・携帯トイレ、防災バッグ、家具対策を足していくと、「自分の家に必要な備え」を判断しやすくなります。

この記事では、初めて防災を考える家庭向けに、**①災害リスク → ②避難先 → ③家族連絡 → ④自宅備蓄 → ⑤持ち出し品 → ⑥家の中の安全**の順で説明します。最後に、今日15分で始める方法と、家庭条件による優先順位の変え方も整理します。

## 結論：最初は「買う」より「確認する」

防災を始める時は、次の6段階で考えると、何を先にするべきかが見えやすくなります。

1. **自宅や生活圏の災害リスクを確認する** — 何に備える家なのかを知る
2. **避難先と避難経路を確認する** — 危険になった時の移動先を決める
3. **家族の連絡方法・集合方法を決める** — 離れて被災した時の行動を決める
4. **水・食料・トイレなどの備蓄を確認する** — 自宅で生活を続ける備えを作る
5. **非常持ち出し品を分けて準備する** — 避難時に持てる量へ絞る
6. **家具や住宅内の危険を減らす** — 被災直後のけがを減らす

この順番にする理由は、**災害の種類や避難方法が分からないまま商品だけを買うと、必要な物と不要な物を判断しにくいから**です。内閣府の令和8年版防災白書でも、食料・飲料水の備蓄、非常持ち出し品、ハザードマップ、避難場所・避難経路の確認が事前の備えとして示されています。

## 1. まず「自宅では何の災害に備えるか」を確認する

最初に決めたいのは、「何を買うか」ではなく**自宅では何の災害を優先して確認するか**です。そのために使うのがハザードマップです。

ただし、洪水・高潮・津波・土砂災害などを最初から全部同じ深さで調べると分かりにくくなります。そこで、まず身の回りの地形や場所を手掛かりに「先に見る災害」を絞り、その後に自宅・勤務先・学校などの住所を公式ハザードマップで確認します。

| 自宅・生活圏の特徴 | まず確認したい災害 | この表の使い方 |
| --- | --- | --- |
| 川の近く、低地、周囲より低い道路、地下・半地下がある | 洪水・内水氾濫 | 洪水・浸水の地図を先に開く |
| 海岸、湾岸、河口に近い | 高潮・津波 | 高潮と津波を分けて確認する |
| 崖、急な斜面、谷筋、山際に近い | 土砂災害 | 土砂災害警戒区域等を確認する |
| 火山の周辺や降灰が想定される地域 | 噴火・降灰 | 自治体の火山防災情報も確認する |
| どの地域でも | 地震 | 地域によって津波・液状化等も追加確認する |

この表だけで「川から離れているから洪水はない」「山から離れているから土砂災害はない」と判断するものではありません。**何の地図を先に見るかを決める入口**です。同じ市内でも想定は変わるため、最後は住所ごとに公式地図で確認します。

洪水の避難判断は[洪水キキクル・河川氾濫はいつ避難する？](article_b042.html)、土砂災害は[土砂キキクルと避難判断の見方](article_b036.html)、高潮は[高潮はいつ避難する？](article_b043.html)、津波は[津波からどう避難する？](article_b041.html)で具体的に確認できます。

### ハザードマップは、まずこの順番で開く

初めて見る場合は、国土交通省・国土地理院の**ハザードマップポータルサイト**を入口にすると探しやすくなります。

1. [ハザードマップポータルサイト](https://disaportal.gsi.go.jp/)を開く。
2. 「重ねるハザードマップ」の**住所から探す**に自宅住所を入力する。
3. 洪水、土砂災害、高潮、津波など必要な災害種別を切り替え、自宅周辺にどのような表示があるかを見る。
4. 地図の色だけで終わらず、凡例で想定浸水深や区域の意味を確認する。
5. 次に「わがまちハザードマップ」から都道府県・市区町村を選び、自治体が公開する最新のハザードマップも確認する。

「重ねるハザードマップ」は全国のリスクを同じ地図上で見比べる入口、「わがまちハザードマップ」は市区町村が作成した地図を探す入口です。

地震については、自治体が地震ハザードマップ、揺れやすさ、液状化等を別に公開している場合があります。ハザードマップポータルで確認できない項目は、市区町村の防災ページも確認します。

## 2. 災害が分かったら、避難先と避難経路を確認する

自宅で優先して見る災害が分かったら、次は**その災害からどこへ逃げるか**を確認します。ここで、近所の小学校や公民館を知っているだけでは、避難先を確認したことにはなりません。

内閣府は、命を守るため緊急に逃げる場所を「指定緊急避難場所」、危険がなくなるまで一定期間滞在する施設を「指定避難所」と区別しています。指定緊急避難場所は洪水、土砂災害、地震、津波など**災害種別ごとに指定**されるため、「学校だから洪水でも津波でも行けばよい」とは限りません。

避難先を知らない場合は、次の順で1か所目を探します。

1. 自治体のハザードマップまたは避難場所一覧を開く。
2. 自宅で優先確認した災害に対応する**指定緊急避難場所**を探す。
3. 自宅からそこまでの経路に、川沿い、地下道、低い道路、崖沿いなど、その災害で危険になりやすい場所がないか確認する。
4. 第1候補が使えない場合に備え、別方向の第2候補も確認する。
5. 家族が学校・勤務先にいる場合は、無理に自宅へ集合せず、それぞれの施設の災害時ルールも確認する。

地図で候補を見つけたら、平常時に一度歩いてみると、階段、暗い道、狭い歩道、ベビーカーや車いすで通りにくい場所など、地図だけでは分からない点を確認できます。

家族が別々の場所にいる場合の決め方は[家族で決めておきたい災害時の連絡・集合ルール](article_b030.html)で詳しく整理しています。

具体的な避難行動は災害の種類やその時の状況で変わります。発災時は、この記事ではなく、気象庁・自治体などの最新の公的情報を優先してください。

## 3. 次に、家族の連絡方法と集合方法を決める

避難先が分かっても、家族が別々の場所で被災すると「全員が自宅へ戻るのか」「今いる場所に留まるのか」で迷います。そのため、避難先の確認とセットで連絡・集合ルールを決めます。

内閣府は、平常時から家族・親族で安否確認方法や集合場所を確認しておくことを案内しています。

最低限、次の項目を決めておくと整理しやすくなります。

| 決めること | なぜ必要か |
|---|---|
| 連絡が取れない場合の集合候補 | 通信障害でも家族が別々に動き続けるのを防ぐため |
| 自宅へ戻れない場合の行動 | 帰宅経路が危険な時に無理に移動しないため |
| 学校・勤務先との連絡方法 | 家族が各施設にいる時の引き渡し・待機ルールを確認するため |
| 遠方の親族など家族共通の連絡先 | 家族同士で直接つながりにくい時の連絡先候補になるため |
| 災害用伝言サービスを使うか | 電話がつながりにくい場合の代替手段を決めておくため |

スマートフォンだけを前提にせず、「連絡が取れなかったらどうするか」まで決めておくことが重要です。具体的な決め方は[家族の連絡・集合ルール](article_b030.html)へ進めます。

## 4. 避難と連絡が決まったら、水・食料・トイレなどを備蓄する

ここまで確認してから、商品や備蓄品を考えます。自宅で生活を続けられる条件か、避難する可能性が高いかによって、準備の重点が変わるからです。

令和8年版防災白書では、食料・飲料水は最低3日分、できれば1週間分を備えることが望ましいとされています。

内閣府の家庭向けチェックページでは、飲料水の目安として「1人1日3リットル」が示されています。また、普段使う食品を多めに買い、使った分を買い足すローリングストックも紹介されています。

| 備えるもの | 主な役割 | 詳細 |
|---|---|---|
| 飲料水 | 飲用・最低限の生活用水 | [飲料水の備蓄](article_b025.html) / [商品例](/goods/water-food.html) |
| 食料 | 調理できない状況でも食事を確保する | [非常食の備蓄](article_b026.html) / [商品例](/goods/water-food.html) |
| 携帯トイレ・簡易トイレ | 断水・排水制限時の排泄手段を確保する | [携帯トイレの使い方と必要数](article_b003.html) / [商品例](/goods/toilet-hygiene.html) |
| 照明・情報手段 | 停電時の移動・情報確認に使う | [停電対策](article_b004.html) / [商品例](/goods/light-information.html) |
| 充電手段 | スマートフォン等を使い続ける | [商品例](/goods/power-charging.html) |
| 衛生用品・常用薬等 | 個人の健康・生活を維持する | 家族構成や持病に合わせて追加する |

必要量は家族構成や生活条件で変わります。まず不足項目を確認し、その後で商品を比較する方が、目的の分からない買い足しを減らせます。

> **Q&A:** [飲料水は何日分くらい備蓄すればいいですか？](qa.html#qa-water-days)

## 5. 自宅備蓄と非常持ち出し品を分ける

備蓄を考え始めると、全部を一つの「防災バッグ」に入れたくなりますが、**自宅に置く物と避難時に持つ物は役割が違います。**

| 分類 | 主な目的 | 考え方 |
|---|---|---|
| 自宅備蓄 | ライフライン停止時などに自宅で生活する | 水・食料・トイレ・生活用品などを中心にする |
| 非常持ち出し品 | 避難時に必要なものを持って移動する | 「すぐ必要」「ないと困る」ものを優先し、重くしすぎない |
| 日常携帯 | 外出中に被災した時の初動に使う | 無理なく普段から持てる範囲にする |

防災リュックの具体的な中身や重さは[防災リュックの中身は何を入れる？](article_b002.html)で整理しています。

## 6. 最後に、家の中で危険な場所を減らす

物を備えるだけでなく、地震等の直後にけがをしにくい環境も作ります。令和8年版防災白書では、家具・家電の固定や配置の見直しによって安全な空間を作ることが重要とされています。

| 確認場所 | 何を見るか |
|---|---|
| 寝室 | 寝ている場所へ倒れそうな家具がないか |
| 出入口 | 家具が倒れて避難経路をふさがないか |
| 高い収納 | 重い物が落下する位置にないか |
| 家具・家電 | 固定が必要な物がないか |
| 枕元・廊下 | 夜間でもライトを手に取れるか |

家具対策は[地震の家具転倒対策｜まず優先したい場所](article_b023.html)で具体的に確認できます。

## 今日15分で始めるなら、この5つ

ここまで読むと項目が多く見えますが、最初から全部終える必要はありません。**今日は「自宅の災害を1つ確認し、その結果から次の行動を1つ決める」まで**で十分です。

1. [ハザードマップポータルサイト](https://disaportal.gsi.go.jp/)を開き、自宅住所を入力する。
2. 洪水・土砂災害・高潮・津波のうち、自宅周辺で表示されるリスクを1つ確認し、災害名と表示内容をメモする。
3. 自治体の地図で、その災害に対応する避難場所を1つ確認する。
4. 家族へ「連絡できない場合にどうするか」を一度話す。詳しい決め方は[家族の連絡・集合ルール](article_b030.html)を見る。
5. 自宅の水・食料・携帯トイレを見て、足りない物を1つだけメモする。必要なら[水・非常食](/goods/water-food.html)や[携帯トイレ・衛生用品](/goods/toilet-hygiene.html)の商品例を確認する。

ここまで終われば、「何を買えばいいか」ではなく、**自分の家では何が起こり得て、どこへ逃げ、何が不足しているか**が見え始めます。

## 家庭によって優先順位はどう変わる？

6段階の基本順序は同じでも、**家族に代わりがきかない物や、住宅・地域固有の危険は先に追加**します。例えば、乳幼児がいる家庭なら一般的な非常食よりミルクやおむつが優先されることがあります。常用薬が必要な人なら、薬の情報確認を後回しにできません。

| 家庭・生活条件 | 追加で先に確認したいこと | 関連記事 |
|---|---|---|
| 乳幼児がいる | ミルク・離乳食・おむつ・衛生用品 | [赤ちゃんの防災備蓄](article_b034.html) |
| 高齢者・介助が必要な人がいる | 薬・補助用品・避難支援 | [高齢者の防災](article_b035.html) |
| 継続して薬・医療機器が必要 | 常用薬の情報、電源・受診先 | 主治医・薬剤師等への確認も行う |
| ペットがいる | 同行避難、フード、ケージ等 | [ペットの防災](article_b033.html) |
| 車で移動することが多い | 車載用品、冠水路を避けるルール | [車載防災用品](article_b029.html) |
| マンションに住んでいる | 共用部、停電・断水、ベランダ等 | [マンションの台風・水害対策](article_b022.html) |
| 浸水・土砂災害リスクがある | 避難開始の判断と経路 | [洪水避難](article_b042.html) / [土砂災害避難](article_b036.html) |

このように、一般的なリストへ自分の生活条件を重ねると、家庭ごとの優先順位が具体的になります。

## 最初の1週間は「確認→試す→足す」で進める

最初の1週間は、同じチェックリストを何度も眺めるのではなく、**確認した結果を実際に試し、不足だけを足す**流れにすると続けやすくなります。

- **1日目：確認** — ハザードマップと避難先を確認する。
- **次の買い物：足す** — 水・食品・携帯トイレなど、確認して不足していた物を補う。
- **週末：試す** — 避難経路を歩く、防災リュックを背負う、携帯トイレの使い方を確認する。
- **試した後：直す** — 夜道が暗い、荷物が重い、家族では通りにくい等の問題を修正する。

次に進む記事として、[防災リュックの中身](article_b002.html)、[携帯トイレの使い方](article_b003.html)、[家具転倒対策](article_b023.html)を使うと、この記事の6段階を具体化できます。

見直しを忘れないため、スマホのカレンダーに**年1回の防災確認**を繰り返し登録する方法もあります。加えて、引っ越し、進学、転職、家族構成の変化があった時は、予定日を待たずに避難先・連絡先を見直します。

## まとめ

防災を始める時に、最初から大量の防災グッズを買う必要はありません。

まず**自宅で何の災害に備えるかを調べる → その災害の避難先を決める → 家族の連絡方法を決める → 自宅備蓄 → 持ち出し品 → 家の中の安全**の順に進めます。そのうえで、乳幼児・高齢者・持病・ペット・住宅条件など、自分の家庭固有の条件を上乗せします。

今日やるなら、ハザードマップで自宅住所を検索し、災害を1つ確認するところから始めてください。そこから必要な備えを一つずつ具体化できます。
