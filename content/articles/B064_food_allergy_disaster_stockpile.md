# 食物アレルギーの防災備蓄｜食品は2週間分？避難所で困らない備え

食物アレルギーがある人の災害対策では、一般的な非常食を人数分そろえるだけでは不十分です。災害後は**普段食べているアレルギー対応食品が手に入りにくくなる可能性**があるため、本人が普段から食べている食品と、アレルギー情報を一緒に備えます。

農林水産省は、食事に配慮が必要な人について、普段使っている食品をローリングストックしながら**少なくとも2週間分**を家庭に備えることを勧めています。

この記事では、**備蓄量 → ローリングストック → 表示確認 → 持ち出し → 避難所での伝え方**の順で整理します。

## 結論：一般備蓄より長く「食品＋情報」を備える

食物アレルギーがある家庭では、次の点を先に確認します。

1. **普段食べて安全を確認している食品**を、少なくとも2週間分を目安にローリングストックする
2. 原材料・アレルゲン表示は、補充のたびに購入した現物で確認する
3. 何にアレルギーがあるかを、本人以外でも確認できる形にする
4. 避難バッグには、自宅備蓄とは別に初動分を入れる
5. 避難所では、必要な配慮を早めに伝える

「アレルギー対応」と表示された食品なら誰でも安全、という意味ではありません。**本人が避ける必要のある原因食物と、購入した食品の表示を照合する**ことが前提です。

## 1. 食品は少なくとも2週間を目安にする

一般家庭の食品備蓄では、最低3日分から1週間分が目安として示されています。一方、農林水産省は、アレルギー対応食品などの特殊食品は災害時に入手しにくくなるため、食事に配慮が必要な人は**少なくとも2週間分**を家庭にストックすることを勧めています。

この2週間は「専用の非常食を14日分買う」という意味ではありません。普段から食べている食品を少し多めに持ち、古いものから使って補充するローリングストックで維持します。

一般家庭向けの備蓄日数と食品の組み方は、[非常食は何日分必要？](article_b026.html)で整理しています。

## 2. 2週間分は「食数」だけでなく組み合わせで確認する

主食だけ14日分あっても、本人が食べられる主菜や補助食品が不足していれば使いにくくなります。

| 役割 | 確認すること |
|---|---|
| 主食 | 普段食べている米、パックご飯、パン、麺等で安全な物があるか |
| 主菜 | 肉・魚・豆等で食べられる缶詰・レトルト等があるか |
| 副菜 | 野菜系の保存食品やスープ等で食べられる物があるか |
| 補助食 | 間食等で普段から食べている物があるか |
| 飲料 | 水に加え、本人が日常的に必要とする飲料があるか |

**日常で実際に食べている食品を少し多めに持つ**方が、期限切れや食べ慣れない食品を減らしやすくなります。

## 3. 商品名ではなく、購入した現物の表示を確認する

同じブランドや同じ商品名でも、原材料や製造方法が変更される可能性があります。「○○不使用」等の表示だけで判断せず、購入した食品の表示を確認します。

補充時に見るのは、

- 原材料名
- アレルゲン表示
- 注意表示
- 賞味期限
- 保存方法

です。

**以前食べられた同名商品でも、今回も同じとは決めつけない**ようにします。

## 4. 避難バッグには初動分を分けて入れる

2週間分すべてを避難バッグへ入れる必要はありません。自宅備蓄とは別に、避難途中から避難先で最初に使う分を持ち出し用として準備します。

| 持ち出し候補 | 目的 |
|---|---|
| 本人が普段食べている食品 | 配給が届くまでの初動分 |
| 飲料水 | 移動中・食事等に使う |
| アレルギー情報カード等 | 周囲へ原因食物や注意点を伝える |
| 緊急連絡先 | 家族や医療機関等へ連絡する |
| 普段から必要な個人用品 | 本人に代替しにくい物を持ち出す |

普段の薬等がある場合は、**日常の管理方法や医療者から受けている指示に従って持ち出せる状態**にしておきます。

防災リュック全体の作り方は[防災リュックの中身は何を入れる？](article_b002.html)で確認できます。

## 5. 避難所では食物アレルギーがあることを早めに伝える

避難所で配慮された食品が用意される場合もありますが、**すべての避難所で必要な食品がすぐ確保されるとは限りません。**

受付や支援者には、

- 食物アレルギーがあること
- 避ける必要がある食品
- 本人が食べられる備蓄食品を持っているか
- 食事について個別確認が必要なこと

を必要に応じて伝えます。

子どもの場合は、本人が自分で説明できない場面も想定し、**表示カード等で情報が分かるようにする**方法もあります。

## 6. 配給・炊き出しは、原材料を確認できない場合に無理して食べない

災害時の配給食や炊き出しは、通常の商品包装と違い、原材料をその場で確認しにくい場合があります。

分からないときは、

- 配布担当者へ原材料や調理方法を確認する
- 確認できない食品は無理に食べない
- 自分の備蓄食品を優先する
- 必要な支援物資があることを避難所側へ伝える

と整理します。

**見た目だけで原因食物が入っていないと判断しません。**

## 7. 本人以外が分かる情報を準備する

乳幼児や子ども、自分で説明しにくい人の場合は、保護者や支援者がいない場面も想定します。

- 原因食物
- 緊急連絡先
- 本人が普段食べている食品
- 学校・園等で共有している注意事項
- 本人用食品の保管場所

を家族内で共有します。

学校・園・医療機関で既に使用しているカードや書類がある場合は、災害用に別の自己流ルールを作るのではなく、**既存の対応と矛盾しないようにします。**

乳幼児用品全体は[赤ちゃんの防災備蓄](article_b034.html)で確認できます。

## 8. ローリングストックは補充ルールまで決める

2週間分を一度そろえても、使った分を補充しなければ減っていきます。

続けやすい方法として、

- 1つ使ったら次の買い物で1つ補充する
- 月1回、本人用食品だけ在庫を確認する
- 賞味期限が近い物から普段の食事で使う
- 学校や職場へ置いている分も合わせて確認する
- 台風シーズン前などに家族でまとめて点検する

などがあります。

**非常食をしまい込むのではなく、普段の食生活の中で回す**ことが2週間分を維持しやすくするポイントです。

## 保存用チェックリスト

- [ ] 本人が普段食べている食品を把握している
- [ ] 少なくとも2週間分を目安に在庫を確認した
- [ ] 主食だけでなく主菜・副菜等も確認した
- [ ] 食品の原材料・アレルゲン表示を補充時に確認している
- [ ] 避難バッグに初動分の食品を入れた
- [ ] アレルギー情報を本人以外も確認できる
- [ ] 避難所で伝える内容を家族で共有した
- [ ] 原材料が不明な食品を無理して食べないことを共有した
- [ ] 月1回など補充ルールを決めた

## まとめ

食物アレルギーがある家庭では、災害時に普段の対応食品が手に入りにくくなることを前提に、**普段食べている食品とアレルギー情報**をセットで備えます。

食品は、農林水産省の要配慮者向け案内を参考に、ローリングストックで**少なくとも2週間分**へ近づけます。避難所ではアレルギーがあることを早めに伝え、原材料を確認できない食品を無理に食べないことも重要です。
