# 停電に備えて準備しておきたいもの｜照明・電源・情報収集を分けて考える

停電対策というと、最初に「大容量のポータブル電源が必要か」を考えがちです。しかし、停電して最初に困るのは、暗くて動けない、情報が取れない、家族と連絡できない、といった**初動の問題**です。

そこでこの記事では、まず停電対策を**照明・情報・連絡・充電・生活維持**の5つの役割に分けます。その中でも、**照明・情報・連絡の3つを最優先**に確保し、その後で充電、冷蔵庫、暑さ寒さ、医療機器など家庭ごとの課題を追加します。

## 結論：「最初の3つ」は優先順位、「5つの役割」は準備漏れを防ぐ分類

これまで「最初の3点」と「5つの役割」が別々に見えやすかったため、関係を整理します。

- **最初の3つ** — 停電直後の安全と情報確保に必要な優先順位
  1. 暗闇をなくす
  2. 情報を取る
  3. 連絡手段を残す
- **5つの役割** — 家庭の停電対策を漏れなく点検するための分類
  1. 照明
  2. 情報
  3. 連絡
  4. 充電
  5. 生活維持

つまり、**まず3つを確保し、その後5分類で不足を洗い出す**、という使い方です。ポータブル電源の容量を先に決める必要はありません。

## 1. 停電対策を5つの役割で確認する

| 役割 | 何を守るか | 備えの例 |
|---|---|---|
| 照明 | 暗所で安全に移動・作業する | 懐中電灯、ヘッドライト、ランタン、足元灯 |
| 情報 | 災害・停電・避難情報を得る | スマートフォン、ラジオ、自治体情報 |
| 連絡 | 家族・勤務先等と連絡する | スマートフォン、連絡先メモ、家族ルール |
| 充電 | 情報・連絡機器を使い続ける | モバイルバッテリー、予備電池、必要に応じて外部電源 |
| 生活維持 | 食事、温度、トイレ、医療等を維持する | 水、食品、携帯トイレ、防寒、医療機器対応等 |

この表を使って、「停電したら何が止まるか」「止まると何に困るか」を家庭ごとに確認します。

> **Q&A:** [停電対策は何から準備すればいいですか？](qa.html#qa-blackout-first)

## 2. 最初に照明を確保する

停電直後は、転倒物や割れたガラス、段差が見えにくくなります。最初に必要なのは、部屋全体を豪華に照らすことではなく、**安全に移動できる明かり**です。

| 用途 | 向いている照明 | 理由 |
|---|---|---|
| 移動 | 懐中電灯・ヘッドライト | 足元や進行方向を確認しやすい |
| 部屋で過ごす | ランタン型ライト | 周囲を広く照らしやすい |
| 夜間の足元 | 自動点灯型・足元灯等 | 寝起きでもライトを探す時間を減らせる |
| 予備 | 乾電池・充電池 | 電池切れで照明を失わないため |

枕元、玄関、廊下など、**暗闇でも手を伸ばせる位置**にライトを置きます。スマートフォンのライトだけに頼ると、通信・連絡に必要な電池を消費します。

→ [停電用ライト・ラジオの商品を比較する](/goods/light-information.html)

> **裸火を照明代わりにしない**
>
> 余震や転倒物がある状況で、ろうそく等の裸火を常用するのは火災リスクがあります。電池式照明を基本に考えます。

## 3. 次に「情報」と「連絡」を分けて備える

スマートフォンは、情報取得と連絡の両方に使えます。しかし、基地局障害、通信混雑、充電切れが重なる可能性があります。そのため、**スマートフォン1台だけで2つの役割を全部担わせない**ようにします。

| 目的 | 主な手段 | 代替を考える理由 |
|---|---|---|
| 災害・停電情報を知る | スマートフォン、ラジオ、自治体情報 | 通信障害や充電切れでも情報経路を残すため |
| 家族へ連絡する | スマートフォン、災害用伝言サービス等 | 通話が混雑する場合を想定するため |
| 連絡先・集合ルールを確認する | 紙のメモ | スマートフォンを開けない場合にも確認するため |

停電時にWi-Fiルーターが止まれば、自宅の固定回線経由の通信も使えない場合があります。平常時に「何が停電で止まるか」を一度確認しておくと、別手段が必要か判断しやすくなります。

## 4. 充電は「何を、どれだけ使うか」を先に決める

ポータブル電源や大容量バッテリーを先に選ぶのではなく、停電中も動かしたい機器を確認します。

| 対象 | まず確認すること | 備えの例 |
|---|---|---|
| スマートフォン | 1日にどの程度充電するか | モバイルバッテリー |
| ライト | 電池種類・連続点灯時間 | 予備電池 |
| ラジオ | 乾電池式かUSB充電式か | 予備電池・USB電源 |
| 医療・生活機器 | 停止できる時間があるか | メーカー・医療機関と非常電源を確認 |

充電ケーブルも電源本体と一緒に確認します。USB-C等、家族の機器に合う端子がなければ、電源があっても充電できません。

ポータブル電源は家庭によって有用ですが、必須とは限りません。容量と出力の考え方は[ポータブル電源は防災に必要？](article_b028.html)、商品例は[モバイルバッテリー・電源の商品紹介](/goods/power-charging.html)で確認できます。

## 5. 生活維持は「冷蔵庫・食事・トイレ・温度・医療」に分ける

照明・情報・連絡・充電を押さえた後で、家庭固有の生活課題を確認します。

### 冷蔵庫・食品

停電すると冷蔵庫・冷凍庫は徐々に温度が上がります。停電直後から何度も扉を開けると冷気が逃げやすくなるため、**扉を開ける回数を減らす**ことを考えます。

停電前に保冷剤を凍らせておく、冷蔵庫内を整理する、常温で食べられる食品を別に備えると、冷蔵庫への依存を減らせます。食品の状態は停電時間や室温で変わるため、見た目や時間だけで安全を断定しません。

詳しくは[停電したら冷蔵庫の食品はいつまで？](article_b045.html)で確認できます。

### 水・食事・トイレ

大規模災害では、停電と同時に水道、ガス、通信、店舗、物流も影響を受けることがあります。

| 備え | 停電時に必要な理由 |
|---|---|
| 飲料水・食品 | 店舗・調理手段が使いにくい場合に備える |
| 携帯トイレ | 断水や排水制限が同時に起きる場合に備える |
| 衛生用品 | 水が使いにくい状況でも衛生を保つ |
| 常用薬・個別用品 | 本人に代替しにくい物を確保する |
| 現金・連絡先 | 決済・通信障害時の代替を持つ |

→ [水・非常食の商品例](/goods/water-food.html)  
→ [携帯トイレ・衛生用品](/goods/toilet-hygiene.html)

### 真夏は「電源」だけでなく移動判断まで考える

真夏にエアコンが止まると、室温管理が安全に直結する場合があります。大容量電源でエアコンを動かすことだけに頼らず、水分・冷却手段と、**自宅で安全を保てない場合にどこへ移動するか**まで確認します。

詳しくは[真夏に停電したらどうする？](article_b047.html)で整理しています。

### 冬は「暖房器具を増やす」だけでなく、体温を逃がさない

冬の停電では、電源を必要としない対策から始めると停電直後から使えます。

| 対策 | 目的 |
|---|---|
| 重ね着、帽子、手袋、靴下 | 体から熱が逃げにくくする |
| 毛布・寝袋・防寒シート | 睡眠・休息時の保温を補う |
| 着替え | 濡れた衣類のまま過ごさない |
| 床の敷物 | 床からの冷えを減らす |
| 使う部屋を絞る | 暖かさを保ちやすくする |

乳幼児、高齢者、持病のある人など、寒さの影響を受けやすい人の状態は早めに確認します。自宅で安全を保ちにくい場合は、自治体が開設する避難所・一時滞在施設や、安全に暖を取れる場所への移動を検討します。

### 燃焼式暖房・携帯発電機は一酸化炭素と火災に注意する

石油・ガス等を燃焼する器具は、取扱説明書どおりの換気・給排気・可燃物との距離を守ります。**携帯発電機は屋内、車庫、換気が不十分な場所で使用しません。** 炭・コンロ・発電機など本来暖房用ではないものを室内で燃焼させる方法も避けます。

### 医療機器・介護用品は一般家庭より先に個別確認する

在宅酸素、吸引器、電動ベッド、人工呼吸器など、電気停止が健康に直結する機器がある家庭では、一般的なモバイルバッテリーの考え方だけでは不十分です。

機器の消費電力、内蔵バッテリーの稼働時間、外部電源の対応可否、停電時の連絡先を、**医療機関・機器メーカー・訪問看護等と平常時に確認**します。家庭用蓄電池やポータブル電源が使えるかどうかも、電圧・波形・接地等の条件があるため自己判断しません。

また、エレベーターが止まる集合住宅では、物資運搬の負担が増えます。高層階では、水や食料等の在宅備蓄を停電前に確認します。

## 6. 地震による停電では「復電後の火災」も確認する

内閣府は、地震後の電気火災対策として感震ブレーカー等の普及を進めています。感震ブレーカーだけで地震火災が完全に防げるわけではなく、家具固定、耐震化、火気管理等と組み合わせます。

| 確認 | 理由 |
|---|---|
| 感震ブレーカーの種類・適合 | 自宅設備に合うか確認するため |
| 停電時に使える照明 | 自動遮断後の暗闇に備えるため |
| 復電前の家電・配線 | 損傷した機器へ通電しないため |
| 焦げ臭さ・火花・浸水 | 異常がある場合に通電を避けるため |

浸水、焦げ臭さ、火花、配線損傷などがある場合は通電を試さず、電力会社や電気工事事業者等へ相談します。

## 7. 停電したら「自宅だけか、地域全体か」を分ける

照明が消えた時は、周囲の住宅や共用部も消えているか確認します。

- **自宅だけ**：ブレーカーや漏電遮断器等が作動している可能性があります。原因が分からないまま何度も入れ直しません。
- **地域全体**：電力会社の停電情報や自治体情報を確認し、復旧が長引く場合は生活維持策へ切り替えます。

安全に確認できない場合や異臭・浸水等がある場合は、無理に設備を操作しません。

## 停電前に10分で確認するチェック

| 確認 | できている？ |
|---|---|
| 枕元・玄関にすぐ使えるライトがある | □ |
| ライト・ラジオの予備電池がある | □ |
| スマホとモバイルバッテリーを充電できる | □ |
| スマホ以外の情報手段がある | □ |
| 家族の連絡方法・連絡先メモがある | □ |
| 水・食品・携帯トイレがある | □ |
| 季節に応じた暑さ・寒さ対策がある | □ |
| 医療・生活機器の停電時対応を確認している | □ |

不足が見つかったら、大きな機器を先に買うのではなく、**役割ごとに足りないものを一つずつ補う**と整理しやすくなります。

## 一度、短時間の「停電訓練」をしてみる

平常時に30分程度、主照明を使わずに過ごしてみると、ライトの置き場所、スマートフォンの充電残量、トイレまでの動線など、一覧表だけでは気づきにくい不足が見えます。

冷蔵庫や医療機器など止めてはいけない設備は対象外にし、**安全な範囲の模擬停電**として行います。見つかった不足は、その場でカレンダーや買い物リストへ登録すると忘れにくくなります。

## まとめ：最初の3つを守り、5つの役割で不足を探す

停電対策の最優先は、**照明・情報・連絡**です。これが「最初の3つ」です。その後、**照明・情報・連絡・充電・生活維持**の5分類で家庭全体を確認します。

この順番にすると、ポータブル電源を買うこと自体が目的にならず、家庭に必要な対策を判断しやすくなります。最後に、冷蔵庫、暑さ寒さ、医療機器など、自宅固有の条件を追加してください。
