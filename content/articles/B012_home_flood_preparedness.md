# 自宅の浸水にどう備える？住宅の水害対策入門

住宅の浸水対策は、土のうを買うことだけではありません。まず**自宅では何の水害が起こり得るか**を確認し、次に水が入りやすい場所、先に移す家財、止水できる場所、排水の異常、避難を打ち切る条件まで決めます。

この記事では、**リスク確認 → 水の入口 → 家財・電気 → 土のう・止水板 → 排水逆流 → 住宅条件 → 避難判断 → 被害後の記録**の順で整理します。

## 結論：家を守る作業より先に「いつ避難へ切り替えるか」を決める

住宅水害への備えは、次の順で考えると整理しやすくなります。

1. 洪水・内水・高潮・土砂災害など、自宅のリスクを確認する
2. 玄関・窓・通気口・車庫など、水が入りやすい場所を把握する
3. 薬・重要書類・小型家電など、先に高所へ移す物を決める
4. 土のう・止水板を使うなら、平時に寸法・必要数・設置方法を確認する
5. トイレや排水口の逆流にも備える
6. 戸建て・マンション・地下住宅など、建物条件に応じて備蓄・設備を分ける
7. 道路冠水・強風・避難情報などを**住宅作業の中止条件**にする
8. 被害後に備え、保険内容と記録方法も確認する

「最後の土のうを置いてから避難する」のではなく、**人が安全に動ける時間を住宅作業より優先**します。

## 1. 自宅の水害を1種類だと思わない

同じ大雨でも、水が来る仕組みは異なります。

| リスク | 何が起きるか | 家庭でまず見ること |
|---|---|---|
| 洪水 | 河川が増水・氾濫して浸水 | 洪水浸水想定区域、浸水深、継続時間 |
| 内水氾濫 | 排水能力を超え、道路・宅地に水がたまる | 内水マップ、低い道路、排水口 |
| 高潮 | 台風等で海面が上昇し沿岸部が浸水 | 高潮マップ、河口・沿岸との位置 |
| 土砂災害 | 斜面崩壊等で住宅・経路が危険になる | 土砂災害警戒区域、崖・谷筋 |

ハザードマップポータルと自治体の地図を使い、**自宅住所で複数の災害種別を確認**します。ハザードマップの開き方から確認したい場合は[防災は何から始める？](article_sample.html)で手順を説明しています。

### 浸水深だけでなく、継続時間と避難経路も見る

同じ浸水深でも、水が短時間で引く地域と長く残る地域では、停電・断水・在宅生活への影響が変わります。

自宅地点だけでなく、

- 近くの川
- 低い道路・アンダーパス
- 地下空間
- 避難先までの経路
- 車の駐車場所

も一緒に確認します。

地図に色がないことを「絶対に浸水しない」と解釈せず、自治体の最新情報を確認します。

## 2. 水が入りやすい場所を、平時に家の外から確認する

ハザードを確認したら、次は**自宅のどこから水が入り得るか**を見ます。

| 場所 | 確認すること |
|---|---|
| 玄関・勝手口 | 開口幅、段差、止水用品を置けるか |
| 掃き出し窓 | サッシ下端、外側の水のたまり方 |
| 床下換気口・通気口 | 低い位置に開口がないか |
| 地下・半地下への階段 | 水が流れ込みやすい形になっていないか |
| 車庫・シャッター下 | 周囲より低くないか、出入口から流入しないか |
| 側溝・雨水ます・ベランダ排水 | 落ち葉・ごみで詰まっていないか |

大雨中に確認するのではなく、**梅雨・台風期の前など安全な日に写真を撮っておく**と、家族で止水位置を共有しやすくなります。

排水口の清掃も平時に行います。雨が強くなってから側溝へ近づいて詰まりを取る作業はしません。

## 3. 1階では「失うと困る物」と「短時間で動かせる物」から上へ移す

水の入口が分かったら、浸水前に何を守るかを決めます。大雨のたびに家財をすべて上階へ移すのは現実的ではありません。

優先しやすいのは、

1. 常用薬・医療用品
2. 重要書類
3. 写真・データ機器
4. 小型家電
5. 衣類・寝具など、短時間で動かせる物

です。

大型家具・大型家電を大雨直前に無理に動かすことは避けます。**失うと生活再建に困る物と、安全に動かせる物を先に決める**方が実行しやすくなります。

### コンセント・電源タップも低い位置を確認する

床置きの電源タップ、延長コード、低い位置の家電は、浸水前の安全な段階なら電源を切って高い位置へ移せる物を移します。

ただし、すでに床が濡れている、浸水が始まっている場合は電気設備に触れません。**水が入ってから電源を切りに戻る行動は避けます。**

給湯器、室外機、蓄電池、EV充電設備などの高所化・防水・止水は設備ごとに施工条件が異なるため、メーカー・施工会社等へ確認します。

## 4. 土のう・止水板は「どこを、何cmふさぐか」から決める

土のうの必要数を「玄関なら○袋」と全国一律には決められません。開口幅、土のうの大きさ、重なり、段数で変わるためです。

### 必要数は「開口幅 ÷ 1袋の有効幅」で概算する

例えば玄関の開口部が**90cm**あり、実際に使う土のうを平らにして重ねたとき、1袋が有効に覆う幅を**40cm**と仮定します。

- 90 ÷ 40 = 2.25
- 端数を切り上げ、**1段につき最低3袋**が概算の出発点
- 2段なら単純計算で6袋だが、端部・重ねしろ・段のずらし方で追加が必要な場合がある

40cmは説明用の仮定です。**購入・配布される土のうの実寸で計算し直してください。** この計算は備蓄数の見積もりであり、その数で浸水を防げるという性能保証ではありません。

### 置き方は自治体・製品の案内を優先する

自治体の設置例では、袋をすき間なく平らに並べ、複数段では継ぎ目をずらす方法などが示されています。地域や資材で方法は異なるため、自治体・製品の案内を優先します。

平時に一度並べると、必要数だけでなく、**保管場所から運べるか、家族1人でも設置できるか、何分かかるか**まで確認できます。

### 止水板は幅だけでなく、床・壁・固定方法を見る

止水板・防水板では、

- 開口幅
- 必要な高さ
- 床・壁との接触部
- 固定方法
- 設置に必要な時間

を確認します。寸法が近いだけで選ばず、メーカーの適合条件を確認します。

土のう・止水板は被害を減らす補助手段です。道路や庭が冠水している、強い流れがある、避難が必要な段階では、**追加設置を続けず安全確保へ切り替えます。**

## 5. トイレ・排水の「ゴボゴボ」は逆流の前兆になる場合がある

大雨時は、家の中へ雨が入っていなくても、下水道側の水位上昇や管内の空気で排水が不安定になることがあります。

例えば、

- トイレからゴボゴボ音がする
- 流れが悪くなる
- 水を流すと便器の水位が押し戻される

といった変化です。

この場合、「詰まり」と決めつけて大量の水を繰り返し流さず、地域の下水道担当部署などの案内を確認します。大雨時に浴室・洗濯など大量排水を控えるよう案内される地域もあります。

### 水のうを使う応急例もある

自治体によっては、便器や浴室・洗濯機の排水口に水を入れた袋を置き、押し戻しを抑える方法を紹介しています。袋の大きさ・作り方を全国共通の方法として固定せず、居住自治体等の案内を確認します。

排水してよいか分からない場合に備え、携帯トイレへ切り替えられるようにします。具体的な備蓄品は[携帯トイレ・衛生用品を比較する](goods_toilet_hygiene.html)で確認できます。

## 6. 住宅の種類で、浸水以外の困り方も変わる

| 住宅 | 特に確認したいこと |
|---|---|
| 戸建て | 1階開口部、床下、屋外設備、上階退避可否 |
| マンション低層階 | 住戸浸水、共用部・地下設備、管理会社ルール |
| マンション高層階 | 停電・断水・エレベーター停止、備蓄運搬 |
| 地下・半地下住宅 | 急な流入、避難経路、止水設備 |

マンション固有の確認事項は[マンションの台風・水害対策](article_b022.html)で詳しく整理しています。

### 上階へ残る場合も、備蓄を1階だけに集中させない

建物が安全で上階にとどまれる場合でも、1階が浸水するとトイレ・冷蔵庫・玄関などを使えなくなる可能性があります。

上階に、

- 飲料水
- 非常食
- ライト
- 携帯トイレ
- モバイルバッテリー
- 常用薬

の一部を分散しておくと、1階へ降りられない場合にも対応しやすくなります。

具体的な商品は[水・非常食](goods_water_food.html)、[ライト・ラジオ](goods_light_information.html)、[電源・充電](goods_power_charging.html)で確認できます。

## 7. 家族の避難時間を足し、「住宅作業の中止条件」を決める

高齢者、乳幼児、要介護者、ペットがいる家庭では、抱っこ、車いす、薬、ペットキャリーなどで移動準備に時間がかかります。

「止水板を付け終えてから避難」「家電を全部上げてから避難」と固定せず、**人の避難準備と住宅対策を並行**します。

住宅作業を中止する条件として、例えば、

- 道路・庭に水がたまり始めた
- 強風・雷で屋外作業が危険になった
- 自治体から避難情報が出た
- 日没が近づいた
- 家族の移動に必要な時間を考えると余裕が小さい

などを平時に決めます。

家族が不在の場合も、外出中の人へ「家を守るため戻ってきて」と求めません。**一人なら何を諦めるか**まで決めておく方が安全です。

洪水時の避難判断は[洪水キキクル・河川氾濫はいつ避難する？](article_b042.html)で確認できます。

## 8. 保険と被害記録は「被害を防ぐ対策」と分けて準備する

火災保険に水災補償があるか、建物・家財のどちらが対象かを平常時に確認します。

被災後は安全確保後、可能なら、

- 建物・部屋全体
- 浸水高さ
- 損傷箇所
- 家財

を記録します。

保険は浸水を防ぐ仕組みではありません。**物理的な浸水対策、早期避難、被害後の経済的備え**を別々に持ちます。

火災保険の水災補償は[火災保険の水災補償とは？](article_b013.html)、被害写真の残し方は[自宅が浸水した後、片付ける前に記録したいもの](article_b015.html)で確認できます。

## 9. 見直しは梅雨前・台風用品点検・住宅変更と結び付ける

河川整備やハザードマップ更新、家族構成・住宅設備の変化で、以前の計画が合わなくなることがあります。

「年1回思い出す」のではなく、

- 梅雨前の排水口清掃
- 台風用品の確認
- 引っ越し
- 住宅改修
- 家族構成の変化

を見直しのきっかけにします。スマートフォンのカレンダーへ、毎年の梅雨前などに繰り返し予定を入れる方法もあります。

## まとめ：住宅対策は「水を完全に止める」より、被害と避難遅れを減らす

住宅の水害対策は、土のうや止水板だけで完結しません。

**自宅のリスク → 水の入口 → 移す家財 → 止水 → 排水 → 建物条件 → 避難の中止条件**までを一つの計画にすると、大雨時に「何から始めるか」で迷いにくくなります。

家の対策が未完成でも、危険が高まったら作業を打ち切り、人の安全を優先します。
