# 地震保険の基本｜火災保険との違いを整理

地震保険は、地震・噴火・これらによる津波を原因とする住宅や家財の損害に備える保険です。**火災保険だけでは地震を原因とする火災・損壊等が原則として補償されない**ため、火災保険とは役割を分けて理解します。

この記事では、**地震保険とは何か → 火災保険との違い → 補償対象と金額 → 自分の証券で見る場所 → 加入を考える軸 → 被災後の行動**の順で整理します。

## 結論：地震保険は火災保険に付帯し、生活再建資金の一部を支える制度

地震保険は単独では契約せず、火災保険に付帯します。保険金額は火災保険金額の**30〜50％の範囲**で設定し、限度は建物5,000万円・家財1,000万円です。

住宅の再建費を全額そのまま補う設計ではないため、**被災後の生活安定に必要な資金の一部をどう補うか**という視点で考えます。

## 1. 火災保険と地震保険は「原因」で分ける

火災保険に加入していても、地震が原因の損害は同じ扱いではありません。

| 原因・損害 | 基本的に確認する保険 |
|---|---|
| 通常の火災、風災、水災等 | 火災保険の該当補償 |
| 地震による住宅損壊 | 地震保険 |
| 地震を原因とする火災 | 地震保険 |
| 噴火による住宅・家財損害 | 地震保険 |
| 地震・噴火による津波 | 地震保険 |

火災保険の商品によっては「地震火災費用保険金」等が付く場合がありますが、**地震保険そのものとは補償内容・支払条件が異なります。** 証券では別項目として確認します。

## 2. 地震保険は建物と家財を分けて契約する

対象は居住用建物と生活用家財が基本です。建物側だけ地震保険を付け、家財側には付けていない契約もあり得ます。

| 保険対象 | 主な確認内容 |
|---|---|
| 建物 | 住宅本体について地震保険が付いているか |
| 家財 | 家具・家電等について地震保険が付いているか |
| 賃貸住宅 | 入居者は自分の家財契約を確認する |
| 自動車 | 地震保険の家財には含まれない。自動車保険側を確認する |

**「地震保険に入っているか」だけでなく、「建物と家財のどちらに付いているか」まで見る**ことが重要です。

車の地震損害は[地震で車が壊れた場合、自動車保険はどう考える？](article_b018.html)で整理しています。

## 3. 保険金額は火災保険の30〜50％で設定する

損保協会の現行案内では、地震保険金額は火災保険金額の**30％〜50％の範囲**で設定し、建物5,000万円、家財1,000万円が限度です。

このため、火災保険と同額まで地震保険を設定する制度ではありません。住宅ローン、仮住まい、家財買い直し、当面の生活費等を考え、地震保険金が家計のどの部分を補うかを確認します。

## 4. 保険金は修理費の実額払いではなく、損害区分で決まる

現行制度では、損害の程度を**全損・大半損・小半損・一部損**の4段階に区分します。認定された区分に応じて、地震保険金額の一定割合が支払われる仕組みです。

| 損害区分 | 支払額の基本 |
|---|---:|
| 全損 | 地震保険金額の100％ |
| 大半損 | 地震保険金額の60％ |
| 小半損 | 地震保険金額の30％ |
| 一部損 | 地震保険金額の5％ |

実際の損害額や時価が上限になる場合があります。個々の家具の購入価格や修理見積額を単純合計して支払額が決まる制度ではありません。

損害認定は保険会社の確認に基づくため、自分で「全損だろう」「一部損だろう」と決めつけず事故連絡を行います。

## 5. 自分の証券はこの順で確認する

制度を理解したら、自分の契約へ落とし込みます。

| 順番 | 証券で見ること | なぜ必要か |
|---|---|---|
| 1 | 火災保険に地震保険が付帯しているか | そもそもの加入有無を確認するため |
| 2 | 建物・家財のどちらに付いているか | 被害物によって対象が分かれるため |
| 3 | 地震保険金額 | 被災時に受け取れる規模を把握するため |
| 4 | 割引の適用 | 建物条件と提出済み資料を確認するため |
| 5 | 保険会社・代理店の連絡先 | 被災後に証券を探し回らないため |

地震を原因とする火災について「地震保険」と「地震火災費用」等の両方が記載されている場合は、名称だけで同じ補償と思わず、それぞれの条件を確認します。

## 6. 割引は建物条件と確認書類をセットで見る

地震保険には、免震建築物割引、耐震等級割引、耐震診断割引、建築年割引があります。重複適用ではなく、所定の確認資料が必要です。

建物の耐震性能が高いと思っていても、証明書類が契約へ反映されているとは限りません。更新時は、**割引名称・建物情報・提出済み資料が現在の状態と合っているか**を確認します。

## 7. 加入するかは「地震が起きる確率」だけでなく資金不足で考える

地震は全国どこでも起こり得るため、「ハザードマップの色が薄いから不要」と単純には決めません。

加入判断では、被災後にどれくらい自己資金が不足するかを考えます。

| 確認すること | 考える理由 |
|---|---|
| 住宅ローン残高 | 住宅を失っても返済が残る可能性があるため |
| 仮住まい費用 | 自宅へ戻れない期間の支出を考えるため |
| 家財の買い直し | 生活再開に必要な支出を考えるため |
| 貯蓄・予備資金 | 保険なしでどこまで対応できるか見るため |
| 家族人数・住宅形態 | 必要な生活再建費が家庭ごとに違うため |
| 賃貸・持家 | 建物と家財の必要補償が異なるため |

「保険金だけで完全再建できないから無意味」でも、「地震が心配だから最大限付ければよい」でもなく、**不足する資金と保険料を比較**します。

## 8. 被害を受けたら「安全→記録→連絡→案内確認」の順

地震後は保険手続きより人の安全が先です。

1. **安全確保** — 余震、火災、津波、倒壊等の危険を避ける
2. **記録** — 安全な範囲で建物・家財の全景と損傷部を撮る
3. **連絡** — 保険会社・代理店へ事故連絡する
4. **案内確認** — 必要書類・損害確認・片付けの進め方を確認する

安全や衛生のため片付けが必要な場合は、可能な範囲で写真・品名・数量等を残します。ただし、余震や津波等の危険区域へ撮影のため戻りません。

## 9. 公的支援と地震保険は別の仕組み

罹災証明や被災者生活再建支援制度等の公的支援と、民間の地震保険は手続き・利用条件が異なります。

一方が使えるからもう一方は使えない、と自己判断せず、**自治体の支援窓口と保険会社を別々に確認**します。

## 更新時の確認チェック

- [ ] 火災保険に地震保険を付帯している
- [ ] 建物・家財のどちらに付いているか分かる
- [ ] 地震保険金額を把握している
- [ ] 割引の建物情報・確認資料が現在と合っている
- [ ] 保険会社・代理店の連絡先を家族が分かる

## まとめ

地震保険は、**火災保険とは別に、地震・噴火・津波を原因とする住宅・家財損害へ備える制度**です。単独契約ではなく火災保険へ付帯し、建物と家財を分け、保険金額も火災保険の30〜50％の範囲で設定します。

まず制度の基本を理解し、その後で自分の証券を**加入有無 → 建物/家財 → 保険金額 → 割引 → 連絡先**の順に確認してください。加入判断は、被災後に不足する資金を基準に考えると整理しやすくなります。
