# 線状降水帯とは？過去事例・発生数・多い地域・雨量記録をデータで見る

線状降水帯は、**発達した雨雲が列をつくり、同じ場所に数時間かかり続けて大雨をもたらす現象**です。防災情報としてよく聞くようになったのは比較的新しい一方、現象そのものは以前から起きており、2014年の広島や2017年の九州北部なども後年の解析で線状降水帯を伴う豪雨として整理されています。

先に結論をまとめると、**短期の発表件数だけでは「近年増えている」とは断定できません**。一方で、気候シミュレーションでは温暖化に伴って発生回数が増える方向が示されています。また、発生頻度は全国一様ではなく、九州～南西諸島、四国南東斜面、紀伊半島で高い傾向があります。現在進行中の大雨では、過去事例よりもキキクルや自治体の避難情報など最新の防災情報を優先してください。2026年だけでも九州北部、千葉、北陸、愛知など複数地域で発生事例があり、古い代表例だけで現状を理解しないことも重要です。

## まず押さえたい5つの事実

| 項目 | 確認できること | 確認ポイント |
|---|---|---|
| 2014年8月 広島 | 三入で1時間101.0mm、3時間217.5mm、24時間257.0mm | いずれも当時の**観測史上1位**。後年、線状降水帯事例として整理 |
| 2017年7月 九州北部 | 朝倉で1時間129.5mm、日降水量516.0mm | **観測史上1位**。線状降水帯という言葉が広く知られる契機の一つ |
| 2018年7月豪雨 | 四国で期間1800mm超。多くの地点で24・48・72時間雨量が観測史上1位 | 一地点の短時間雨量だけでなく、広域・長時間の異常さが特徴 |
| 2023年5月25日 | 気象庁の現行「線状降水帯の事例」掲載系列の起点 | **制度上の起点であり、災害事例ではない**。これ以前と以後を単純な年間件数で比較しない |
| 将来気候 | 過去実験23回/年 → 2℃上昇31回 → 4℃上昇38回 | **気候シミュレーション**。現在の観測年次数ではない |

表で押さえたいのは、雨量の大きさだけでなく「その地域でどれほど異例だったか」です。100mmという数字だけを見ても、その地点で普段どの程度雨が降るのか、何時間の雨量なのかで意味が変わります。そこで、**1時間・3時間・24時間・期間総雨量、観測史上順位、平年月降水量との比較**を並べて見ます。

また、同じ豪雨でも「短時間に猛烈な雨が集中したのか」「数日間の総雨量が極端に多かったのか」で災害の性質は変わります。1時間雨量だけでなく、3時間・24時間・期間総雨量、過去最高値との差、平年値との比率を並べることで、その事例が短時間型なのか長時間型なのかを読み分けられます。同じ物差しで見ると、短時間型の豪雨なのか、長時間に雨が積み重なった豪雨なのかを比較しやすくなります。

## 2026年の主な発生例

2026年は、6月3日の徳島・和歌山・静岡等、6月24日の鹿児島、7月2日の九州北部5県、7月5日の熊本、8月13〜14日の千葉、8月27日の石川・富山など、複数地域で発生が確認されています。9月8日の愛知の大雨も直近事例として確認し、地域別・県別記事へ反映します。**予測だけが出たケースは発生事例に数えません。**

## 線状降水帯は「発達した雨雲が同じ場所にかかり続ける」現象

気象庁は、次々と発生する発達した積乱雲が列をなし、数時間にわたってほぼ同じ場所を通過または停滞することで作られる、**長さ50～300km程度、幅20～50km程度の線状に伸びる強い降水域**を線状降水帯と説明しています。

現在の「線状降水帯の事例」一覧では、前3時間100mm以上の分布域の面積、形状、領域内最大雨量、災害危険度など複数条件によって掲載事例を抽出しています。これは、ニュース映像を見て「雨雲が線に見える」というだけで判定するものではありません。

### 図で確認：線状降水帯の全体イメージ

暖かく湿った空気が流れ込み、発達した積乱雲が次々に発生して列をつくると、**同じ地域へ強い雨が繰り返しかかる**ことがあります。図では「空気の流入 → 雨雲の発達 → 同じ場所で強雨が続く」という流れを模式化します。

## 古い豪雨も、後年の解析で線状降水帯と分かることがある

過去の豪雨を扱うときは、**当時の呼び方と後年の解析を分ける**必要があります。例えば2014年8月の広島豪雨は、当時の気象速報では「広島県の大雨」として雨量や土砂災害が整理されています。その後の気象庁資料では、線状降水帯が発生した顕著な大雨の事例の一つとして紹介されています。

したがって、古い事例は「当時から線状降水帯情報が出ていた」とは扱えません。**当時の名称と、後年の解析による位置付けを分けて読むこと**が重要です。

## 短期の発生件数だけでは「増えている」と断定できない

**現在の短い公式事例系列だけでは、線状降水帯が長期的に増えているとは断定できません。** 気象庁の現行事例一覧は、顕著な大雨に関する気象情報の新たな運用を始めた**2023年5月25日13時以降**を掲載対象としています。また、検出・危険度の条件や予測情報も改善され続けています。

そのため、「2023年は○件、2025年は○件だったから増えた」という短期比較だけでは長期傾向を判断できません。判断するときは、次の3種類のデータを分けます。

1. **現行基準で検出・公表された事例**
2. **過去の豪雨を後から解析して線状降水帯と位置付けた事例**
3. **温暖化した将来気候を計算したシミュレーション**

一方、**将来については増える方向が示されています。** 気象庁の気候シミュレーションでは、日本全国の平均年間発生回数が過去実験23回に対し、2℃上昇実験31回、4℃上昇実験38回となっています。これは温暖化した将来気候で発生が増える可能性を示す重要な結果ですが、**現在すでに23回から38回に増えたという観測結果ではありません**。

## 発生頻度が高いのは九州～南西諸島・四国南東斜面・紀伊半島

気象庁の解析では、線状降水帯は**紀伊半島、四国の南東斜面、九州から南西諸島**で発生頻度が高い傾向が示されています。一方で、近年は東北や北陸でも顕著な事例があります。2024年7月には山形県で同日に2回線状降水帯が発生し、2024年9月には能登で猛烈な雨となりました。

ただし、東北や北陸でも発生事例があり、**「西日本だけの現象」ではありません**。自分の地域の危険度は、その日のキキクルや自治体情報で確認する必要があります。

## 雨量は「何mm」より時間尺度と過去記録で見る

線状降水帯による雨の異例さを見るときは、**観測史上1位かどうか**も重要な手掛かりになります。例えば2017年7月5日の朝倉は1時間129.5mm、日降水量516.0mmで観測史上1位でした。2026年8月の千葉豪雨では、千葉で1時間115.0mm、24時間367.0mmなど観測史上1位を更新しました。

また、2018年7月豪雨では7月平年値の2～4倍となる地点、2024年9月の能登では平年9月月降水量の2倍を上回る地点がありました。こうした**普段の月降水量との比較**は、単純なmm値より災害の異例さを把握しやすい指標です。

## 「100年に一度」と「観測史上1位」は同じ意味ではない

災害時には「50年に一度」「100年に一度」「これまでに経験したことのない大雨」など、さまざまな表現が使われます。しかし、それらは同じ意味ではありません。気象庁の確率評価、公的機関の説明、報道上の比喩を混同すると歴史資料として不正確になります。

したがって、「100年に一度」と「観測史上1位」は置き換えられません。年表では正式名称と公的資料に残る表現を分け、確率表現は出典が確認できる場合だけ扱います。

## 線状降水帯発生情報＝警戒レベル5ではない

2026年5月29日から、防災気象情報の名称や体系が変わりました。線状降水帯については、半日程度前の**「気象解説情報（線状降水帯半日前予測）」**、発生の2～3時間前を目標とする**「気象防災速報（線状降水帯直前予測）」**、実際に発生して災害危険度が急激に高まっているときの**「気象防災速報（線状降水帯発生）」**があります。

| 情報 | 目安となる時期 | 確認したいこと |
|---|---|---|
| 線状降水帯半日前予測 | 半日程度前 | ハザードマップ、避難先・経路、予定変更 |
| 線状降水帯直前予測 | 発生の2～3時間前を目標 | 自治体の避難情報、キキクル、河川情報 |
| 線状降水帯発生 | 発生時 | 周囲の状況を確認し、危険な場所では速やかに安全確保 |

### 図で確認：どの情報をどう見るか

半日前予測・直前予測・発生情報は、それだけで避難行動を決める情報ではありません。実際の判断では、**①気象情報で大雨の見通しを知る → ②キキクルで自分の周辺の危険度を確認する → ③自治体の避難情報や河川情報で行動を決める**、という順に見ると整理しやすくなります。

特に、自治体から避難指示がまだ出ていなくても、警戒レベル3相当・4相当の防災気象情報やキキクルで危険が高まっている場合は、自分で早めに避難判断することが重要です。

ここで注意したいのは、**線状降水帯発生情報＝警戒レベル5ではない**ことです。気象庁は線状降水帯発生情報を、警報などの警戒レベル相当情報を補足する情報として、**警戒レベル4相当以上の状況**で発表します。

警戒レベルは、自治体の避難情報と住民が取る行動を結び付ける5段階の基準です。大雨に関する気象庁の情報も、2026年から「レベル3大雨警報」「レベル4大雨危険警報」「レベル5大雨特別警報」のように、対応するレベルが分かる名称になっています。

| 警戒レベル | 主な避難情報・行動 |
|---|---|
| 3 | 高齢者等避難。危険な場所にいる高齢者などは避難 |
| 4 | 避難指示。危険な場所から全員避難 |
| 5 | 緊急安全確保。災害が発生または切迫しており、命を守るため直ちに安全確保 |

### 図で確認：警戒レベルと行動

警戒レベルは、線状降水帯の強さを5段階で示すものではなく、**住民が取るべき行動を整理する枠組み**です。レベルが上がるにつれて、「情報確認 → 避難行動の確認 → 高齢者等の避難 → 危険な場所から全員避難 → 緊急安全確保」へ行動が変わります。

大切なのは、**レベル5を待たないこと**です。危険な場所では**レベル4までに避難する**のが基本です。線状降水帯発生情報が出ていなくても、キキクルや自治体の情報から危険が高まっていれば行動を前倒しします。

## 実際の大雨ではキキクルと避難情報を優先する

歴史・統計を読む目的は、過去の数字を眺めることだけではありません。線状降水帯が発生すると、短時間で洪水・浸水・土砂災害の危険度が高まることがあります。現在進行中の大雨では、過去事例よりも**気象庁の最新情報、キキクル、自治体の避難情報**を優先してください。

### 図で確認：大雨時に避けたい行動

川や用水路を見に行く、冠水道路へ進入する、アンダーパスへ入る、がけや斜面へ近づくといった行動は避けます。大雨時は「様子を見るために危険へ近づく」のではなく、**近づかない・無理をしない・早めに避難する**ことを優先します。

### 図で確認：家庭の行動タイムライン

制度名や情報名を覚えるだけでは十分ではありません。自宅や職場で何をするかに置き換えると、**「早めの準備 → 避難の判断 → 命を守る行動」**の3段階で考えると整理しやすくなります。

平常時のうちに、ハザードマップ、避難先、家族の連絡方法を確認しておくと、半日前予測や大雨に関する情報が出たときに「何から始めるか」で迷いにくくなります。より具体的な備えや避難判断は、以下の記事で確認できます。

実際の備えは[大雨・水害にどう備える？](flood/flood-preparedness-basics.html)、避難判断は[洪水キキクル・河川氾濫はいつ避難する？](flood/flood-river-evacuation.html)、土砂災害は[土砂キキクルと避難判断](flood/landslide-evacuation-kikikuru.html)を参照してください。
