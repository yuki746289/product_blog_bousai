# 認知症の人の防災｜避難前の準備・持ち物・避難所で伝えたいこと

認知症の人と暮らす家庭の防災では、水・食料・避難先を決めるだけでなく、**本人が自分で説明しにくい情報を家族や支援者が共有できる状態にすること、移動に時間がかかる前提で早めに避難すること、避難先で必要な配慮を伝えること**が重要です。

厚生労働省は「被災時の支援（認知症関係）」として専用情報をまとめ、日本認知症学会等も被災した認知症の人と家族向けの支援マニュアルを公開しています。

この記事では、**平常時の準備 → 早めの避難 → 持ち物・情報 → 避難所で伝えること → 支援先へつながる方法**の順で、家庭側が確認しておきたいことを整理します。

## 結論：本人の「いつもの情報」を持ち、家族だけで抱え込まない準備をする

最初に確認したいのは次の7点です。

1. 自宅の災害リスクと避難先・避難経路を確認する
2. 移動や準備に時間がかかる場合は、危険が高まる前に動けるようにする
3. 常用薬・お薬手帳、眼鏡・補聴器、排泄用品等の個人用品を確認する
4. 本人の呼ばれ方、生活リズム、医療・介護情報、連絡先を1枚にまとめる
5. 避難所では認知症があることと、普段必要な支援を早めに伝える
6. 福祉避難所や介護サービスの災害時運用を自治体・事業所へ平時に確認する
7. 避難先で対応に困った場合は、家族だけで抱え込まず自治体・医療・介護職等へ相談する

**認知症だから必ず特定の避難所へ行く、特定の対応をする、という全国一律のルールはありません。** 本人の状態、家族の支援状況、災害の種類、自治体の受入体制によって変わります。

## 1. 平常時に「どこへ、誰と、どう避難するか」を決める

認知症の人がいる家庭では、避難開始後に本人へすべて説明して初めて動くのではなく、平常時から家族・支援者で避難計画を共有します。

確認したいのは、

- 自宅のハザードマップ
- 災害種別ごとの避難先
- 避難経路
- 誰が本人と一緒に動くか
- 家族が不在の場合の連絡先
- 利用中の介護サービス事業所
- 地域包括支援センター等の相談先
- 車を使えない場合の移動方法

です。

本人が通い慣れている場所、日頃支援している人、地域の見守り関係者等がいる場合は、災害時に誰へ連絡するかも決めます。

高齢者全般の避難準備は[高齢者の防災は何を準備する？](article_b035.html)で整理しています。

## 2. 移動に時間がかかる場合は早めの避難を前提にする

認知症介護研究・研修センター等の災害支援ガイドでは、認知症の人を含む**避難に時間を要する人は、警戒レベル3「高齢者等避難」等の段階から早めに避難する**考え方が示されています。

ただし、「認知症がある人は全員必ずレベル3で同じ行動」という意味ではありません。自宅の災害リスク、自治体の避難情報、本人の移動能力、支援者の状況を確認します。

平常時に、

- 荷物をそろえるのにどの程度時間がかかるか
- 本人が落ち着いて移動できる時間帯か
- 階段や長距離歩行が必要か
- 雨・暗闇で使いにくくなる経路がないか
- 家族1人で介助できない場合に誰へ連絡するか

を確認しておくと、避難情報が出てから迷う時間を減らせます。

## 3. 持ち物は一般用品＋本人に代替しにくい物を優先する

認知症の人向けだから特別な防災用品を大量にそろえるのではなく、本人が普段の生活で必要としている物を優先します。

| 分類 | 確認するもの | 理由 |
|---|---|---|
| 薬・医療情報 | 常用薬、お薬手帳、薬名・用量が分かる情報 | 本人が説明しにくい場合に備える |
| 視覚・聴覚 | 眼鏡、補聴器、必要な予備電池等 | 情報理解や移動に影響する |
| 排泄 | おむつ、パッド等、普段使う用品 | 避難先ですぐ同じ物が入手できるとは限らない |
| 身元・連絡 | 本人確認に使うもの、家族・支援者の連絡先 | 家族と離れた場合にも確認できるようにする |
| 日常用品 | 普段使っている小物、着替え等 | 慣れない環境で本人が必要とする物を確認する |
| 一般防災 | 水、食品、ライト、充電手段、携帯トイレ等 | 家庭共通の備え |

薬については、災害用に余らせるため自己判断で服用量を変えたり中止したりしません。平時に医師・薬剤師等へ備え方を確認します。

常用薬の情報整理は[災害時の常用薬はどう備える？](article_b061.html)で詳しく整理しています。

## 4. 「本人のことが分かる1枚」を作る

避難先では、普段本人を知っている家族・介護職が常にそばにいられるとは限りません。

そこで、紙1枚程度に次をまとめておくと情報共有に使えます。

| 項目 | 例 |
|---|---|
| 呼ばれ方 | 普段安心しやすい名前・呼び方 |
| 家族連絡先 | 優先順に複数 |
| 医療情報 | かかりつけ、服薬情報、お薬手帳の有無 |
| 介護情報 | 利用サービス、担当事業所・ケアマネジャー等 |
| 補助用品 | 眼鏡、補聴器、歩行補助、排泄用品等 |
| 普段の生活 | 食事、睡眠、トイレ等で特に伝える必要があること |
| 困りやすい場面 | 大きな音、人混み、急な環境変化等、家族が把握している範囲 |
| 安心しやすいこと | 普段の関わりで家族が知っていること |

これは診断書や専門的な介護計画の代わりではありません。**避難先の人へ「この人は普段どう生活しているか」を短時間で伝える補助**として使います。

個人情報が含まれるため、誰でも見える場所へ掲示するのではなく、家族・必要な支援者が確認できるよう管理します。

## 5. 避難所では「認知症があること」と普段の支援を早めに伝える

避難所では、多くの人が同じ空間で生活し、音・照明・人の出入り・寝る場所等が普段と大きく変わる場合があります。

受付や保健・福祉担当者等へ、必要に応じて、

- 認知症があること
- 家族が同行しているか
- 普段必要な介助
- 服薬・医療情報
- 眼鏡・補聴器等の使用
- 排泄・食事等で必要な支援
- 家族が対応に困っていること

を伝えます。

「周囲へ迷惑をかけたくない」と考えて家族だけで抱え込むと、本人にも介護者にも負担が大きくなる可能性があります。**早い段階で避難所運営者や保健・福祉担当へ相談**します。

## 6. 避難先で様子が変わったら、家族だけで原因を決めない

慣れない環境では、不安、睡眠の乱れ、落ち着かなさ、食事や排泄の変化等が起こる場合があります。

一方で、体調不良、脱水、感染症、薬の問題、痛み等、認知症以外の原因が関係することもあります。

そのため、

- 「認知症だから仕方ない」と決めつけない
- 新しい症状や普段と違う状態を記録する
- 本人の安全を確保する
- 避難所の医療・保健・介護担当等へ相談する

という流れを基本にします。

この記事では、興奮、不眠、幻覚等への個別の治療方法や薬の変更方法は扱いません。専門的な対応は厚生労働省が案内する認知症支援マニュアルや医療・介護職の判断を確認してください。

## 7. 福祉避難所は「認知症なら自動的に利用できる」と考えない

福祉避難所は、高齢者、障害のある人、妊産婦等を含む要配慮者の受入先として整備されますが、**対象者、開設時期、直接避難の可否、受入方法は自治体によって異なります。**

平時に自治体へ、

- 自宅地域の福祉避難所
- 誰が対象になるか
- 一般避難所を経由するのか
- 事前調整された人が直接避難できる制度があるか
- 開設情報をどこで確認するか

を確認します。

福祉避難所の基本は[防災Q&A](qa.html#qa-welfare-shelter-who)で整理しています。

## 8. 介護サービス・地域の支援者と災害時の連絡方法を確認する

在宅介護でデイサービス、訪問介護、訪問看護等を利用している場合、災害時に通常どおりサービスを受けられるとは限りません。

平時に、

- 災害時の連絡方法
- 休業・変更情報の確認方法
- 緊急時の代替連絡先
- ケアマネジャー等へ伝えておく情報

を事業所へ確認します。

また、地域包括支援センター、自治体の高齢者・福祉担当、民生委員等と普段からつながりがある場合は、**災害時にどの窓口へ相談するか**を家族内で共有します。

## 9. 行方不明への備えは地域の制度を平時に確認する

認知症の人が外へ出て道に迷う可能性がある家庭では、災害時だけ別の対策を作るのではなく、日頃の見守り・行方不明対策を防災計画にもつなげます。

自治体によって、

- 見守りネットワーク
- 事前登録制度
- SOS情報の配信
- 個人識別に使う用品・サービス

等があります。

制度の名称・利用条件は地域で異なるため、自治体や地域包括支援センターへ確認します。

実際に行方が分からなくなった場合は、家族だけで長時間捜し続ける前提にせず、**警察等へ早く相談すること**を優先します。

## 10. 介護する家族自身の持ち物と休息も計画に入れる

認知症の人の用品だけを準備しても、介護する家族が休めなければ避難生活を続けにくくなります。

- 家族自身の水・食料・薬
- スマートフォンの充電
- 着替え・衛生用品
- 交代できる支援者の連絡先
- 相談窓口

も同時に確認します。

**「家族が全部対応する」ことを前提にしない**ことが重要です。避難所や地域の支援につながることも防災準備の一部です。

## まとめ

認知症の人の防災で重要なのは、特別な用品を大量にそろえることだけではありません。

**避難に時間がかかる前提で早めに動ける計画を作り、本人が自分で説明しにくい情報を家族・支援者が共有できるようにし、避難先では家族だけで抱え込まず支援につながる**ことが中心です。

本人の状態や必要な介助は一人ひとり違います。医療・介護上の個別対応は、平時から関わっている医療・介護職、自治体等へ確認してください。
