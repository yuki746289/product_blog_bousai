# 台風・洪水で水没した車は車両保険の対象になる？

台風や洪水で車が水没した場合、**車両保険で補償対象になる契約があります**。ただし、「水没した」という見た目だけでは判断できません。車両保険の有無、損害原因、補償範囲、免責・支払条件を契約書類で確認します。

この記事では、**平常時に確認する契約 → 洪水と津波の違い → 被災直後の行動 → 写真・連絡 → 修理・レッカー等の手続き**の順で整理します。

## 結論：まず「契約・原因・条件」の4点を確認する

最初に見るのは次の4点です。

1. **車両保険を付けているか**
2. **台風・洪水・高潮が補償範囲か**
3. **免責・自己負担、保険金額等の条件**
4. **水没原因が地震・津波ではないか**

被害後は、補償確認より人の安全が先です。浸水した車は始動を試さず、安全な場所から保険会社・ロードサービス等へ連絡します。

## 1. 台風・洪水・高潮による水没は車両保険の対象になり得る

日本損害保険協会は、一般的な車両保険の補償例として**台風・洪水・高潮**を挙げています。補償範囲を限定したタイプでも対象例として示されていますが、実際の商品・契約条件は各社で異なります。

| 契約書類で見ること | 確認内容 |
|---|---|
| 車両保険 | そもそも車両損害を補償する契約があるか |
| 補償範囲 | 台風・洪水・高潮等が対象か |
| 免責・自己負担 | 損害時に自分で負担する金額があるか |
| 保険金額・限度 | 車両について設定されている金額 |
| 特約・付帯サービス | レッカー、代車等の条件 |

**「車両保険あり」という名称だけで判断せず、証券・契約概要・約款を確認**します。

## 2. 同じ「水没」でも洪水と津波は分ける

一般的な自動車保険では、地震・噴火・津波による車両損害は対象外とされます。地震等を補償する特約が用意されている場合がありますが、通常の車両保険とは別に条件を確認します。

| 水没の原因 | 最初に確認すること |
|---|---|
| 河川氾濫 | 車両保険の洪水補償 |
| 高潮 | 車両保険の高潮補償 |
| 内水氾濫 | 契約上の自然災害補償 |
| 地震による津波 | 通常の車両保険とは別に地震等特約の有無 |
| 地下駐車場への水流入 | 水害原因と車両保険を確認。施設側責任とは別問題 |

**被害の見た目ではなく、何が直接の原因かと契約を照合**します。地震・津波による車の損害は[地震で車が壊れた場合、自動車保険はどう考える？](article_b018.html)で整理しています。

## 3. 被災直後は「安全→始動しない→連絡→記録」の順

車が水没した直後に、保険請求のため現場へ戻る必要はありません。

| 順番 | 行動 | 理由 |
|---|---|---|
| 1. 人の安全 | 冠水路・流れのある水・立入制限区域へ戻らない | 二次被害を避けるため |
| 2. 始動しない | 浸水した車のエンジン・モーターを試さない | 点検前の故障拡大等を避けるため |
| 3. 連絡 | 保険会社・代理店・ロードサービス等へ連絡 | 移動・修理・必要資料の案内を受けるため |
| 4. 記録 | 安全な範囲で車両・周囲を撮影する | 事故状況を後から説明するため |

## 4. 写真は「どこで、どの程度水没したか」が分かるように残す

安全に撮影できる場合は、次を記録します。

- 車両全体と周囲の状況
- 車内・外装の損傷
- 浸水した高さが分かる痕跡
- ナンバー等、車両を特定できる情報
- 駐車中か走行中か
- レッカー移動前後の状態

地下駐車場等で水没した場合は、駐車位置や施設側の案内も残します。走行中なら道路名、規制状況、停止位置等を分かる範囲でメモします。

**写真撮影のために冠水区域へ戻らない**ことを優先します。

## 5. 「自分にも落ち度があるから対象外」と先に決めつけない

冠水路へ進入した等の事情がある場合も、加入者側で補償可否を自己判断せず、事故状況を事実として伝えます。

- いつ
- どこで
- 駐車中か走行中か
- 周囲はどの程度冠水していたか
- 避難・移動中だったか

等を整理し、**保険会社が契約条件と事故状況を確認する**という順にします。

## 6. 修理できるか・全損かは外見だけで決めない

水没車は電装系や内装、機械部品等に広範囲な損傷が出ることがあります。修理費、車両価値、契約条件等を踏まえて保険会社や修理事業者が確認するため、自分で「全損だろう」「乾いたから修理不要」と決めません。

特にEV・PHEV・HVは高電圧バッテリーを搭載しているため、**自分で高電圧系統へ触れず、整備工場・販売店等へ相談**します。

## 7. レッカー移動・保管先は「誰が、どこへ運んだか」を残す

水没車を自走させず、ロードサービス等で移動することがあります。

| 残す情報 | 目的 |
|---|---|
| 事業者名 | 誰が移動したか分かるようにする |
| 移動日時 | 時系列を残す |
| 移動元・移動先 | 車両の所在を追えるようにする |
| 作業記録・領収書 | 費用確認に使う |

保管場所によって追加費用が発生する場合もあるため、可能なら保険会社へ連絡したうえで移動先を調整します。

## 8. 車内の荷物・代車・ローン等は車両本体と分けて確認する

車両本体の補償が分かっても、周辺費用・持ち物まで同じとは限りません。

| 項目 | 確認すること |
|---|---|
| 車内のパソコン・カメラ等 | 車両保険でどこまで付属品等として扱われるか、他契約が関係するか |
| 代車・レンタカー | 特約の有無、補償日数・上限・条件 |
| ローン・リース | 所有者・リース会社への連絡手順、残債等 |
| ロードサービス | 利用条件、移動距離・保管等 |

必要なサービスを先に自費で長期契約する前に、契約先の条件を確認すると自己負担を把握しやすくなります。

## 9. 保険証券が手元にない場合に備えて「契約先」を共有する

災害で書類を持ち出せない場合でも、保険会社名や代理店が分かれば契約照会できる場合があります。

平常時に家族で、**保険会社名・代理店・事故受付先**を共有します。事故受付後は、受付番号、担当部署、次の連絡予定も一つのメモへまとめます。

## 大雨前に確認する4項目

1. 車両保険を付けているか
2. 台風・洪水・高潮が補償範囲か
3. 免責・自己負担、保険金額を確認したか
4. 保険会社・ロードサービスの連絡先が分かるか

保険確認は被害後の経済的備えです。浸水リスクが高い駐車場所では、**保険があることより、早めの車両移動と冠水路へ入らないこと**を優先します。

## まとめ

台風・洪水で車が水没した場合、車両保険の対象になる契約があります。ただし、**車両保険の有無 → 原因 → 補償範囲 → 免責・条件**の順で確認する必要があります。

被災後は、人の安全を確保し、浸水車を始動せず、契約先へ連絡します。写真・レッカー・修理等の記録は、安全な状態になってから時系列で残してください。
