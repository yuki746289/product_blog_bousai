# 高齢者の防災は何を準備する？薬・補聴器・入れ歯・避難支援を確認

高齢者がいる家庭では、水・食料だけでなく、**薬を続けられること、眼鏡・補聴器・入れ歯等で生活機能を保てること、本人が食べられること、避難を手伝う人と避難先が決まっていること**を一つの防災計画として確認します。

年齢だけで一律の持ち物や避難方法を決めず、本人が普段の生活で欠かせない物と、移動・情報取得・服薬・食事で支援が必要な場面から逆算します。

## 結論：備える対象を「医療・生活機能・食事・避難支援」の4つに分ける

高齢者向けの防災は、専用品を増やすことより、**災害後も本人の生活を途切れさせない準備**が重要です。確認する対象は、①常用薬・お薬手帳・主治医等の医療情報、②眼鏡・補聴器・入れ歯・杖・排泄用品などの生活機能、③普段の食事形態に合う食品、④避難先・移動手段・支援者・自治体制度の4つに分けると整理しやすくなります。

特に、無いと歩けない、聞こえない、見えない、食べられない、薬を継続できない物は、一般的な非常用品より優先度が高くなる場合があります。一方、本人が自力で避難できるか、家族が昼間不在か、住まいが洪水・土砂・津波等の危険区域かでも必要な支援は変わります。**「高齢者だから同じ備え」ではなく、本人の生活機能と避難条件を確認する**のが出発点です。

## 常用薬は「予備の日数」より先に、薬の情報を他人が確認できるようにする

薬の備えでは、サイト独自に「○日分を追加処方してもらう」と決めません。薬の種類、処方日数、保管条件によって対応が異なるため、予備薬については平常時に医師・薬剤師へ相談し、自己判断で服用量を減らしたり中断したりしないことが基本です。

最低限、**薬の名前、用法・用量、処方医療機関、利用薬局、アレルギー・副作用歴**を本人以外も確認できる状態にします。普段のお薬手帳に加え、停電・通信障害・端末故障に備えて薬名等の紙メモを用意しておくと、情報経路を分散できます。厚生労働省は電子版お薬手帳を案内しており、災害時には条件を満たせば医療機関・薬局側から薬剤情報等を確認できる仕組みもありますが、すべての状況で情報取得できる保証とは考えません。

常用薬の備えと、薬を失った・切れそうな場合の相談先は[災害時の常用薬はどう備える？](article_b061.html)で詳しく整理しています。

## 眼鏡・補聴器・入れ歯・杖は「予備品」より、すぐ使える状態を確認する

災害時は、眼鏡が見つからない、補聴器の電池が切れる、入れ歯を置いて避難する、杖が玄関から離れている、といった小さな断絶が避難や生活を難しくします。まず、本人が普段使っている物を**夜間や停電時でも短時間で持ち出せる場所**に置きます。

| 生活機能 | 平時に確認すること |
|---|---|
| 視覚 | 眼鏡、ケース、予備がある場合は度数が現在も合うか |
| 聴覚 | 補聴器、対応電池または充電手段、ケース。避難所で聞き取りにくいことを伝える方法 |
| 口腔 | 入れ歯、保管容器、洗浄用品。紛失時に食事へ影響することを家族も知る |
| 移動 | 杖・歩行器、履き慣れた靴。段差・階段を含む避難経路で実際に使えるか |
| 排泄 | 大人用おむつ、尿取りパッド、処理袋等。普段の使用量から必要量を確認 |

災害用として新しい補助具を用意する場合は、未使用のまま保管せず、本人が扱えるかを平時に試します。持ち出し袋を重くした結果、杖や手すりを使えなくなるなら逆効果なので、本人が持つ物と家族・支援者が運ぶ物も分けます。

## 入れ歯と口腔ケアは「衛生用品」だけでなく、食事と健康維持に関わる

厚生労働省は、避難生活では水不足等で歯・口・入れ歯の清掃が難しくなり、特に高齢者では体力低下も重なって誤嚥性肺炎などの呼吸器感染症につながりやすいと案内しています。入れ歯の紛失・破損や歯の痛みで食べることに困る場合は、避難所の担当者や歯科医師等への相談が必要です。 citeturn751063search1turn751063search2

そのため、入れ歯本体だけでなく、**保管容器、歯ブラシ、本人が普段使う洗浄用品**まで一組にします。水が十分に使えない状況もあるため、平時のケア方法を家族も把握し、避難先で困った場合に「口腔ケアが必要」「入れ歯がないと食事が難しい」と支援者へ伝えられるようにします。

## 食品は「高齢者用」で選ばず、普段の食形態と指示を再現する

農林水産省は2026年9月版の要配慮者向け食品ストックガイドで、高齢者向けにおかゆ、缶詰・レトルト食品、フリーズドライ食品、栄養補助食品、好物の食品・飲み物、入れ歯・洗浄剤等を例示しています。噛む・飲み込む機能への配慮が必要な人向けには、やわらかい食品や介護食品等も案内されています。 citeturn751063search6turn751063search8

ただし、**「高齢者だから全員おかゆ」「とろみを付ければ安全」とは決めません。** 本人が普段食べている形態、アレルギー、塩分・水分等の食事制限、医療・介護職から受けている指示を優先します。本人用食品には名前と食べ方を付け、保管場所を家族や普段の支援者と共有します。本人だけが場所を知っている状態では、本人が体調を崩したときに使えません。

## 避難は「警戒レベル3になったら高齢者全員」ではなく、場所と避難時間で考える

2026年3月改定の内閣府「避難情報に関するガイドライン」では、警戒レベル3は「高齢者等避難」です。ここでいう「高齢者等」には、**危険な場所にいて、避難を完了するまでに時間を要する高齢者・障害者等と、その避難を支援する人**が含まれます。危険な場所から早めに避難するための情報であり、年齢だけを理由に全国の高齢者全員が同じ場所へ移動するという意味ではありません。 citeturn953285search1turn953285search33

平時にハザードマップで自宅の洪水・土砂・津波等の危険を確認し、本人が玄関を出てから避難先へ着くまでに、着替え、薬・補助具の準備、階段、車いす移乗、支援者との合流などでどれくらい手順が増えるかを確認します。大雨・台風では、自治体の避難情報とその時点の道路・風雨の状況を優先し、支援者の到着を待つために安全な避難開始時期を逃さないようにします。

## 個別避難計画は「誰が来るか」だけでなく、来られない場合まで確認する

内閣府の2026年版防災白書では、自ら避難することが困難な高齢者・障害者等の避難行動要支援者について、個別避難計画の作成を市町村の努力義務として進めています。2025年更新の取組指針では、ハザードの状況、本人の心身状態、医療機器の電源喪失、**独居・昼間独居・社会的孤立、家族の避難支援力**なども作成優先度を判断する要素として示されています。 citeturn953285search3turn751063search46

本人・家族は、自分が制度の対象か、計画が作成済みか、避難先・連絡先・移動手段が現在も使えるかを市区町村へ確認します。計画に支援者が書かれていても、災害時にその人が必ず到着できるとは限りません。**支援者と連絡がつかない場合、同居家族が不在の場合、普段の介護サービスが止まった場合に誰へ連絡するか**まで複数候補を決めます。

一人暮らしや昼間独居なら、遠方家族だけでなく、本人が平時から関係している近隣の親族・知人、ケアマネジャー、介護サービス事業者、自治体窓口などを確認します。民生委員等を連絡先にする場合も、本人との関係や地域の運用を確認し、個人情報の共有は本人の意思と自治体・事業者のルールに従います。

## 福祉避難所は「高齢者なら行けば入れる場所」と決めない

指定福祉避難所は、高齢者、障害者、妊産婦・乳幼児、医療的ケアを必要とする人など、一般の避難所で生活することが難しい要配慮者を受け入れるための避難所です。制度上、施設ごとに受入対象者を特定・公示でき、個別避難計画等を通じて事前に対象者を調整したうえで**指定福祉避難所へ直接避難する運用**も想定されています。 citeturn914935search30turn914935search31

一方で、「高齢者なら発災時に任意の福祉避難所へ直接行けば受け入れてもらえる」とは限りません。利用対象、直接避難の可否、開設状況、移送方法は自治体・施設で異なります。本人が一般避難所での生活に支援を要する場合は、**平時に自治体へ、受入対象か、どの施設へ、誰と、どう移動する計画になっているか**を確認します。

## 持ち出し品は、本人の移動を妨げないように分担する

本人がすぐ使う薬、薬情報、眼鏡・補聴器、杖、連絡カードなどは本人の近くへ置きます。一方、まとまった飲料水、数日分の食品、予備の排泄用品、追加の着替え等を一つのリュックへ集中させると、立つ・歩く・杖を使う・手すりを持つ動作を妨げることがあります。

防災リュックは「本人が持つ分」「同居家族が運ぶ分」「自宅備蓄」に分け、実際に靴を履き、補助具を使い、玄関や階段を通れるかまで試します。支援者が来る前提で本人に必要品を持たせない構成も避け、薬・眼鏡等の代替しにくい物は本人がすぐ確保できる位置を優先します。

## 保存用チェックリスト

- [ ] 常用薬・お薬手帳・薬名メモの場所を本人以外も知っている
- [ ] 主治医・薬局・介護事業者の連絡先を紙または複数の端末で確認できる
- [ ] 眼鏡・補聴器・入れ歯・杖等を夜間でも持ち出せる
- [ ] 補聴器の電池・充電方法を確認した
- [ ] 入れ歯の保管容器・口腔ケア用品をまとめた
- [ ] 排泄用品を普段の使用量から確認した
- [ ] 本人が普段食べている食形態・食事制限を家族も説明できる
- [ ] ハザードマップで自宅が「危険な場所」か確認した
- [ ] 避難に必要な時間と、誰とどこへ移動するか確認した
- [ ] 支援者と連絡がつかない場合の連絡先を決めた
- [ ] 自治体の避難行動要支援者名簿・個別避難計画の対象か確認した
- [ ] 福祉避難所を利用する可能性がある場合は受入対象・直接避難の可否を確認した

## 今日15分でやるなら

まず、お薬手帳・眼鏡・補聴器・入れ歯・杖の場所を本人と一緒に確認します。次に、自宅のハザードマップと避難先を開き、「誰と、どう移動するか」を一度声に出して確認します。最後に自治体サイトで「避難行動要支援者」「個別避難計画」「福祉避難所」を検索し、本人が対象になり得る制度の窓口を保存します。
