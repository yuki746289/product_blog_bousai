# 災害 × 在宅医療・医療機器 キーワード詳細調査

更新日: 2026-09-11
状態: `RESEARCH_DONE / ARTICLE_NOT_CREATED`

## 1. 結論

判定: `NEW / P2 / HIGH_RISK`

現在の防災くらしガイドには、在宅で人工呼吸器、酸素濃縮器、吸引器等を使用する人向けの専用記事がない。

一般的な「停電への備え」では不十分で、次の独立した検索意図がある。

- 人工呼吸器が停電したらどうするか
- 外部バッテリーをどう備えるか
- 酸素濃縮器の停電時バックアップ
- 吸引器を電源なしでどう確保するか
- 長時間停電時にどこへ相談・避難・入院するか
- 主治医、訪問看護、機器業者、自治体と何を平時に決めるか

対象人口は一般防災テーマより狭い可能性があり、検索ボリューム確定前なのでP1にはしない。ただし生命維持に関係するため情報価値は高い。

医療機器・患者状態ごとの差が大きいため、記事では一般的な電源容量や稼働時間を断定せず、主治医・訪問看護・医療機器メーカー/販売会社と個別計画を作ることを中心にする。

## 3. 2026年の公的情報

### 福岡県 2026-05-01

福岡県は「在宅で人工呼吸器を御使用の方及びその御家族等の方へ（停電への備え）」を2026年5月1日に更新している。

主な確認事項:

1. 医療機器・周辺機器の定期メンテナンス
2. 外部バッテリーや酸素ボンベ等の非常用品
3. バッテリー寿命・充電状態
4. 停電時アラームの作動確認
5. 蘇生バッグを必要とする場合の準備と、主治医等からの使用指導
6. 吸引器の充電式・足踏み式・手動式等について主治医と相談
7. 長時間停電時の緊急入院先・避難場所・避難経路を主治医と相談
8. 緊急連絡表を関係者と共有

参考:
https://www.pref.fukuoka.lg.jp/contents/zaitaku-teiden-sonae.html

### 福岡市 非常用電源助成

福岡市には、一定の条件を満たす在宅人工呼吸器使用者に対し、非常用電源装置等の購入費を助成する制度がある。

制度には対象者・性能要件・助成額等の条件があるため、「全国で助成がある」と一般化せず、居住自治体の制度を確認する具体例として扱う。

参考:
https://www.city.fukuoka.lg.jp/hofuku/hokensho/nanbyo/zaitaku/respi-emergencypowersupply.html

### 在宅酸素療法

厚生労働省は2026年7月に在宅酸素療法の火気取扱い注意を更新している。酸素濃縮装置・液化酸素・酸素ボンベは火気に近づけない等の安全管理が必要。

停電対策で酸素ボンベ等を扱う記事にする場合、電源確保だけでなく火気安全も必須。

参考:
https://www.mhlw.go.jp/stf/houdou/2r98520000003m15_1.html

## 4. 体験・ニッチ側で見える課題

仙台市の医療的ケア当事者・家族の災害体験では、東日本大震災時の停電・断水により、医療機器の充電や加湿用の水の確保、生活物資の調達等が困難になった事例が紹介されている。

2026年の報道でも、人工呼吸器の電源喪失時に手動呼吸器で対応した過去の事例や、水が出ないことで加湿・吸引等に影響が出る問題が取り上げられている。

体験から得られる重要な論点:
- 電源だけでなく水も必要になる機器・ケアがある
- 患者を一人残して物資調達に行けない場合がある
- 近隣・支援者ネットワークが重要
- バッテリー稼働時間だけでは長期停電に対応できない
- 避難先で電源が確保できるとは限らない

体験談の機器構成・時間・薬量等は個別事例であり、一般基準として使わない。

参考:
https://www.city.sendai.jp/kikakusomu/kurashi/kenkotofukushi/shogai/shien/shiencenter/sodanshien/ikeasaigai-e.html
https://newsdig.tbs.co.jp/articles/-/2405499?page=3

## 6. A/B/C/D/E判定

### A: 新記事の必須項目

- 使用機器と停電時の動作を主治医・メーカー/販売会社と確認
- 内蔵/外部バッテリーの状態・寿命・充電
- 代替電源を個別機器の仕様に合わせて確認
- 酸素療法で必要なバックアップを医療者と確認
- 吸引器等の代替手段
- 停電時アラーム
- 長時間停電時の連絡先・避難/入院先
- 緊急連絡表
- 水・衛生・消耗品等の非電源依存ニーズ

### B: ニッチ強化候補

- `人工呼吸器 非常用電源 助成`
- `医療的ケア 災害 避難`
- `人工呼吸器 災害 入院`
- `在宅酸素 災害 避難`
- 停電だけでなく断水がケアへ与える影響

自治体制度は地域別具体例として扱う。

### C: 避ける内容

- ポータブル電源の容量だけで安全時間を一律計算
- 一般向け製品を特定医療機器に無条件で推奨
- 人工呼吸器/酸素濃縮器/吸引器で共通のバックアップ時間を設定
- 医療者の指示なく酸素流量・機器設定等を変える案内
- 全自治体に非常用電源助成があるとする
- 医療機器を発電機へ接続する具体手順を機器確認なしで案内

### D: 防災くらしガイドの強みにする方向

「買うべき電源」を中心にせず、

1. 機器の確認
2. バッテリー/代替手段
3. 主治医・訪問看護・業者
4. 避難/入院先
5. 自治体支援
6. 家族・近隣との連絡計画

という実際の行動順に整理する。

### E: WATCH

- 医療機器別の記事分割
- 非常用電源助成の地域別記事
- 医療的ケア児専用記事
- 在宅酸素療法専用記事

検索需要を確認してから独立化する。
