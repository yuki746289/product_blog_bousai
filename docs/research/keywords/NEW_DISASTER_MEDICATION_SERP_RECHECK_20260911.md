# 新規候補: 災害×常用薬 SERP再調査（新基準）

## 1. 結論

`災害×常用薬` は独立記事候補として引き続き有力。

ただし、従来調査に重要な根拠修正がある。

**「厚生労働省が一般の常用薬について3〜7日分を推奨している」とは扱わない。**

従来根拠としていた厚労省PDF `001409762.pdf` は、令和5年度厚労省委託事業の「薬局における疾患別対応マニュアル ～精神疾患（統合失調症）～」であり、Q5-3の3〜7日分は統合失調症患者への疾患別対応の文脈である。

したがって全疾患・全常用薬へ一般化できない。

## 3. 現在の公的一次情報で確実に言えること

### 政府広報

2026年の防災特集では、`常用薬・お薬手帳の備え` を独立項目として扱い、お薬手帳やマイナ保険証により常用薬・病気の情報を正確に伝える重要性を案内している。

一方、この一般向けページでは常用薬の一律の日数基準は示していない。

### 消防庁系防災教材

持病がある人は、通院できない場合を想定し、処方箋等のコピーを用意する重要性を案内している。

### 厚生労働省 電子処方箋

災害時は、マイナンバーカード・資格確認書・お薬手帳等を持参できない場合でも、一定の条件のもと、氏名・住所等で本人確認し、本人同意を得て薬剤情報等を閲覧できる仕組みがある。

電子処方箋対応施設の直近情報や、マイナポータルに記録された情報を避難先で共有できる。

### 厚生労働省 電子版お薬手帳

2026-08-01時点で対応サービス情報が更新されている。
紙だけでなく電子的な服薬情報を持つことも現実的な選択肢。

## 4. 「何日分」の扱いを修正

SERPでは民間・医療機関・疾患別資料に、`3日` `3〜7日` `1週間程度` 等の表現がある。

しかし根拠・対象が異なる。

例:
- 厚労省の3〜7日: 統合失調症の疾患別マニュアル
- 厚労省資料の「3日分、できれば1週間分」: 障害等を抱える方向けの災害準備資料等、対象文脈が限定される
- 病院・薬剤師監修記事: 3日〜1週間等を案内する例がある
- 政府広報の一般防災ページ: 常用薬の備えは推奨するが、一律日数は示さない

したがって新記事では、

**「全国一律に全員○日分」と断定せず、薬の種類、処方管理、疾患、残薬管理、保管条件等で異なるため、平常時に主治医・薬剤師へ災害時の予備について確認する**

を基本とする。

検索語 `災害 薬 何日分` には、数字を断定するのではなく「公的資料や医療機関で数日〜1週間程度の備えが示される例はあるが、対象や薬により異なる」と整理する。

## 5. 「処方箋なしで薬をもらえる」の扱い

過去の大規模災害では、災害ごとの特例通知により処方箋なしで処方箋医薬品を販売できる取扱いが示された事例がある。

しかし、これを常設・全国共通の一般ルールとして書かない。

新記事では:
- 薬が不足しそうなら早めに医療機関・薬局・避難所の医療/薬事窓口へ相談
- 災害時の特例は、その災害時点の厚労省・自治体・医療機関等の最新案内を確認
- お薬手帳・薬袋・処方情報等、服薬内容を確認できる情報を持つ

とする。

## 6. SERP競合の傾向

### 公的ページ

強い点:
- 常用薬とお薬手帳の重要性
- マイナ保険証/電子処方箋等の現在の制度
- 信頼性

弱い点:
- `何日分 → 情報管理 → 避難 → 薬切れ → 相談先` を一つの一般向けページで時系列整理しているものは少ない

### 医療機関・薬剤師系

強い点:
- 3日〜1週間等の具体的目安
- お薬手帳
- 薬が不足した場合の実務

注意:
- 対象疾患・地域・記事時点を確認し、日数や特例を一般化しない

### 低品質/非医療サイト

検索結果には独自計算式で「14〜30日」等を示すページもある。
根拠が弱い独自基準は採用しない。

## 7. 差別化

防災くらしガイドでは医学的な薬剤解説ではなく、

`平常時 → 避難時 → 薬が足りなくなりそうな時 → 情報を医療者へ伝える`

という行動フローを主役にする。

特に2026年時点の:
- 紙のお薬手帳
- 電子版お薬手帳
- マイナポータル
- 電子処方箋

を、代替関係ではなく複数の情報経路として整理する価値がある。

## 8. 仮タイトル再評価

従来案:
`災害時の常用薬は何日分備える？お薬手帳・薬が切れたときの相談先`

検索意図には強く合うが、「何日分」に単一回答がある印象を与える可能性がある。

候補:
`災害時の常用薬はどう備える？何日分・お薬手帳・薬が切れたときの相談先`

または従来案を使う場合、冒頭1〜2文で「全員共通の日数は決められない」と明示する。

## 10. 最終判定

`NEW / P1` を維持する。

ただし、記事作成前に従来調査の「厚労省3〜7日を一般基準とする」解釈を破棄する。
記事では、一般向け公的情報と疾患別・医療機関情報を明確に区別する。
