# 線状降水帯 都道府県別ページ計画 2026-09-21

作成日: 2026-09-21

## 目的

線状降水帯特集を地方単位から都道府県単位へ拡張し、次の二つの検索意図を同時に満たす。

1. 「○○県では過去にいつ線状降水帯が発生したか」という歴史・時系列需要
2. 「今後大雨になったとき、どこで危険度・避難先を確認するか」という実用需要

県名だけを差し替えた量産ページにはしない。各ページは、県固有の発生履歴、代表事例、地形・河川・都市構造、避難情報の確認先を持つ。

## 歴史の扱い

### 2023年5月25日13時以降

気象庁「線状降水帯の事例」の統一基準で掲載された検出結果を、公式検出履歴として扱う。

### それ以前

「顕著な大雨に関する気象情報」の現行掲載基準より前の事例は、気象庁が後年の解説等で線状降水帯事例として明示したもののみ「線状降水帯事例」と記載する。

単に大雨だっただけの事例は「関連する大雨・豪雨」として別列にし、公式検出履歴と同じ件数系列へ混ぜない。

## 県別ページの共通骨格

共通骨格は持つが、章タイトル・代表事例・順序は県固有に調整する。

1. その県で何を押さえるべきか（結論）
2. 発生・関連豪雨の時系列年表
3. 代表事例を2〜4件深掘り
4. 県内で雨のリスクを考える地域差
5. 雨量・河川・土砂災害の確認方法
6. 避難先を探す（指定緊急避難場所と指定避難所を区別）
7. 現在の線状降水帯情報が出たときの行動
8. 地方記事・全国年表・雨量記録への内部リンク

## 避難場所ポリシー

- 「指定緊急避難場所」と「指定避難所」を混同しない。
- 線状降水帯・大雨ページでは、洪水、崖崩れ・土石流・地滑り、内水氾濫等に対応した指定緊急避難場所かを確認する。
- 国土地理院のデータは補助導線として利用可能だが、最新でない場合があるため市町村公式情報で再確認する。
- 開設中かどうかは固定記事から断定しない。災害時は自治体のリアルタイム避難情報・避難所開設情報を確認する。
- 市町村ごとの施設名を大量に静的転載せず、県・市町村の公式防災マップと地理院地図へ誘導する。
- 将来、GeoJSONを使った地図表示を追加する場合も、災害種別フィルタと更新日・免責を表示する。
