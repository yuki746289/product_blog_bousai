# 線状降水帯 都道府県別ページ計画 2026-09-21

## 目的

線状降水帯の「全国傾向」だけでなく、県ごとの過去事例を時系列で確認できるページ群を作る。
県名だけ差し替えた量産ページにはせず、各県で以下を差別化する。

1. 線状降水帯・関連豪雨の時系列年表
2. 県固有の地形・河川・都市構造と大雨リスク
3. 現在の防災判断（キキクル、河川水位、自治体避難情報）
4. 洪水・土砂災害等に対応した避難場所・ハザードマップの公式導線

## 年表の扱い

- 2023-05-25 13時以降: 気象庁の現在の統一基準で掲載される線状降水帯事例
- それ以前: 気象庁・地方気象台が整理した代表的な豪雨史
- 両者を同じ「県別発生件数」として合算しない
- 過去の豪雨史は歴史理解のため、現行事例は同一基準での比較のために掲載する

## 避難場所の扱い

固定的な施設名を大量転載しない。
指定緊急避難場所・指定避難所は更新や開設状況の変更があるため、県・市町村の公式防災マップ、避難情報、ハザードマップへ誘導する。

特に大雨時は、
- 洪水対応か
- 崖崩れ・土石流・地滑り対応か
- 実際に開設されているか
- 避難経路自体が危険区域を通らないか

を確認するよう各県ページで明記する。
