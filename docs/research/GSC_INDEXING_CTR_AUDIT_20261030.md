## 7. CTR改善の運用ルール

1. ニュースイベント日と通常日を分ける。
2. PCとMobileを分ける。
3. 順位変化とCTR変化を分ける。
4. favicon / パンくず修正の効果確認前にtitle / descriptionを同時変更しない。
5. 修正後の確定データが複数日たまってもCTRが低い場合に、title / descriptionを次の施策として検討する。
6. 災害ニュース直後の一時的検索需要を恒常的なSEO成長と誤認しない。

## 8. 今回の実装

- sitemapの記事URLへ registry の `modified_at` を `lastmod` として出力する。
- デプロイ日を `lastmod` に使用しない。
- 根拠のある更新日を持たない固定ページ・カテゴリには `lastmod` を付けない。
- 高露出の愛知県ページから、未露出候補 `region/nagoya/flood-storm-surge-history.html` へ自然な内部リンクを追加する。
- 愛知県ページのtitle / meta descriptionは10/30の検索表示修正の効果を分離するため変更しない。

## 9. 制約

- Coverage exportに44 URLの一覧がないため、未登録URLの個別確定はSearch Console URL検査または詳細URL一覧の取得が必要。
- Performanceの「表示0」はインデックス未登録を意味しない。
- ニュース連動期間の分類は、公開された気象・災害情報に基づくが、すべてのニュース需要を完全に説明するものではない。
