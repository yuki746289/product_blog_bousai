## 4. CORE SERP再調査

対象例:
- `自然災害 保険`
- `台風 水害 地震 保険 違い`
- `自然災害 火災保険 地震保険 違い`
- `自然災害 どの保険`

### 上位ページの共通傾向

- 火災保険・地震保険・車両保険など具体的な保険名をtitleで明示
- 災害名ではなく「原因」「対象物」「契約内容」で補償が変わることを説明
- 台風・洪水・高潮と地震・噴火・津波を明確に分ける
- 契約商品・特約・免責等により最終判断が変わることを明示

B019は、具体的な保険名の羅列より `原因→被害物→契約対象→原因の補償→支払条件` の5段階判断で差別化できている。

## 5. 車両保険系SERP再調査（2026-09-12）

GSCで実際にB019が4位/9位へ出ているため、車両保険系SERPを追加確認した。

### 三井住友海上

`水害・水没は車両保険で補償される？洪水で浸水した場合は？`

主な訴求:
- 台風・洪水・高潮等による水没は車両保険で補償対象となる契約例
- 地震・噴火を原因とする津波は通常の車両保険では対象外
- 特約の有無
- 保険を使った場合の等級
- 低地・アンダーパスを避ける、水没前の車両移動

### ソニー損保 / アクサ

タイトルやFAQで `台風` `大雨` `洪水` `水没` `車両保険` を直接明示する。

### SERP上の特徴

車両保険系検索では、B019のような横断ピラーよりも「質問に対する即答型ページ」が強い。

そのためB019がこの検索意図でも順位を取れていることはプラスだが、ここを狙って本文を車両保険中心へ寄せると記事役割が崩れる。

判断:
- B019 = 総合入口 / 判断ロジック
- B011 = 水没車と車両保険の詳細
を維持する。

## 6. INTENT / NICHE再調査

### `火災保険 水災 いらない`

上位・ニッチでは以下を具体化したページが強い。

- ハザードマップ
- 内水氾濫
- 戸建て/マンション/階数
- 建物/家財
- 自己負担可能額
- 補償を外した場合の最大損失

この検索意図はB019の総合ピラーよりB013やQ&Aの方が適合しやすい。B019へ詳細を詰め込まない。

### `水害 保険 請求 体験`

実体験記事は、被災当日→連絡→査定→支払という時間軸が強い。

ただし個人体験の査定期間・支払額は一般化しない。
B019では短い「被害後は何をするか」までに留め、詳細記録はB015等へ送る構成が妥当。
