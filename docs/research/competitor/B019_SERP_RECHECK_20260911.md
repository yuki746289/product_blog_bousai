## 4. CORE SERP再調査

対象例:
- `自然災害 保険`
- `台風 水害 地震 保険 違い`
- `自然災害 火災保険 地震保険 違い`
- `自然災害 どの保険`

### 日本損害保険協会

表示タイトル例:
`風水雪災等による損害を補償する損害保険`

傾向:
- 火災保険・車両保険・傷害保険に分ける
- 台風・洪水等と地震・噴火・津波の違いを早い段階で明示
- 一次情報として信頼性が高い
- 修理業者の「保険金が使える」勧誘注意も掲載

### 地震保険公式 / 損保協会

傾向:
- `火災保険とは何が違うの？` など直接的な疑問形式
- 地震・噴火・津波は地震保険
- 地震による火災も火災保険ではなく地震保険という誤解ポイントを前面に出す

### 保険会社系

タイトル例:
`火災保険の自然災害補償｜台風・水災の対象と地震保険との違い`

傾向:
- `火災保険` `台風` `水災` `地震保険` をtitleへ具体的に入れる
- 冒頭で「すべての自然災害が自動的に補償されるわけではない」と結論を先に出す

### B019との差

B019は具体的な保険名の羅列より、`原因→被害物→契約→補償→条件` の判断ロジックで差別化できている。
一方、SERPだけでは「火災保険と地震保険を比較する記事」であることが競合より弱く見える可能性がある。

## 5. INTENT / NICHE再調査

### `火災保険 水災 いらない`

上位・ニッチでは以下を具体化したページが強い。

- ハザードマップ
- 内水氾濫
- 戸建て/マンション/階数
- 建物/家財
- 自己負担可能額
- 補償を外した場合の最大損失

表示タイトル例:
`火災保険の水災補償はいらない？ハザードマップで外す前の5確認`

この検索意図はB019の総合ピラーよりB013やQ&Aの方が適合しやすい。B019へ詳細を詰め込まない。

### `水害 保険 請求 体験`

実体験記事は、被災当日→連絡→査定→支払という時間軸が強い。

ただし個人体験の査定期間・支払額は一般化しない。
B019では短い「被害後は何をするか」までに留め、詳細記録はB015等へ送る構成が妥当。
