# 線状降水帯 都道府県別ページ計画 2026-09-21

## 方針

県名だけを差し替えた量産ページにしない。各ページは次の4要素で差別化する。

1. 時系列の「線状降水帯・関連豪雨史」
2. 県固有の地形・河川・都市構造と大雨リスク
3. 現在の防災判断（キキクル、河川情報、自治体避難情報）
4. 洪水・土砂災害に対応する避難場所・ハザードマップの公式確認先

### 年表の区分

- 2023-05-25以降: 気象庁の統一掲載基準による「線状降水帯の事例」
- それ以前: 気象庁・地方気象台が整理した代表的な豪雨史。「現在の公式事例一覧と同じ件数系列」にはしない

### 避難場所

固定的な施設一覧を転載しない。避難所は開設状況・指定状況が変わるため、県・市町村公式の防災マップ、指定緊急避難場所、ハザードマップへ誘導する。洪水・土砂災害など災害種別への適合を確認するよう明記する。
