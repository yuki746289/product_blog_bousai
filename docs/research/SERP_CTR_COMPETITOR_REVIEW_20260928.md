# SERP title / description 競合比較・CTRレビュー 2026-09-28

## 1. 目的

2026-09-28時点のSearch Consoleと実検索結果を使い、CTR改善対象5ページについて以下を比較する。

- SERPで実際に表示されたタイトル
- 競合上位ページのタイトル構造
- スニペットで何を先に伝えているか
- 自サイトの現在の `<title>` / meta description / H1
- パンくず・サイト名・faviconの扱い
- 今すぐ再変更するか、再クロール後に観察するか

重要:
- 競合タイトルをコピーしない。
- SERP表示とページ側設定を分けて記録する。
- 2026-09-28午前にtitle/descriptionを本番変更した直後のため、Google側に旧表示が残るページがある。
- 旧表示が残ること自体を根拠に連続変更しない。
- favicon / パンくずは検索結果UIで目視できる場合のみ実表示を判定し、テキスト検索結果から推測しない。

## 3. 競合比較

### 3.1 B067 線状降水帯特集
代表クエリ: `線状降水帯 発生 履歴`

今回確認できた主な上位候補:
- 気象庁「線状降水帯に関する情報」
- 気象庁「大雨事例等における防災気象情報の検証等」
- 防災くらしガイド「線状降水帯の過去事例｜全国の主な豪雨を年表で比較」
- 日本気象「線状降水帯の雨域」
- JAXA「線状降水帯集中観測モニタ」

傾向:
- 公式・データ系は短い主題名が中心。
- 履歴意図では「過去事例」「事例集」「実績」が強い。
- 自サイトのpillarは履歴だけでなく、雨量記録・多い地域・発生数までまとめる役割があるため、単純に「履歴」だけへ寄せない方がよい。

現在のtitle:
`線状降水帯とは？過去の発生履歴・雨量記録・多い地域を解説`

現在のdescription:
`線状降水帯とは何か、過去の発生履歴・1時間雨量などの雨量記録・発生しやすい地域を公的データで整理。全国の事例や発生数も比較できます。`

判定: **MONITOR**
- 検索意図は前方で識別可能。
- 履歴・雨量・地域というページ固有価値が競合との差になる。
- SERP側には旧titleが残っているため再変更しない。

## 5. パンくず・サイト名・favicon

- サイト名用 `WebSite` JSON-LD、`og:site_name`、faviconは2026-09-28に本番反映済み。
- 検索結果上のサイト名・faviconは再クロール後に変化する可能性がある。
- パンくずはBreadcrumbListと画面上のパンくずを整合させる。
- 今回のテキスト検索結果だけからfavicon実表示を推測しない。
- SERPを目視できる環境では、favicon / site name / breadcrumbもGC03-SERPの証跡へ追加する。

## 6. 次回変更の条件

次回title / descriptionを変更する前に以下を満たす。

1. 2026-09-28本番変更が検索結果へ反映されたことを確認する。
2. 対象ページ・代表クエリで変更後データが十分に蓄積する。
3. CTR、平均順位、表示回数、クエリ構成を同時に比較する。
4. 低CTRが続く場合、競合との差とスニペットの抜粋元を再確認する。
5. 仮説を1つに絞り、title / description / 本文冒頭を同時に大きく変更しない。
