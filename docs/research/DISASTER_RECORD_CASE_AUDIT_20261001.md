## 1. 監査目的

災害事例を「線状降水帯が発生したか」「雨量が大きいか」だけで選ばず、次の2軸で再確認する。

1. **重大被害**: 人的、住家、土砂、河川・堤防、都市型水害、ダム、交通、停電・断水、農林水産等
2. **記録性**: 観測史上1位、月として1位、統計開始以降、施設運用開始以降、初、最長、過去最低等

同一台風・前線・豪雨で複数の被害種別が発生しても別事例へ分割しない。  
地域別に詳細を持つ必要がある場合は**同じ event_id を複数行で使用**し、独立事例数は event_id のユニーク件数で数える。

## 2. 判定ルール

- 線状降水帯区分は `実発生 / 予測のみ / 未確認 / 非該当` を分離する。
- 「観測史上1位」と「○月として1位」を混同しない。
- 「県内初」「市内初」「制度開始後初」は対象範囲を省略しない。
- 気象庁の特定期間ランキングは速報値である場合、そのまま「速報」と管理する。
- 被害集計は発表機関・集計時点・対象範囲が異なる場合がある。異なる集計値を単純合算しない。
- 進行中・調査継続中の災害は確定値扱いしない。
- 報道・民間集計で発見した記録は、可能な限り一次資料へ戻る。一次資料側に同じランキング定義がない場合は、その点を明記して保留または限定採用とする。

## 4. 優先事例の詳細監査

### 4.1 台風第25号：千葉県

#### 北印旛沼・角川・長門川

9月30日更新の千葉県資料では、北印旛沼周辺の応急復旧は次の状態だった。

- 船形干拓: 被災延長 **72.6m**、荒締切を施工中
- 角川排水路: 右岸27.0m・左岸10.0m、荒締切 **46m / 46m（100%）**
- 長門川右岸: 被災延長33.2m、荒締切 **29m / 33.2m（87%）**
- 9月30日未明から緊急排水ポンプを順次稼働

初報等の「約100m決壊」と、復旧工事で管理する「被災延長72.6m」は測定・管理の文脈が異なるため、同一値として置換しない。

#### 交通・生活・農林水産

- 9月30日14時時点で県管理道路 **56区間**が全面通行止め。
- 国交省9月30日資料では、JR内房線・久留里線・総武本線・成田線等で復旧に長期間を要する区間が残る。
- 断水は複数市町で発生し、一部地域は9月30日時点でも復旧途中。
- 富津市金谷では孤立1世帯1人が継続。
- 千葉県の農林水産被害は9月28日正午時点で**44市町村・約17億円**。調査継続中のため確定額ではない。

これらはすべて `E20260919_T25_KANTO` の被害内訳であり、別災害件数へ加えない。

### 4.4 東京の長雨・9月記録

旧監査には「2026年9月の東京の月降水量607.0mm、9月として2位」とあったが、10月1日に気象庁の月別ランキングを再確認すると、

- 月降水量: **696.5mm、9月として1位**
- 月間日照時間: **45.8時間、9月として少ない方から2位**
