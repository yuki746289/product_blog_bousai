# 防災くらしガイド 競合調査用 検索ワード一覧

更新日: 2026-09-10

## 目的

競合・ニッチサイト比較で実際にGoogle等で検索する語を管理する。

このファイルは固定リストではない。Search Consoleで新しい実測クエリが確認された場合は、**実測語を最優先で追加し、検索順位・表示回数・記事との対応を見ながら優先度を更新する**。

## 検索語の区分

- `GSC`: Search Consoleで実際に確認できた語
- `CORE`: 記事テーマの中心語。SERPの主要競合を把握するために使う
- `INTENT`: 「どうする」「必要」「いつ」など、検索者の行動・疑問を表す語
- `NICHE`: 大手にない具体的ケースやニッチサイトを探す語
- `CANN`: 自サイト内の別記事とのカニバリを確認する語
- `DISC`: ニッチサイト発見用の補助語。「ブログ」「体験」「事例」等を付加

## Search Console更新時のルール

1. 調査開始前に最新GSCを確認する。
2. 対象ページに紐づく実測クエリがあれば `GSC` として先頭へ追加する。
3. 表示回数が増えた語、平均順位20位以内の語を優先する。
4. GSCで匿名化されている可能性があるため、ページの表示回数とクエリ合計が一致しなくても異常扱いしない。
5. 実測語と既存の想定語がズレた場合は、実測語を優先して検索セットを組み直す。
6. 調査済み語は削除せず、`調査済` として履歴を残す。
7. 検索意図が別記事向けだった場合は `CANN` に移す。

# ニッチサイト探索の共通検索パターン

上位SERPだけでは大手に偏るため、主キーワードに次の補助語を付けて別検索する。

- `[主キーワード] 体験`
- `[主キーワード] ブログ`
- `[主キーワード] 事例`
- `[主キーワード] 失敗`
- `[主キーワード] 実際`
- `[主キーワード] どうした`
- `[主キーワード] 個人`
- `[主キーワード] マンション`
- `[主キーワード] 車`
- `[主キーワード] 子ども`
- `[主キーワード] 高齢者`
- `[主キーワード] ペット`
- `[主キーワード] 地域名`

大手サイトを除外する検索演算子は、通常SERPを確認した後の補助探索に限定する。最初から大手を除外すると、上位との比較基準を失うため使用しない。

# 調査順序

各記事で以下の順に検索する。

1. `GSC` 実測語
2. `CORE` 主要語
3. `INTENT` 行動・疑問語
4. `CANN` 自サイト別記事との境界語
5. `NICHE / DISC` ニッチサイト探索語

1つの検索語だけで結論を出さず、主検索意図ごとに複数SERPを比較する。
