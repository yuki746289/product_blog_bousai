# 新規候補: 認知症×災害・避難 SERP再調査

更新日: 2026-09-12
判定: `NEW / P2 / HIGH RISK`

## 1. 想定検索意図

- 認知症 防災
- 認知症 災害 避難
- 認知症 避難所
- 認知症 災害 家族

一般的な高齢者防災ではなく、認知症の本人と家族が「避難前に何を決めるか」「避難所で何を伝えるか」「環境変化へどう備えるか」を確認する独立意図がある。

## 2. 公的一次情報

### 厚生労働省

「被災時の支援（認知症関係）」として専用ページを設け、被災した認知症の人と家族向け支援マニュアル、避難所掲示用チラシ、災害支援ガイド等を案内している。

### 認知症介護研究・研修センター / 日本認知症ケア学会

災害支援ガイドでは、認知症の人を含む避難に時間を要する人について警戒レベル3「高齢者等避難」での早めの避難を示し、お薬手帳・常用薬、眼鏡・補聴器、おむつ等の個別用品も例示している。

### 日本認知症学会

被災した認知症の人と家族の支援マニュアルを公開し、避難所等での環境変化に伴う不安、行動変化、睡眠、排泄等について支援者向け情報を整理している。

## 3. 既存B035との境界

B035「高齢者の防災」は、高齢者全般について薬・補聴器・入れ歯・移動支援・福祉避難所・個別避難計画等を扱う。

新規記事では、以下を認知症固有の家庭側準備として扱う。

- 本人が説明しにくい情報を家族が持つ
- いつもの生活・支援内容を簡潔に記録
- 連絡先・介護サービス・医療情報
- 早めの避難判断
- 避難所で認知症であることや必要な配慮を伝える
- 家族だけで抱え込まず支援者・自治体へ相談する
- 福祉避難所や直接避難の運用は自治体差がある

B035は親記事、新規記事は認知症特化とする。

## 4. 独立記事の役割

候補構成:
1. 平常時に避難先・支援者・連絡方法を決める
2. 警戒レベル3等、移動に時間が必要な場合は早めに動く
3. 常用薬・お薬手帳・眼鏡・補聴器・排泄用品等を確認
4. 本人情報カード: 呼び名、普段の生活、連絡先、医療/介護情報、困りやすいこと
5. 避難所で認知症と必要な配慮を伝える
6. 慣れない環境で様子が変わった場合は家族だけで対応を抱え込まない
7. 福祉避難所・介護支援・自治体相談先を平時に確認
8. 行方不明対策は自治体の見守り制度等を確認

## 5. HIGH RISK品質ゲート

記事は医療・介護の個別対応手順を一般化しない。

避ける:
- 興奮・不眠・幻覚等への具体的治療指示
- 薬の追加・中止・増減の指示
- 身体拘束等の対応方法
- 認知症なら必ず福祉避難所へ行けるという断定
- 本人の意思を無視した一律対応
- 行方不明時の捜索を家族だけで行わせる表現

異変や対応困難時は、避難所運営者、自治体、地域包括支援センター、医療・介護職等へ相談する方向に限定する。

## 7. 判定

`NEW / P2 / HIGH RISK`

理由:
- 厚労省が独立した被災時支援ページを設けている
- 日本認知症学会等に専用支援マニュアルがある
- B035の高齢者一般記事だけでは検索意図を十分に満たしにくい
- 一方、医療・介護上の個別判断が絡むため、女性防災記事より慎重に扱う

まず一般家庭向けの「事前準備・情報共有・早めの避難・相談先」に限定して記事化し、症状別対応は専門マニュアルへ送る。
