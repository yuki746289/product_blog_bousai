## 結論

低順位ページを3群調査した結果、**単純な記事品質不足より、サイト新規性・競合強度・検索意図の細分化が影響している可能性が高い**。

- `台風 備え`: B006本文は上位公的ページの主要要素をほぼ網羅。全面改稿より内部リンク・カテゴリ役割・時間経過観察。
- `防災バッグ 中身`: B002は検索意図との整合が高く、競合との差も小さい。タイトル変更よりインデックス/内部リンク/評価蓄積を優先。
- `火災保険 水災 いらない`: B013は水災補償の説明記事として強いが、検索者は「外してよいかの判断手順」を求める。別Q&Aまたは独立記事の方が適合する。

## 3. `火災保険 水災 いらない`

### GSC

B013 `insurance/fire-insurance-water-damage.html`
- `火災保険 水災` → avg 99
- `火災保険 水災 いらない` → 3 impressions / avg 96.67
- `火災保険 水災 事例` → 3 / avg 91.33

### 上位SERP傾向

Oricon:
- `水災補償はいらない？`
- 判断方法
- ハザードマップ
- 高台/マンション上層階
- 内水氾濫
- 水災と水濡れの違い

チューリッヒ:
- マンションでも本当に不要か
- 地域リスクと住宅リスクを分ける
- ハザードマップ
- 階層/構造

ソニー損保:
- 周辺環境によって必要性が異なる
- マンション2階以下、低地、山/崖等を例示
- リスクが低くてもゼロではない

2026-09-09公開のニッチページ:
- `外せる条件と後悔しない判断手順`
- 高台や上階だけで決めない
- リスクと自己負担可能額を確認

### B013評価

B013は水災補償の一般説明として強い。

既に:
- 水災補償の有無
- 風災との違い
- 建物/家財
- 賃貸
- 支払条件
- ハザードマップ
- 免責/自己負担
- 被災後の記録
- `色がないから不要` を否定
を持つ。

一方、`いらない` クエリの検索意図は**説明ではなく判断**。

検索者が知りたいのは:
1. 自宅の水災リスク
2. マンション階数/構造
3. 内水/高潮/土砂も含むか
4. 建物/家財のどちらを外すのか
5. 外した場合に自費負担できる最大損失
6. 保険料差とリスクの比較

B013へ全部追加すると記事役割が広がりすぎる。

### 判定

`CONTENT_GAP: INTENT_SPLIT`
`SEO_ACTION: NEW_QA_OR_DETAIL`

候補:
- Q&A: `火災保険の水災補償はいらない？外す前に何を確認する？`
- 独立記事: `火災保険の水災補償は必要？ハザードマップ・階数・家財で判断する方法`

B013は親記事としてリンクする。
