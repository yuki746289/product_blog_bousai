## 1. `水 備蓄 量`

### GSC

対象: B025 `guide/drinking-water-stockpile.html`

- `水 備蓄 量` → 1 impression / average position 96
- B025ページ全体 → 1 impression / average position 96

母数は極小。

### 上位・一次情報

政府広報オンライン（2026-02-13）は、水について **1人1日3L**、食品について最低3日〜1週間分の備蓄を案内している。

農林水産省も、飲料・調理用だけで **1人1日3L**、最低3日分として9Lを案内している。

政府広報の別記事では、南海トラフ巨大地震等の広域災害では1週間分以上が望ましいとの指摘も紹介し、飲料水とは別に生活用水も必要としている。

### B025との比較

B025は既に:

- 1人1日3L
- 最低3日 = 9L
- 可能なら7日 = 21L
- 人数別計算表
- 飲料・調理用と生活用水の分離
- ローリングストック
- 水道水の短期保存
- 分散保管
- 2L / 500〜600mLの使い分け
- 持ち出し用との分離
- 給水時の運搬重量

を持つ。

検索意図に対する本文不足はほぼない。

### 判定

`CONTENT_GAP: LOW`
`SEO_ACTION: MONITOR + INTERNAL_LINK`

現時点でtitle/H1を変更する根拠は弱い。

将来の軽微候補:
- Q&A `水は1人何リットル備蓄すればいい？`
- B039在宅避難、B002防災リュック、B026非常食からB025への内部リンク確認
- カテゴリ一覧の説明文に `1人1日3L` を過剰でない範囲で明示

## 2. `ポータブル電源 防災 必要か`

### GSC

対象: B028 `goods/portable-power-station-disaster.html`

- `ポータブル電源 防災 必要か` → 1 impression / average position 96

### SERP傾向

2026年の民間上位記事は、タイトル段階から:

- 本当に必要か / いらないか
- どんな家庭なら必要か
- 容量の目安
- 選び方
- 停電時の使用機器

を前面に出している。

Anker（2026-07-14）は `本当にいらない？` という判断意図を直接取り、活用場面・選び方・商品へつなぐ。

ニッチ記事でも、スマホと照明だけならモバイルバッテリーで足りる家庭がある一方、冷暖房補助・PC・冷蔵庫等を使う家庭では必要性が上がる、という条件分岐が中心。

公的側では、経済産業省がポータブル電源の火災・感電等のリスクと安全性要求事項を整理している。自治体の注意喚起でも、防災用途で普及する一方、火災事故への注意が示されている。

### B028との比較

B028はタイトルが既に:
`ポータブル電源は防災に必要？用途と注意点`

本文冒頭で:
- 全家庭に必須ではない
- 何を何時間使うかから逆算
- スマホだけなら大容量不要な場合がある
- 基本備蓄が不足しているならそちらを先にする

と答えている。

さらに:
- 必要な家庭 / 優先度が低い家庭
- WhとWの違い
- 消費電力と使用時間
- 容量帯比較
- 重量
- リコール確認
- 保管・充電・実機テスト
- ソーラーの位置付け
- 医療機器はメーカー/医療機関等へ確認

まで持っている。

### 判定

`CONTENT_GAP: LOW`
`SEO_ACTION: MONITOR + TRUST/FRESHNESS`

本文追加より、以下を優先する。

1. 商品型番・価格・販売継続・リコールの定期確認
2. 商品記事からB004停電対策、B045冷蔵庫、B047暑さ対策等への内部リンク
3. B004側から「大容量電源が必要とは限らない」文脈でB028へ送客
4. 商品選定ロジックの維持

検索順位96位だけを理由に記事を長文化しない。

## 3. `火災保険 台風`

### GSC

対象: B016 `insurance/typhoon-wind-damage-insurance.html`

- B016ページ全体: 12 impressions / average position 23.5
- `台風 火災保険` → 1 impression / average position 25
- `火災保険 台風` → 2 impressions / average position 99.5

語順が逆なだけで順位差が大きいが、母数が1〜2 impressionsなので即時対応しない。

### 上位・一次情報

日本損害保険協会は、火災保険で風災・水災等を補償する商品があること、台風・暴風による風災、水害による水災を分けること、契約内容によって異なることを案内している。

損保ジャパンも:
- 台風による屋根等の損傷は風災
- 建物と家財は別
- 商品・契約条件による
という構成。

あいおいニッセイ同和損保FAQは `台風による損害は火災保険の補償の対象ですか？` に対し、風災と水災を分けて即答する。

### B016との比較

B016タイトル:
`台風の風災は火災保険でどう扱われる？`

本文は:
- 台風だから一律対象ではない
- 風災 / 水災の区別
- 建物 / 家財
- 免責 / 支払条件
- 経年劣化との区別
- 安全 → 記録 → 契約確認 → 連絡 → 修理
- 保険金利用をうたう修理勧誘への注意

を持ち、検索意図への不足は小さい。

### 判定

`CONTENT_GAP: LOW`
`SEO_ACTION: MONITOR`

特に `火災保険 台風` と `台風 火災保険` の順位差は、現段階ではノイズの可能性が高い。

変更候補を作るとしてもtitle変更ではなく:
- Q&A `台風の被害は火災保険で補償される？`
- B019/B013/B016間のアンカーテキスト整理
- 風災と水災の違いを検索結果に抜かれやすい短文で維持

程度に留める。

## 4. `大雨 対策 できること`

### GSC

対象: B005 `flood/flood-preparedness-basics.html`

- B005ページ全体: 16 impressions / 1 click / average position 70.56
- `大雨 対策 できること` → 1 impression / average position 86
- `大雨対策 できること` → 1 impression / average position 83
- `水害対策` → B005で3 impressions / 1 click / average position 77.33

### SERP・一次情報

政府広報の2026年大雨・台風特集では:
- 警戒レベル
- 早期避難
- 洪水キキクル
- 土砂災害
- 防災気象情報

等、「今どう行動するか」を短く切り出したページ群が強い。

警視庁2026-09-03更新ページも、レベル5時には移動せず安全確保、レベル4までの避難、冠水道路へ入らない等、行動を直接提示している。

一般SERPでは `自分でできる対策` `家庭でできること` のように、行動チェックリスト型が目立つ。

### B005との比較

B005本文は非常に広く:
- ハザードマップ
- 洪水 / 内水 / 土砂 / 高潮
- 気象・避難情報
- 避難方法
- 避難経路
- 家の外の準備
- 停電 / 断水 / トイレ
- 家族条件
- 危険行動

を持っている。

つまり**内容不足ではない**。

一方、検索者が `できること` と入力した場合、SERPでは:
- 今すぐやること
- 平常時にやること
- 雨が強くなる前にやること
を短く知りたい可能性が高い。

B005の情報は網羅的なため、検索結果や冒頭だけでは「具体的な行動一覧」がやや埋もれる。

### 判定

`CONTENT_GAP: LOW`
`FRAMING_GAP: MEDIUM`
`SEO_ACTION: LIGHT_EXPAND / QA`

候補:

#### Q&A
`大雨・水害対策で個人ができることは？`

回答構造:
1. ハザードマップを見る
2. 避難先・経路を決める
3. 側溝・排水口を安全なうちに確認
4. 飛散物を片付ける
5. 水・食料・携帯トイレ・充電を確認
6. 車を低い場所から移す判断を早めにする
7. 雨が強くなったら外作業をやめる
8. 警戒レベル・自治体情報で早めに避難

#### 本文局所追加
B005冒頭付近に `個人でできること8項目` のような短い要約を置く候補。

ただし、現状の `自宅の危険を知る→情報を決める→安全なうちに動く` という独自骨格を壊さない。
