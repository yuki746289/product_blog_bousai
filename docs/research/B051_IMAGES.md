# B051 画像選定メモ

確認日: 2026-09-07
- image_source_count: 0
- image_status: APPROVED

## 理由

B051は保険会社10社の比較記事であり、読者が判断に使う中心情報は比較表、補償設計、申込導線、比較手順である。

- 保険会社ロゴ・商品ロゴを装飾目的で転載しない。
- 災害被害の汎用写真を置いても、保険会社比較の理解には直接寄与しない。
- 会社ごとのカード、比較表、手順、注意ボックスを視覚要素として使用する。
- 画像を追加する場合は、記事内容に直接必要で、利用条件を確認できるものに限定する。

したがって、現版では**画像0枚を意図的に採用**する。
