## 2. B067 挿入計画

対象ファイル: `content/articles/B067_linear_rainband_feature.md`

### B067-1 図4「どの情報をどう見るか」

挿入対象章:
`## 線状降水帯情報と警戒レベルは別に確認する`

推奨位置:
現在の「線状降水帯半日前予測 / 直前予測 / 発生」の3行表の直後、
「ここで注意したいのは、線状降水帯発生情報＝警戒レベル5ではないことです。」の直前。

図の直前に追加する文章:

> 半日前予測・直前予測・発生情報は、それだけで避難行動を決める情報ではありません。実際の判断では、**①気象情報で大雨の見通しを知る → ②キキクルで自分の周辺の危険度を確認する → ③自治体の避難情報や河川情報で行動を決める**、という順に見ると整理しやすくなります。

図プレースホルダー:

`[FIGURE-04: 線状降水帯が心配なときに、どの情報をどう見るか]`

図の直後に追加する文章:

> 特に、自治体から避難指示がまだ出ていなくても、警戒レベル3相当・4相当の防災気象情報やキキクルで危険が高まっている場合は、自分で早めに避難判断することが重要です。

狙い:
- 3種類の線状降水帯情報の表から、実際の避難判断へ自然につなぐ。
- 「線状降水帯情報だけを見る」という誤解を防ぐ。

### B067-2 図5「警戒レベルと行動」

挿入対象章:
`## 線状降水帯情報と警戒レベルは別に確認する`

推奨位置:
現在の警戒レベル3/4/5の表の直後、
「レベル5を待って避難するのではなく」の段落の直前。

図の直前に追加する文章:

> 警戒レベルは、線状降水帯の強さを5段階で示すものではなく、**住民が取るべき行動を整理する枠組み**です。レベルが上がるにつれて、「情報確認 → 避難行動の確認 → 高齢者等の避難 → 危険な場所から全員避難 → 緊急安全確保」へ行動が変わります。

図プレースホルダー:

`[FIGURE-05: 警戒レベルが上がるほど、行動は「確認」から「避難」へ変わる]`

図の直後に置く文章:

> 大切なのは、**レベル5を待たないこと**です。危険な場所にいる場合はレベル4までに避難し、線状降水帯発生情報が出ていなくても、キキクルや自治体の情報から危険が高まっていれば行動を前倒しします。

既存本文との整理:
- 現行の「レベル5を待って避難するのではなく…」段落と内容が重なるため、実装時は上記の直後文へ統合する。
- 3/4/5の表はテキスト代替として残す案を基本とする。
- 将来、表を1〜5へ拡張する場合も、図は直感理解、表は正確な文字情報という役割分担にする。

## 5. 重複を避ける編集原則

1. 図の前では「何を見る図か」を1〜2文で示す。
2. 図の後では「読者がどう判断するか」を1〜2文で示す。
3. 図中の全文を本文で繰り返さない。
4. 安全上重要な要点は画像内だけに閉じ込めない。
5. B067は行動寄り、B072は制度整理寄りの語り口を維持する。
6. 同じ図を使う場合でも、周辺本文はページの役割に合わせて変える。
