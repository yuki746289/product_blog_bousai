更新日: 2026-09-22  
対象: B082〜B092, B094〜B096（実発生確認済み14都県）  
状態: IN_PROGRESS / 本番デプロイ禁止

## 1. 今回の調査方法見直し

従来は、気象庁の線状降水帯統一一覧や検索結果を起点に個別事例を探す比重が高く、公式アーカイブに存在する大雨・台風・気象災害を十分に母集団化できていなかった。

今後は次の順で調査する。

1. 地方気象台・測候所等の「気象速報」「過去の災害」「気象災害史」アーカイブを年単位で確認し、候補母集団を作る。
2. 気象庁の線状降水帯統一事例一覧・年度別実績で実発生を照合する。
3. 地方気象台の個別気象速報・災害時気象資料で対象県の状況を確認する。
4. 気象庁「災害をもたらした気象事例」、都道府県・市町村、国土交通省、消防庁等の一次資料で被害・災害名を補完する。
5. 気象庁観測記録で雨量・観測史上順位・時間尺度を照合する。
6. 検索エンジンは公式資料発見の補助に限り、網羅性判定には使用しない。

### 調査終了条件

- 直近・過去それぞれ10件の適格候補を一次資料で確認できた、または
- 対象期間の公式アーカイブ・主要一次資料を年単位で一巡し、それ以上の適格候補が確認できない。

5件に達しただけでは調査完了にしない。

### 分類

- A: 線状降水帯の実発生を公的一次資料で確認
- B: 関連する重大豪雨・局地的大雨
- C: 予測・可能性の呼びかけのみ（実発生件数に含めない）
- H: 現行制度以前の歴史的豪雨

制度以前の豪雨を、雨域形状・雨量・被害だけから記事側で遡及的に線状降水帯認定しない。

## 4. 現時点の結論

旧方式は「実発生の正確性」には寄与したが、「県内で過去に起きた関連豪雨を漏れなく候補化する」工程が弱かった。特に B090静岡、B096富山、B095石川、B085長崎は、地方気象台の公式アーカイブと現行記事の件数差が大きい。

今後は、記事本文を書き換える前に各県の候補台帳を完成させ、A/B/C/H分類と採否理由を確定する。候補台帳未完了の記事は READY_TO_PUBLISH にしない。
