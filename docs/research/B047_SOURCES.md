# B047 一次情報メモ

確認日: 2026-09-17

## F-B047-001 厚生労働省「災害時における健康管理」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/tiiki/saigai_00001.html
- 災害時、避難所の気温上昇や片付け作業で熱中症へ注意。
- 停電等で扇風機・エアコンが使えない場合、こまめな水分・塩分補給、室内・外出時・衣服の工夫による予防を案内。

## F-B047-002 厚生労働省「熱中症予防のために」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000212502.html
- 室内でも、のどの渇きを感じなくても、こまめな水分・塩分等の補給を案内。
- 涼しい場所へ移動し、衣服をゆるめ、首周り・脇の下・足の付け根等を冷やす応急処置を案内。
- 自力で水が飲めない、意識がない場合は直ちに救急車を要請する。

## F-B047-003 厚生労働省「熱中症が疑われる人を見かけたら」
URL: https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/kenkou/nettyuu/nettyuu_taisaku/happen.html
- 涼しい場所へ移動、衣服をゆるめ体を冷やす、水分補給を案内。
- 自力で水が飲めない、意識がない場合は救急車を呼ぶ。
- 心臓・腎臓等の疾患で水分摂取の指示がある人は医師の指示に従う。

## F-B047-004 環境省「指定暑熱避難施設（クーリングシェルター）・リンク集」
URL: https://www.wbgt.env.go.jp/heatillness_shelter.php
- 気候変動適応法に基づく指定暑熱避難施設を指定している自治体のリンク集。
- 2026年9月4日までの自治体報告を基に、1260市区町村がクーリングシェルターを指定済み。
- 施設の詳細・最新状況は各自治体サイトで確認する必要がある。

## F-B047-005 環境省「指定暑熱避難施設に関するFAQ」
URL: https://www.wbgt.env.go.jp/faq.php
- 指定要件は、適当な冷房設備、熱中症特別警戒情報の発表期間中に開放できること、必要な滞在空間の確保。
- 対象地域に熱中症特別警戒情報が発表された場合、あらかじめ定められた開放日時等に住民等へ開放される。
- 「停電したら自動開放」「通常の熱中症警戒アラートなら全国一律で開放」とは扱わない。

## F-B047-006 消費者庁「停電時の発電機によるCO中毒や、復旧後の通電火災に注意！」
URL: https://www.caa.go.jp/policies/policy/consumer_safety/caution/caution_070/
- 携帯発電機の排ガスには一酸化炭素が含まれ、屋内では絶対に使用しないよう注意喚起。
- 自動車内・テント内も屋内と同等以上に危険。
- 屋外でも出入口・窓等の開口部から離し、風通しのよい場所で使用する。

## 記事内の安全境界
- 自宅に居続けることを目的にせず、冷房のある場所へ移れるうちに移る判断を前倒しする。
- ただし、暴風・冠水・倒壊・道路障害がある場合は、熱中症対策だけを理由に危険な経路へ出ない。
- 移動が危険な状況でも、自力飲水不可・意識異常等の救急基準に該当したら「移動可能になるまで待つ」とせず119番を優先する。
- モバイル扇風機・保冷剤・ポータブル電源は補助であり、危険な高温環境を安全化する保証ではない。
- 指定暑熱避難施設は熱中症特別警戒情報の発表期間中に所定の日時等で開放される制度であり、停電だけで自動開放されるとは書かない。
- 発電機は屋内で絶対に使用せず、自動車内・テント内でも使用しない。屋外でも開口部から離す。
- 経口補水液・塩分を過剰に取らせる表現や、サイト独自の一律摂取量を設定しない。
