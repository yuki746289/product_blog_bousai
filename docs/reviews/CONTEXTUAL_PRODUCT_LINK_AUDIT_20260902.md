## 1. 目的

一般情報記事の中で、読者が商品を必要とする理由・用途・選び方を理解した直後に、対応する商品紹介記事へ自然に進めるかを B001〜B047 で横断確認する。

確認方針:

- 商品リンクを記事末尾だけに依存しない
- 商品説明・備蓄説明・用途説明の直後を優先する
- 一般情報記事から Amazon へ直接大量誘導しない
- 商品との関連が弱い記事へ無理に導線を追加しない
- 高リスク記事では安全情報を商品導線より優先する
- 同じリンクを短い間隔で過剰に繰り返さない
- 専用の商品ガイドが存在しないテーマを、関連の薄い既存4商品ガイドへ無理に接続しない
- Markdown / preview HTML / 記事別チェックリストの整合を確認する

## 5. 結論

B001〜B047を通して、**商品ニーズがある記事すべてへ商品リンクを付ける運用にはしない**。

現在の基本導線は、

**情報記事 → 必要性・用途の理解 → 適切な商品紹介記事がある場合のみ接続 → Amazon**

の順を維持する。

特に、保険、避難判断、被災後処理、医療・要配慮者、電気安全などでは、商品導線を増やすことで記事の信頼性や安全上の優先順位を崩す可能性がある。専用の商品ガイドが存在しない場合は、関連の薄い既存ガイドへ無理に接続せず N/A とする。

将来、新しい専用商品ガイドを作成した場合のみ、対応するN/A記事を再監査する。
