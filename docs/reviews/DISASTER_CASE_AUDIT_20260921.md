# 実在災害事例 横断品質監査 2026-09-21

## 目的

サイト内の記事で扱う実在の災害・豪雨・地震・噴火等について、線状降水帯だけに限定せず、次を横断確認する。

- 同一イベントの重複計上
- 発生実績と予測・制度説明・想定の混同
- 地域との直接関係
- 年表の時系列
- 最新事例の欠落
- title / H1 と実データの整合
- 表の行数と独立イベント数の混同

サイト内96記事を機械抽出し、実在災害事例を中核にする記事を重点監査した。

## 適用判断

「直近実事例を原則2件以上」は、**複数事例を比較する年表・地域史・発生史記事**に適用する。
特定の1災害を深掘りする記事（例: 阪神・淡路大震災、真備2018年水害）へ、無関係な新しい災害を件数合わせで追加しない。

制度史・情報史の記事では制度変更が記事の主題なので、制度行を残してよい。ただし災害発生件数には含めない。

## 全記事共通ルールへの反映

private正本およびpublic作業コピーへ次を追加した。

1. 1事例 = 一連の同一イベント
2. 同じ台風・前線・低気圧・地震・噴火等を日別・地域別・資料別に重複計上しない
3. 実発生 / 予測 / 制度 / 想定 / 注意喚起を分類する
4. 予測のみを発生事例へ数えない
5. 表の行数ではなく独立イベント数を数える
6. 複数事例比較記事では、一次情報で確認できる場合に直近実事例を原則2件以上確認する
7. 単一災害深掘り記事へ件数合わせで別災害を追加しない
8. 最新・直近・近年と書く場合は公開・大幅更新時点まで再検索する
9. title/H1の年代・件数と本文年表を再照合する
10. 線状降水帯では半日前予測・直前予測・発生情報を分離する
