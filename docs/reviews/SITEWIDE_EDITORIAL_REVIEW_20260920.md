## 3. 今回、実際に本文修正が必要だった記事

### B067-B077 線状降水帯特集

初回再監査では以下を確認した。

- B067: 特集トップのH2が論点メモに近く、「線状降水帯は増えているのか」への答えが遅い
- B068: 年表の価値はあるが、制作側の説明が混ざる
- B069: 「増えている？」への結論をもっと先に出す必要がある
- B070: 公開本文に「CSVを集計した後に追加」という制作TODOが混入
- B071: 比較軸は妥当だが、読者が何を見ればよいかを先に出す余地がある
- B072: 制度史が年次列挙に寄り、2021/2022/2026の意味を先にまとめる必要がある
- B073-B077: 地域名と事例だけを差し替えたように見える共通構成があり、地域固有の主張が弱い

対応後は、各記事について「問い → 結論 → 根拠」の順を明確にし、制作メモ表現を除去、地域記事は地域固有の事例・地形・行動へ再構成した。

## 4. B001-B066で確認した定型表現について

複数記事に「この記事では〜整理します」「〜で整理しています」が存在する。ただし、今回重点確認したB001、B007、B019、B057、B061-B066では、すでに先頭に明確な結論見出しがあり、定型文が結論の代わりにはなっていなかった。

したがって一括置換は行わない。関連記事リンクの「〜で整理しています」も、リンク先の役割説明として自然な場合は維持する。

今後の新規・改訂記事では、次を優先する。

- 「この記事では何を説明するか」より「読者がまず何を知るべきか」を先に書く
- 兄弟記事で同じ章構成を使い回さない
- 疑問形見出しは直後1〜2文で答える
- 制作側のTODOや将来作業を公開本文へ出さない
