# B033 ペット防災 表・チェックリスト改善レビュー（2026-09-18）

## ユーザー指摘

- 「命・健康」「移動」などの分類名と用品名だけでは抽象的で、何を確認すれば準備完了なのか伝わりにくい。
- 保存用チェックリストを記事内に置くだけでは、読者がページを閉じた後に忘れやすい。

## 改善方針

### 表・要約コンテンツ

短い分類表でも、単なるキーワード列挙で終わらせない。少なくとも次の3段階が分かるようにする。

1. **準備するもの**：具体的な用品・情報
2. **平常時に確認すること**：数量、期限、使用可否、移動可否、ルール等
3. **災害時に困らないためのポイント**：なぜ必要か、どの行動まで試すか

「キャリーを用意する」ではなく「ペットを入れた状態で持てるか・玄関や階段を通れるかまで試す」のように、読者が完了条件を判断できる表現を優先する。

### 保存用チェックリスト

公開ページの「保存用チェックリスト」は、対応可能な場合は次を備える。

- ブラウザ内でチェック状態を自動保存
- 完了数を表示
- 最終更新日を表示
- 未完了項目を含む共有テキストを生成
- Web Share APIが利用できない場合はクリップボードコピーへフォールバック
- ブラウザデータ削除時には保存状態が消えることを説明

チェック結果は外部サーバーへ送信せず、端末ブラウザの localStorage に保存する。

## B033での変更

- 5つの抽象的なカードを4列の詳細表へ変更
- 「命・健康」「移動」「排泄・衛生」「情報」「避難先」それぞれに具体的な確認内容・完了条件を追加
- 保存用チェックリストをインタラクティブ化
- 進捗共有時は未完了項目を先に表示
- 家族・自分のメモアプリ等への共有用途を本文で説明
