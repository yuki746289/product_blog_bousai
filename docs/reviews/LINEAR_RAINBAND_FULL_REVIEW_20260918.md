## レビュー理由

短期間で特集を拡張した結果、公開記事内に以下の問題が残っていた。

1. 「今後追加する集計」「将来的には」「CSV集計後に追加」など、編集者向けTODOが本文へ露出
2. 「先に確認」「まず見る」「読み方」など、公開記事として不自然な編集用語
3. 「代表事例」「代表例」の多用
4. 地域記事B073-B077で見出し構成と説明順が過度に共通化
5. 2026年5月29日からの新しい防災気象情報名称と警戒レベルの関係が十分に反映されていない
6. Markdownを直してもデプロイ時の enhance_linear_rainband_feature.py が古い表現を再挿入する箇所があった

## 実施した修正

### B067
- 「まず見る：5つの数字」を「主な事例とデータ」へ変更
- 「読み方」を「確認ポイント」へ変更
- 「代表事例」を「主な事例」へ変更
- 2026年の現行情報名を追加
  - 気象解説情報（線状降水帯半日前予測）
  - 気象防災速報（線状降水帯直前予測）
  - 気象防災速報（線状降水帯発生）
- 警戒レベル3・4・5との関係を追加
- 「線状降水帯発生情報＝警戒レベル5ではない」を明記
- 危険な場所ではレベル4までに避難する考え方を明記

### B068-B072
- 制作予定・調査予定・将来対応の記載を削除
- 「代表」表現を中立化
- 件数ランキング作成予定を削除し、短期系列をランキング化しない理由へ置換
- 観測史上1位の比較では統計開始年に注意する説明へ修正
- 2026年5月29日以降の情報体系へ更新
- 過去の情報名と現在の情報名を混同しない説明へ修正

### B073-B077
共通の「半日前予測→直前予測→発生情報→4段階」というテンプレ構成を撤去し、地域固有の判断ポイントへ再構成。

- B073 九州：九州北部・南部・奄美・沖縄等の情報区分
- B074 関東甲信：都市部・地下空間・河川・山地・通勤移動
- B075 中国：山陽・山陰、土砂・河川・浸水、山口県の気象情報区分
- B076 四国：山地・谷沿い・夜間移動の危険
- B077 東海：県内での対象地域変化、移動予定、県ごとの災害特性

全地域記事で、線状降水帯発生情報が警戒レベル5そのものではなく、警戒レベル4相当以上で発表される補足情報であることを明確化。
