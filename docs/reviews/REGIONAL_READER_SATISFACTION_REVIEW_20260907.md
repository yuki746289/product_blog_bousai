# 地域記事・関連行動記事 読者満足度レビュー

更新日: 2026-09-07
対象: B048〜B050、B053〜B058

## 1. 評価目的

従来の「文字数」「出典」「安全性」に加え、読み終えた読者が次の状態になれるかを評価する。

1. その地域でなぜその災害に備える必要があるか理解できる
2. 被害数だけでなく、実際に何が起きたか具体像を持てる
3. 災害が生活へどう波及するか想像できる
4. 過去の事例と現在のハザードを混同せず理解できる
5. 読後に自宅・職場・家族で何を確認するか分かる

文字数は補助指標とし、見出しが多くても各章が短い要約だけの場合は「内容十分」としない。

## 3. 今回重点補強した記事

### B048 宮城県

補強前の課題:
- 2011年の説明が「最大震度7・巨大津波」中心で、生活への波及が薄かった。
- 1978年と2011年の違いは説明できていたが、読者が「自分は何を備えるか」へ落とし込む材料が少なかった。

補強内容:
- 東日本大震災のピーク時避難者、避難所、停電、給水・ガス支障を追加。
- 公共交通の運休・代行輸送等を生活影響の具体例として追加。
- `データ → 読み取れる課題 → 家庭の対策` 表を追加。
- B057地震初動へのリンクを追加。
- 「水・食料」だけでなくトイレ・電源・情報・移動を一つの生活セットとして考える説明を追加。

### B049 広島市

補強前の課題:
- 1999/2014/2018年の被害集計はあるが、2014年に何が起きたかの具体像が弱かった。
- 夜間豪雨と避難判断の難しさが十分に伝わっていなかった。

補強内容:
- 2014年8月19日夜〜20日未明の雨の集中を追加。
- 上原観測所の1時間雨量・累加雨量を追加。
- 八木三丁目で阿武山からの土石流が沢出口の住宅地へ流れ込んだ具体例を追加。
- 1999/2014/2018年の違いを比較する表を追加。
- 夜間になる前の判断、家族内の支援順など読者行動へ接続。

### B050 荒川下流

補強前の課題:
- 洪水史と治水史は十分だったが、「現在の長期浸水が生活に何を起こすか」が抽象的だった。

補強内容:
- 荒川右岸低地氾濫の想定最大規模ケースで、浸水範囲の大部分に2週間以上の浸水継続区域が生じる資料を追加。
- 道路、電気・給排水、エレベーター、トイレ、車、物流等への影響を具体化。
- 戸建て/低層、マンション/高層、車保有家庭で確認点が変わることを追加。
- `データ → 課題 → 対策` 表を追加。

## 6. 今後の既存記事レビューへ適用する基準

地域記事以外のB001〜B047、B051〜B052についても、次の順で再レビューする。

1. 高リスク/行動記事
2. 商品・グッズ記事
3. 保険・制度記事
4. 住宅・車・停電等の実用記事
5. pillar/総合記事

各記事で以下を確認する。

- 結論だけでなく理由・具体例が十分か
- 章が短い要約の連続になっていないか
- 読者が自分の状況へ置き換えられるケースがあるか
- 数字や一般論だけでなく生活場面が見えるか
- 読後に次の行動が明確か
- 必要な場合、情報記事 → 商品記事 → Amazonの自然な導線があるか
- 既存記事へのリンクで説明を省略しすぎていないか

## 7. 判定方針

最終判定は「規定文字数を満たしたか」ではなく、**その記事を最後まで読んだユーザーが、検索前より理解・判断・行動を具体化できるか**を主基準とする。

文字数は不足検知に使うが、満足度は具体例・詳細・比較・生活影響・次の行動を含む情報価値で評価する。
