## 4. 今回の新しい依頼

ユーザーから以下の方針が承認された。

### 4.1 線状降水帯記事の「発生後」再調査
記事作成後も各地で被害が更新されているため、線状降水帯や関連豪雨について、

- 人的被害
- 住家被害
- 土砂災害
- 河川氾濫
- 堤防決壊
- 都市型水害
- ダム
- 交通
- 停電・断水
- 農林水産
- 避難・孤立
- その他の社会影響

まで横断検索し、既存事例の被害内訳を更新する。

### 4.2 「記録更新」の横断収集
雨量だけでなく、以下のような記録も事例選定対象にする。

- 観測史上1位 / 上位
- ○月として1位
- 連続降水日数
- 月内降水日数
- 日照時間
- 河川最高水位
- 最大浸水深 / 浸水面積
- ダム貯水率・貯水量の過去最低
- 水系全体の過去最低
- 取水制限・給水制限
- 緊急放流 / 異常洪水時防災操作
- 停電・断水・交通の過去最大/最長
- 農林水産被害
- 県内初 / 市内初 / 制度開始後初
- その他、公的一次資料で確認できる地域史上の記録

ユーザー例:
- 「ダムの貯水率が過去最低」
- 「東京で34日？連続雨で過去最高」
  - 調査時点では2026年9月30日までで35日連続降水という候補を把握している。
  - 記事反映前に一次資料で最終確認すること。
