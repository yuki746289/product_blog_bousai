## 7. 現在の追加記事方針

B001〜B060まで整備済みのため、B061以降は次の順で判断する。

1. 既存60記事・Q&A・商品記事と検索意図を照合
2. 現在のSERP・検索需要を確認
3. 一次情報・更新可能性を確認
4. `NEW ARTICLE / EXISTING ARTICLE UPDATE / Q&A / HOLD` を判定
5. NEW ARTICLEの場合のみ新しい記事IDを採番

記事数そのものをKPIにしない。

商品記事の場合は `docs/AMAZON_WORK_PREFLIGHT.md` を開始ゲートとし、Amazon専用ルールを必ず読み直す。

地域記事の場合はprivate正本 `sites/bousai/REGIONAL_CONTENT_PLAN.md` の地域選定スコアを適用する。
