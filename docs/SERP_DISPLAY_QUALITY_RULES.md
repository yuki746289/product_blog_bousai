# 防災ブログ SERP表示品質ルール

作成日: 2026-09-11
正本: `yuki746289/product_blog_rules/sites/bousai/rules/SERP_DISPLAY_QUALITY_RULES.md`

## 1. 目的

Google検索結果では、ページの `<title>` や `meta description` がそのまま表示されるとは限らない。
Googleは検索クエリやページ内容等に応じてタイトルリンクやスニペットを自動生成するため、記事品質はページ内だけでなく、**検索結果上で「何の記事か」「検索者の疑問に答えそうか」が伝わるか**も確認する。

本ルールは検索結果だけを最適化するための文章制作を目的としない。読者にとって自然で正確な本文を前提とし、重要な回答部分が検索結果に抜粋されても意味が通る文章構造を作る。

## 2. 記事作成時の基本

- `<title>` は主検索意図が一目で分かる、ページ固有の簡潔な表現にする。
- H1はtitleと意味をそろえ、ページ主題をぶらさない。
- `meta description` はページ固有の内容を正確に要約するが、常にそのまま表示される前提では設計しない。
- 主要なH2/H3では、必要に応じて直下1〜2文で結論または要点を示す。
- 重要な回答段落は、検索結果に単独で抜粋されても対象・条件・行動または結論が分かるようにする。
- 「これ」「その場合」「前述の通り」「上記の理由で」だけに依存した重要文を避ける。
- SERP表示を狙うための不自然なキーワード反復、誇張、煽り、危険な断定を行わない。

## 3. SERP調査項目

主要クエリごとに可能な範囲で以下を記録する。

- 調査日
- 検索クエリ
- 順位
- サイト / URL
- Google検索結果に実際に表示されたタイトル
- ページ側の `<title>` / H1との相違
- Googleによるタイトル書き換えの有無または可能性
- 実際に表示されたスニペット本文
- スニペットが本文のどの箇所から取得されたか（特定できる場合）
- meta descriptionとの一致 / 不一致 / 一部一致
- 検索意図への回答度
- SERPだけを見たときの内容理解のしやすさ
- クリック理由が明確か
- 自サイトとの差

検索結果はユーザー、地域、端末、時期等によって変化し得るため、1回の目視結果を固定的な事実として一般化しない。

## 4. 判定

- `PASS`: タイトルとスニペットが検索意図と整合し、重要段落も単独抜粋に耐える。
- `FIX`: title/H1/本文構造に原因があり、検索結果で内容が伝わりにくい。
- `MONITOR`: データ不足、順位が既に良い、またはGoogle側変動との切り分けができない。
- `N/A`: 検索流入を目的としないページ。

## 5. 既存記事の見直し

既存記事は一括改稿しない。優先順位は次の通り。

1. Search Consoleで表示実績がある記事
2. 平均順位5〜15位程度で改善余地がある記事
3. 表示回数が多いのにCTRが低い記事
4. Google表示タイトルがページ主題とずれている記事
5. スニペットが検索意図に対して弱い記事

順位が既に良い記事は、まずSERP表示と本文構造をレビューし、必要なら局所修正する。title、H1、URL、記事全体構成の変更はSearch Consoleと競合調査を確認してから判断する。

## 6. 禁止事項

- スニペット表示を保証しない。
- meta descriptionが必ず表示される前提で評価しない。
- 1回の検索結果だけでtitleを変更しない。
- 競合のタイトル・スニペットをコピーしない。
- 検索結果向け文章のために本文の自然さ、安全性、正確性を下げない。
