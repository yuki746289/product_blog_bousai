# 線状降水帯 地方別記事 拡張方針

作成日: 2026-09-14

## 目的

線状降水帯特集 B067-B072 の全国俯瞰に加え、検索者が自分の地域へ落とし込んで読める地方別記事を追加する。

地方名だけを置換した量産は行わない。各記事は少なくとも次のうち複数を、その地方固有の一次資料で説明できる場合に作成する。

- 代表的な線状降水帯・豪雨事例
- 観測史上1位等の具体的な雨量記録
- 気象庁が解析した発生環境
- 地方予報区・府県情報など防災気象情報の単位
- 洪水・土砂・内水・高潮等、その地方で記事上区別すべき危険
- 既存の地域災害史記事・避難判断記事との内部リンク

## 情報設計

- B067: 線状降水帯特集トップ
- B070: 地域別の全国概観・地方別記事へのハブ
- B073以降: 地方別の詳細記事

地方別記事は B070 の子記事とし、全国の「多い地域」概観と検索意図を分ける。

## SEO上の境界

- B070は `線状降水帯 多い地域`、`線状降水帯 地域` の全国比較意図を担当する。
- B073以降は `線状降水帯 九州`、`線状降水帯 関東` 等の地域検索意図を担当する。
- 同じ全国表・同じ説明を各地方記事へ大量複製しない。
- 地方記事には、その地方固有の事例・数値・発生環境・情報単位を置く。
- 都道府県別記事は、GSCで需要が確認され、一次資料で十分に差別化できる場合に追加する。

## 安全性

- 過去事例を次回の発生地点・発生時刻の予測に使わせない。
- 「この地方は多い/少ない」だけで自宅の危険を判断させない。
- 現在進行中の大雨では、最新の気象庁情報、キキクル、河川情報、自治体の避難情報を優先する。
- 半日前予測・直前予測・発生情報のどれか一つを、全国一律の避難スイッチとして書かない。

## 更新運用

- 地域別公式件数は、2023年5月25日以降の気象庁CSVを同一ルールで集計できた後に追加する。
- 基準変更があれば系列を注記する。
- 最新の顕著事例を追加する際は、一次資料確認日と既存記事との差分を記録する。
- 公開後はGSCで地域名クエリを観測し、記事追加・統合・見出し修正の判断材料にする。
