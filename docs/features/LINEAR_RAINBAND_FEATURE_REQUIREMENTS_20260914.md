# 線状降水帯 特集 要件

更新日: 2026-09-14

## 1. 目的

線状降水帯について、単なる用語解説ではなく、**日本でいつ・どこで・どの程度の豪雨が起きたかを、歴史・雨量記録・地域差・発生頻度・情報制度の変化から俯瞰できる特集**を作る。

読者が長文を読む前に概要を把握できるよう、各ページは表を先に置き、詳細解説を後段に置く。

## 3. 表示要件

### 3.1 最初に表で見せる

各ページの上部に、読者が数十秒で概要を把握できる表を置く。

全国年表の基本列:

- 年月日
- 地域
- 災害・気象事例名
- 主な雨量
- **記録性**
- 従来記録・平年値との比較
- 当時の公的な表現・名称
- 線状降水帯との関係
- 出典

### 3.2 「記録性」を独立表示する

優先して表示する表現:

- 観測史上1位
- 統計開始以来最大
- 月として1位
- 従来記録を更新
- 平年月降水量の2倍・3倍等
- 記録的な大雨

独自の「異常度スコア」は当面作らない。公的資料で確認できる事実を優先する。

### 3.3 「100年に一度」等の扱い

「100年に一度」「50年に一度」等は、気象庁・自治体・報道等の出典を確認できた場合のみ掲載する。

以下を混同しない。

1. 気象庁が定めた災害・気象事例の名称
2. 公的機関が当時使った表現
3. 報道で使われた表現

確認できない表現を推測で補わない。

## 4. 歴史データの重要ルール

### 4.1 2023年5月25日を境に集計系列を分ける

気象庁の現行「線状降水帯の事例」一覧は、顕著な大雨に関する気象情報の新たな運用を開始した**2023年5月25日13時以降**を統一的な掲載対象としている。

そのため、2014年・2015年・2017年・2018年・2020年等の過去豪雨と、2023年以降の公式検出事例を単純に同じ年次件数系列として比較しない。

### 4.2 発生数を3系統に分ける

- **A: 現行基準による公式検出・情報発表**
- **B: 過去豪雨を後から解析して線状降水帯と位置付けた事例**
- **C: 気候シミュレーションによる将来発生頻度**

A/B/Cを同じ「実測の年間件数」として扱わない。

## 5. 「増えているか」の結論ルール

「最近、線状降水帯がどんどん増えている」と短い観測系列だけから断定しない。

初期版では次のように整理する。

- 公式の事例一覧は運用・基準変更の影響を受けるため、短期間の件数だけでは長期トレンドを判定できない。
- 気象庁の気候シミュレーションでは、平均年間発生回数が過去実験23回、2℃上昇実験31回、4℃上昇実験38回となり、温暖化した将来気候で増える結果が示されている。
- 上記は**将来気候シミュレーション**であり、「現在すでに23回から38回へ増えた」という意味ではない。

## 6. 地域分析

初期版は47都道府県ランキングを無理に作らず、気象庁が解析で高頻度としている地域と主要事例を整理する。

重点地域:

- 九州～南西諸島
- 四国南東斜面
- 紀伊半島
- 中国地方
- 東海
- 関東甲信
- 北陸・東北
- 北海道

今後、現行基準のCSVを集計できた段階で地域別件数表を追加する。

## 7. 全国年表の初期対象

気象庁が線状降水帯を伴う顕著な大雨として明示している、または事後解析で線状降水帯と説明している主要事例を中心にする。

初期掲載候補:

- 2014年8月 広島県の大雨
- 2015年9月 関東・東北豪雨
- 2017年7月 九州北部豪雨
- 2018年7月 平成30年7月豪雨
- 2020年7月 令和2年7月豪雨
- 2023年6月 梅雨前線・台風2号による大雨
- 2024年7月 山形県等の大雨
- 2024年9月 能登を中心とする大雨
- 2025年8月 低気圧と前線による大雨
- 2026年8月 千葉豪雨等、公開時点で一次資料を確認できる最新事例

## 8. データ品質

- 最優先ソースは気象庁。
- 雨量値は観測地点・時間単位を必ず併記する。
- 「観測史上1位」は対象観測地点・指標を省略しない。
- 「平年の月降水量の○倍」は気象庁がその比較を明示した場合に使う。
- 災害名称と気象事例名を区別する。
- 後年解析で線状降水帯とされた古い事例では「当時から公式にそう呼ばれていた」と書かない。
- 更新時は出典確認日を記録する。

## 9. デザイン

- 通常記事より「資料・データ特集」と分かる見た目にする。
- 冒頭に特集内ナビゲーションを置く。
- 表はスマートフォンで横スクロール可能にする。
- `観測史上1位`、`記録更新`、`将来予測`、`後年解析` 等をテキストバッジで識別する。
- 色だけで意味を伝えない。

## 10. SEO・内部リンク

- 特集全体の主テーマ: `線状降水帯 歴史`, `線状降水帯 過去`, `線状降水帯 増えている`, `線状降水帯 発生回数`, `線状降水帯 多い地域`, `線状降水帯 雨量`, `線状降水帯 いつから`
- B005等の行動記事とは検索意図を分離する。
- 特集からB005、B036、B042などの防災行動記事へ導線を置く。
- 初期公開後、GSCでクエリを観察し県別・個別豪雨ページの増設を判断する。
